# キーバインドとコマンド

2026-10-23現在のソースに対応する操作表。中央の設定面・カテゴリ追加の＋・3表示モード・自前メニューは、公開済みv0.1.0 ZIPより後の変更である。

## 画面から操作する

窓の共通上部は左に「新しいノート」、右に「一覧」「両方」「ノート」があり、表示する区画を切り替える（#290 / ADR0047）。
3つは外枠を持たず、項目間の区切りと選択中の塗り・下線で示す。設定・閉じるとは間を空ける（#349 / ADR0060）。
「一覧」は窓を細くし、「両方」「ノート」へ戻すと直前の広い幅または最大化状態に戻る。
切替だけでは保存せず、編集中の本文・Undo・選択・読んでいる論理行を保つ。設定と閉じるもこの上部に常設する。
一覧でノートをクリックしたりj/kで選んだりしても細いまま。Enter・編集・新規で本文へ入ると両方を表示する。
ノート表示からCtrl+Shift+Fや本文Escで索引へ戻ると両方になる。Escは従来どおり、編集中なら保存する。
パレットとEx `:listonly` / `:both` / `:noteonly`からも同じ切替ができる。

| 直接キー | 表示 |
| --- | --- |
| `Ctrl+Shift+1` | 一覧のみ。窓を細くする |
| `Ctrl+Shift+2` | 一覧とノートの両方 |
| `Ctrl+Shift+3` | ノートのみ |

数字は主キーボード列を使う。索引・本文・Ex/パレット/検索/置換/絞り込みの欄から共通コマンドへ渡る。
IME変換中、名前入力・確認ダイアログ・設定モーダル中は表示キーを実行しない。
ボタンのツールチップ、パレット、F1のキー説明にもキーを表示する。
一覧のツールチップは窓が細くなることも示す。設定と閉じるにも説明がある。
ツールチップは全操作部品に付く。字のある釦はキー（無ければ短い説明）だけ、絵だけの部品は名前とキーを出す。
同じキーをUIAのAcceleratorKeyにも公開する（#348 / ADR0060）。
Windows側の入力言語切替などへ同じキーを個別割当した環境は、OS側の動作が優先される場合がある。

共通ヘッダー左の「新しいノート」で無題を書き始める。狭い一覧窓では紙と追加記号の図形になる。
tooltipとUIAのHelpTextは表示のたびに作成先を「新しいノート — 〈現在のカテゴリ〉へ（Ctrl+N）」と示し、カテゴリが無ければ作れない理由を出す。作成先の規則はCtrl+Nと同じ（#344 / ADR0059、#349 / ADR0060）。
右ペイン上部は［保存｜このノート内を検索｜操作▾］をパンくず・通常本文と同じ左基準へ揃える。「保存」で本文を保存し、「操作」でこのノートの7操作を選べる。「編集」で入力を始め、
「保存して閲覧」で保存後に閲覧へ戻る。上部の「閲覧」「編集」の札も同じ処理を使う。
変更があるあいだ「保存」は橙の主操作になり、パンくずのノート名の後ろに丸の印が付く。無題は開いた時点から変更ありとして扱い、編集へ入っただけでは灯さない。
保存（Ctrl+S・「保存」・本文Esc・ノート切替の保存）が済むと中立の釦へ戻り、印が消え、UIAで「保存しました」を通知する。窓の題名は変えない（#349 / ADR0060）。
ノートを選んでいないあいだは本文操作列と閲覧/編集を出さず、本文の場所に案内とキー（Ctrl+N / Ctrl+Shift+F / F1）と作成先を出す。
新規の常設入口は3表示とも共通ヘッダーの一つで、一覧のみからも書き始められる。
F6/Shift+F6は可視の共通ヘッダー・索引・本文操作列・本文を巡回する。ヘッダーの入口は新規、索引は検索欄、本文操作列は選択中の札。
ヘッダー内はTab/Shift+Tabで新規→表示3択→ヘルプ→設定→閉じるを巡る。表示3択と閲覧/編集の群にはTabで1回だけ止まり（選択中の項目）、
←→↑↓はfocusだけを動かし、Enter/Spaceで選ぶ（矢印だけでは窓幅や保存を変えない・#348 / ADR0060）。
Enterは押した時、Spaceは離した時に実行し、押し続けた自動繰り返しは無視する。
マウスの釦は押して離した時に実行し、押したまま外へ出て離すかcaptureを失えば取り消す。「操作」だけは押した時に開く。
focusの枠はキーボードで動かした後だけ描き、OSの「キーボードの印を常に表示」がonなら常に描く。
検索欄へ入る場合は既存のfocus時保存を適用し、名前付きEDITは保存、無題は質問せず検索対象外を保つ（#342）。
カテゴリ行の右クリック「新しいノート」は押したカテゴリを作成先にする。作成先はHelpTextにも示す。
無題の離脱をキャンセルしたときは本文・Undoと表示モードを保ち、新規作成の成功後に本文を開く（#302 / ADR0051）。
「保存済みなら終了」は未保存の変更があると終了を拒否し、「保存して終了」とは動作が異なる。
新規の初回保存では名前と既存カテゴリを選ぶ。「操作」の「別名で保存」で別の新しいmdへ保存して開く。
「操作」の「名前を変更」は同じ入力面で現在ノートのmdと履歴を新しい名前へ移す。カテゴリは変えられない。
「このノート内を検索」は表示中の本文の中を探す。幅の狭い窓では虫眼鏡の絵だけに縮め、消さない（#348）。
「操作」の「置換」は下端に置換の欄を開く。**正規表現**で、編集中の本文だけが対象（FR-023 / #41）。
ドロワーが見える表示では頭に「すべてのノートを検索」の欄が出ている。ここに打つと、名前か本文が一致するノートだけが索引に残る
（FR-032 / #40）。ノート内検索とは対象も語も別で、同期しない。

## 操作メニュー・右クリックメニュー

操作▾は「別名で保存…／名前を変更…／保存して閲覧」｜「置換…／履歴から戻す…」｜「編集を破棄して読み直す／ノートをごみ箱へ移す」の3群7項目。
設定・表示切替・行番号・カテゴリの操作は共通ヘッダーやパレットから使う。末尾の「…」は次に入力する面がある印で、確認なしの破棄・ごみ箱には付かない。
カテゴリ行の右クリックは「新しいノート」｜「色を変える…／カテゴリ名を変更…」｜「新しいカテゴリ…」｜「カテゴリを削除」、
ノート行は「名前を変更…」｜「ノートをごみ箱へ移す」、空白は「新しいカテゴリ…」。右クリックだけでは文書や索引cursorを選び直さない。
Shift+F10／アプリケーションキーは索引cursorの行に開く。行が無ければ空白のメニューになる。

↑↓は無効な項目を飛ばして巡回し、Home/Endは端の有効項目へ移る。Enter/Spaceと表示されたアクセスキーは離した時に実行する。
マウスは同じ項目で左ボタンを押して離すと実行する。開いた時の解放だけや、外での解放では実行しない。
Esc・Alt・F10・外クリック・非アクティブ化で閉じ、操作▾の再押下も閉じる。狭い窓では矢印の合図とホイールで面内を送れる。
右列は既存の直接キー、無ければ `:history` のようなEx名。どちらも無い「保存して閲覧」「置換」は「V（メニュー内）」「P（メニュー内）」と示す。
本文Escは保存して索引へ戻る操作で、閲覧モードへの切替ではない。Ctrl+Hも置換には割り当てない。

操作できない項目は無効表示し、実行時にも可否を確かめる。失敗は入力面が開いていればその結果行、ほかではI/O失敗を箱、前提不足や入力の拒否を下端の1行に出す。
一覧だけの表示でも同じ下端通知を使い、表示モードは変えない。ごみ箱操作の成功は画面通知を出さず、UIAだけが「〈名前〉を一覧から除きました」と知らせる（#350 / ADR0060）。

## ヘルプを開く

共通ヘッダー右の「?」（ヘルプ・設定の左）、F1、`:help` / `:h`、Ctrl+Pは同じ操作一覧を開く（#349 / ADR0060）。
日本語の使い方と候補を表示し、「キー操作を表示」またはTabでキー説明を開閉する。
候補はクリック、上下の「前」「次」、ホイール、↑↓で選べる。
キー説明を開いても候補は最低3行残り、入りきらない説明はPgUp / PgDnで送る。ページ数は窓の高さと説明行数から決まり、札の右に表示する（#69 / #292）。
ヘルプの入口はこの4つ。**INDEXの `?` は後方検索になった**ので、ヘルプには使わない（ADR 0023）。編集中の本文や入力欄の `?` は文字入力。
INDEXと閲覧本文の文字キーはIMEを英数入力にして使う。

## INDEX（左の索引）

| キー | 動作 |
| --- | --- |
| `/` / `?` | このノート内を前方／後方に検索する欄を開く |
| `n` / `N` | 直前の方向／逆方向で次の一致へ。欄が閉じていても効く |
| `F3` / `Shift+F3` | 次の一致／前の一致。向きを名指しするので、覚えている向きは変わらない |
| `:` | コマンド入力 |
| `i` | 現在ノートを編集し、本文へ。既に編集中なら入力中の本文を維持 |
| `F1` | ヘルプ |
| `Ctrl+P` | コマンド一覧 |
| `Ctrl+F` | このノート内を検索する欄を開く |
| `Ctrl+Shift+F` | ドロワーの頭の「すべてのノートを検索」の欄へ移り、いまの語を全選択する |
| `Ctrl+N` | 現在カテゴリに新しい無題を開く。名前付きの編集は先に保存。無題は保存／保存しない／キャンセルを選ぶ |
| `Ctrl+S` | 開いている本文を保存。無題は名前入力へ。編集モードは保つ |
| `j` / `k` | 次／前のノート、または折り畳んだ・空のカテゴリへ |
| `g` `g` / `G` | 最初／最後の行へ |
| `h` / `l` | カテゴリを折り畳む／展開する。カテゴリ行からの `l` は中のノートへ |
| `Enter` | ノートから本文へ。カテゴリ行では移動しない |
| `↑` / `↓` / `PgUp` / `PgDn` | 索引をスクロール。`j` / `k`のカーソル移動とは別 |
| `Esc` | 何もしない。アプリは閉じない |

別のノートを選ぶときは、編集中の本文を保存してから切り替える。保存できなければ切り替えない。

Ctrl+Shift+SはINDEX・本文・コマンド入力から「別名で保存」を開く。名前入力欄やIME変換中へ追加割当しない。
F2は同じ表・同じ抑止条件で「名前を変更」を開く。

## 本文（右のペイン）

| キー | 動作 |
| --- | --- |
| `:`（閲覧時） | コマンド入力。Escで閲覧本文へ戻る |
| `i`（閲覧時） | 編集を開始 |
| `/` / `?`（閲覧時） | このノート内を前方／後方に検索する欄を開く |
| `n` / `N`（閲覧時） | 直前の方向／逆方向で次の一致へ |
| `Ctrl+F` | このノート内を検索する欄を開く（編集中も同じ） |
| `F3` / `Shift+F3` | 次の一致／前の一致（編集中も同じ。覚えている向きは変わらない） |
| `Ctrl+h` / `Ctrl+j` / `Ctrl+k` / `Ctrl+l`（編集時） | 通常の矢印と同じ左／下／上／右へ移動。本文とUndoを保つ |
| `Ctrl++` / `Ctrl+-` | 本文表示を10%ずつ拡大／縮小。テンキーの＋／－も同じ |
| `Ctrl+0` | 本文表示を100%へ戻す。テンキー0も同じ |
| 本文上の `Ctrl+ホイール` | 上で拡大、下で縮小。本文にfocusが無くても使える |
| `F1` | ヘルプ |
| `Ctrl+P` | コマンド一覧。開くだけでは保存せず、本文を保つ |
| `Ctrl+N` | 新しい無題を開く。名前付きの編集は先に保存。無題は保存／保存しない／キャンセルを選ぶ |
| `Ctrl+S` | 本文を保存。無題は名前入力へ。編集モードは保つ |
| `Esc` | INDEXへ戻る。編集中なら保存し、編集モードは保つ。保存失敗なら本文に留まる |

Ctrl＋hjklは編集本文だけで使う。Shift・Alt併用やIME変換中は追加割当せず、RichEdit／IMEへ渡す。
拡大縮小は閲覧/編集共通で50～300%。Ctrl++はShift併用の＋にも対応し、US配列のCtrl+=も拡大する。
倍率はノート・モード・テーマ・言語を切り替えても実行中は共通で保ち、次の起動では100%に戻る。
本文の文字サイズ・内容・Undo・保存状態は変えず、行番号だけ本文倍率へ追従する。IME変換中やモーダルの背面では適用しない。
通常のhjkl、Backspace、Enterは従来の文字入力・編集のまま。Ctrl+Hは置換には割り当てない。
編集中の本文では `/`・`?`・`n`・`N` は普通の文字入力で、検索はCtrl+Fと画面のボタンから開く。

## コマンド一覧・コマンド入力

| キー | 動作 |
| --- | --- |
| 文字入力 | 一覧では名前・別名で絞り込む。コマンド入力では命令を書く |
| `↑` / `↓` | 一覧の候補を選ぶ |
| `Enter` | 選んだ操作、または入力した命令を実行 |
| `Esc` | 入力面を閉じ、開く前の区画へ戻る。保存しない |
| `Ctrl+P` | 同じコマンド一覧へ切り替える |
| `F1` | 同じヘルプ一覧へ切り替える |
| `Tab`（一覧） | キー説明を開く／閉じる |
| `PgUp` / `PgDn`（一覧） | キー説明が箱に入りきらないとき、1 枚ずつ送る。先頭・末尾で止まる。いま何枚目かは札の右の「n/m」（#69） |
| `Ctrl+N` | 共通の新規操作 |

**Ctrl+Sはどの入力面（Ex・パレット・検索欄・置換の欄・絞り込み欄）でも共通の保存へ渡り、欄は開いたまま残る**（#67）。
保存できたかどうかに関わらず、欄の語・選択・キャレット・フォーカス・入力面の種類は変わらない。
編集中でなければ本文と同じく何もせず、失敗の1行の見せ方も本文のCtrl+Sと同じである。

入力面のIME変換中はIMEの操作を優先し、Enterで命令を実行したり、Escで入力面を閉じたりしない。
変換中のCtrl+Pでも一覧へ切り替えず、入力を残す。変換を終えた後は上の操作に戻る。
編集中の本文の `:`・`i`・`?` は命令にならない。本文のIME変換中もキーはRichEdit／IMEへ渡す。
検索欄・名前入力欄・コマンド入力欄の `/`・`?`・`n`・`N` も普通の文字入力で、検索の操作にはならない。

## このノート内の検索欄

本文の操作行の下に検索欄・件数・前後・閉じるをまとめて表示する。本文を覆わず、幅が狭いときは結果を別の行へ置く。
検索対象とEnterの方向は、入力後も表示する（[ADR0052](adr/0052-note-search-surface.md)）。

| キー・操作 | 動作 |
| --- | --- |
| 文字入力 | 打つたびに、いまの向きで最初の一致へ進む（IME変換中は動かず、確定してから進む） |
| `Enter` | 直前の方向で次の一致へ。**欄は閉じない** |
| `Shift+Enter` | 逆方向で前の一致へ。覚えている向きは変えない |
| 「◀ 前へ」/「次へ ▶」 | その向きで1つ進む。覚えている向きは変わらない（F3 / Shift+F3 と同じ） |
| `Ctrl+S` | 共通の保存。**欄は開いたまま**で、語も選択もキャレットも変わらない（#67） |
| `Esc` / 検索帯の「×」 | 同じ処理で欄を閉じ、開く前の可視の区画へ戻る。**本文の選択はそのまま残る** |

対象はRichEditが今表示している平文で、閲覧なら描画後の文字、編集なら未保存の本文。
一致はASCIIの英字だけ大小を無視し、全角／半角・かな／カナは区別する。正規表現は#41の範囲。
一致は選択範囲1つで示し、全一致の着色はしない。端まで行ったら反対の端から続ける。
欄には向きと「k / n 件」が出て、0件は同じ場所に「見つかりません」と出て選択は変わらない。
IME変換中はマウスの前後・閉じるも実行せず、変換終了後の操作を受ける。
欄を閉じているときの `n` / `N`・F3 が一致しなければ音だけで知らせる。語は保存せず、起動のたびに空から始まる。
向きを変えるのは `/` と `?` だけで、`n` / `N` と Enter / Shift+Enter はその向きに対する相対の操作である。
重なる一致（`aaaa` の中の `aa`）も飛ばさず、件数と同じ順番で全部たどれる。

## すべてのノートを検索する欄（ドロワーの頭・常設）

| キー・操作 | 動作 |
| --- | --- |
| `Ctrl+Shift+F` | どの区画からでもこの欄へ移り、いまの語を全選択する（IME変換中は移らない） |
| 文字入力 | 打つたびに索引を絞り込む（IME変換中は動かず、確定してから1回だけ絞り直す） |
| `Esc` | **索引（INDEX）へフォーカスを戻す。絞り込みはそのまま残る** |
| `Enter` | Escと同じ。索引へ戻り、絞り込みは残る |
| 空にする | 絞り込みを解き、索引が元に戻る |
| 欄の右端の `×` をクリック | 語を空にして絞り込みを解く（「空にする」と同じ経路。絞り込み中だけ出る・#86） |
| `Ctrl+S` | 共通の保存。欄は開いたまま、絞り込みも残る（#67 で「開いている入力面も閉じない」に揃えた） |
| `F1` / `Ctrl+P` / `Ctrl+N` | 「どこにいても」の操作。ヘルプ・コマンド一覧・新しい無題。Escで欄へ戻る |
| `/` `?` `n` `N` `:` | 普通の文字入力。検索やコマンドの操作にはならない |

検索欄の外枠は空のときから表示する（#340 / ADR0051）。絞り込み中は**欄の右端に `×` が出て**、
**カテゴリ見出しの右の数が「一致 / 総数」**（例: `3 / 128`）になる。
解けると `×` が消え、数は総数だけに戻る。Esc / Enter の振る舞いは変えていない。

対象は**全ノートの名前と本文**で、本文はこの欄に最初に文字を入れたときに1回だけ読む（起動は遅くならない）。
以後は保存・新規・改名・移動でその写しだけを入れ替える。読めなかったノートは一致しない（理由は出さない）。
一致はASCIIの英字だけ大小を無視する部分一致で、全角／半角・かな／カナは区別する。正規表現は#41の範囲。
一致を持つカテゴリは折り畳んでいても展開して並び、一致しないノート行とカテゴリは索引から消える。
**絞り込んでいるあいだは、並び替え（ドラッグ）とカテゴリの折畳／展開（`h` / `l`・クリック）ができない。**
**カテゴリ行のクリックと `h` / `l` は失敗を出さずに何もしない**（ドラッグと同じ無音の拒否）。
掴んで動かしたあとに離しても、その行を選び直したりはしない。
色の変更・閲覧・編集・保存・新規・別名保存・名前変更はそのまま使える。
**一致を見るのは保存済みの本文**。名前付きノートの編集から検索欄へ移ると、本文を先に保存する（#342）。
変更がなければファイルも履歴も書き直さない。保存できなければ本文へ戻り、未保存の内容とUndoを保つ。
UNTITLEDは保存先を尋ねず検索へ進み、検索対象には入らない。`×`も先にfocus時の保存を通し、失敗時は検索語を消さない。
開いている本文は一致しなくても閉じない。右ペインもモードも変わらず、索引に行が無いので選択の面だけが見えなくなる。
語は保存せず、起動のたびに空から始まる。

## 保存と終了

| コマンド | 動作 |
| --- | --- |
| `:enew` | 新しい無題を開く。名前付きの編集は先に保存。無題は保存／保存しない／キャンセルを選ぶ |
| `:w` / `:write` | 現在の本文を保存。無題なら名前入力を開く。モードを保つ |
| `:w 名前` / `:write 名前.md` | 無題を現在の文書カテゴリへ初回保存。名前の途中の空白は保持。名前付きの本文には使わない |
| `:saveas` / `:saveas 名前.md` | 現在本文を新しいノートへ保存して開く。引数なしは名前・カテゴリ入力へ |
| `:rename` / `:rename 名前.md` | 現在ノートのmdと履歴を新しい名前へ移す。引数なしは名前入力へ。F2も同じ |
| `:q` / `:quit` | 保存済みなら終了。未保存の変更があれば拒否 |
| `:wq` / `:x` | 保存できた場合だけ終了 |
| `:q!` | 現在の未保存変更を破棄して終了。保存済みの内容や履歴を巻き戻す操作ではない |
| `:help` / `:h` | 共通の操作一覧と説明 |
| `:startinsert` | 現在ノートを編集し、本文へ。既に編集中なら本文とUndoを維持 |

`:e`はVimのファイルを開く・読み直す操作なので編集開始には使わない。「保存して閲覧」はGUI専用。

右上の×と `Alt+F4` は通常終了。無題なら保存／保存しない／キャンセルを選ぶ。
名前付きは保存後に終了し、保存に失敗したらアプリと本文を残す。
「保存して終了」と`:wq` / `:x`は明示保存のため、保存しない選択を出さない。

新規のカテゴリは索引カーソル→開いている文書→最初のカテゴリの順で選ぶ。カテゴリが0件なら理由を表示する。
無題は空でも未保存なので`:q`を拒否する。
別ノート・次の新規・通常終了へ進むときは、名前入力面で次を選べる（#298 / ADR0050）。

| 選択 | 結果 |
| --- | --- |
| 保存 | 名前とカテゴリを指定し、保存成功後に元の操作へ進む |
| 保存しない | 現在の無題のファイルを作らず元の操作へ進む。切替先の読取・表示準備に失敗したら無題を保つ |
| キャンセル / Esc / ダイアログの× | 元の操作を止め、本文とUndoを保つ |

名前欄・カテゴリ一覧でのEnterは保存。Tabで各ボタンへ移した後のEnter/Spaceはそのボタンを選ぶ。
明示保存（Ctrl+S・`:w`・別名保存）と、本文Esc・「保存して閲覧」は保存専用である。
日本語と途中の空白を使え、`.md`は自動補完する。同名・Windows予約名・末尾の空白やピリオドは拒否する。
名前全体は拡張子を含め255 UTF-8バイト以内。保存名の面では失敗理由を表示し、入力を残して修正できる。
mdを作成できても索引台帳の保存に失敗した場合は名前付きの本文を保持して通知する。次の保存で台帳を再試行し、
未同期のまま切替や`:q`へ進まない。初回は履歴を作らず、以後の保存は既存の履歴を残す。

別名保存では元ファイルと履歴を最後の保存状態に保つ。閲覧中はMarkdown原文、編集中は未保存本文を新ノートへ保存する。
編集中に保存してもUndoは残り、モードは変えない。同名へ上書きせず、取消・公開前失敗は元ノートを保持する。
公開後の台帳失敗は新ノートを保持して通知し、閲覧中も`:q`は拒否、`:w`や通常保存は台帳を再試行する。

名前変更は編集中なら先に保存してから、mdと履歴ディレクトリを新しい名前へ移す。本文・モード・Undoは変えない。
同じ名前は何もせず、大小文字だけ違う名前と既存の名前は拒否する。カテゴリは変えられない（移動はドラッグのまま）。
移動先のmdまたは履歴が既にあれば断り、ローカルNTFS以外・シンボリックリンク／junctionを含む場所も断る。
OneDriveやDropboxがファイルに付けるプレースホルダ（name surrogateでないタグの再解析ポイント）は
通常のファイルとして扱う（#61）。断った場合は何も変わらない。
記録（`data/.rename.json`）を公開した後で止まったときは、パンくずが「名前変更の復旧待ち」になり、
保存・切替・並替・新規・別名保存・終了確認が先に同じ名前変更を再試行する。入力面の「キャンセル」では取り消せない。
`:q!`で閉じても記録は残り、次回の起動が続きを行う。復旧できない記録があるあいだは起動しない。

同じ`data/`を2つのNeNe Folioで開くことはできない。`data/`に書けない場所（読み取り専用など）は閲覧のために起動し、
保存や名前変更はそのつど理由を出して断る。

## 置換の欄（正規表現・#41）

| キー・操作 | 動作 |
| --- | --- |
| 「操作」→「置換」・Ctrl+Pの一覧の「置換」 | 下端に置換の欄を開く。モードは変えない（閲覧中は理由の1行が出るだけ） |
| 文字入力 | どちらの欄でも、打つたびに一致を数え直して「対象名 / k 件」を出す（IME変換中は動かず、確定してから1回だけ） |
| `Tab` | パターンの欄と置換文字列の欄を往復する |
| `Enter` / 「1 件」 | いまの選択以降で最初の一致（無ければ先頭から巡回）を1件だけ置き換える。**欄は開いたまま** |
| `Ctrl+Enter` / 「すべて」 | 全部の一致を1回で置き換える。キャレットは先頭へ戻り、読んでいた論理行は保たれる。**欄は開いたまま** |
| `Ctrl+S` | 共通の保存。**欄は開いたまま**で、2つの欄の語も選択も変わらない（#67） |
| `Esc` | 欄を閉じ、開く前の区画へ戻る |

IME変換中の「1 件」「すべて」のクリックは無視する。本文・下見・状態行・フォーカスを変えず、確定後の実行を予約しない。
確定後は下見を取り直し、改めて押した操作だけを適用する（#226）。

対象は**編集中の本文だけ**で、閲覧中に開くと「編集モードではありません。」の1行が出て本文は変わらない。
置換は `EM_REPLACESEL` 1回なので**Undo 1単位**で、Ctrl+Zで元に戻る。mdは書かないので、保存は従来どおりCtrl+Sか編集を抜ける操作。
大小無視は**パターンの中の `(?i)`** で指定する（チェックボックスは無い）。これはUnicodeのfull case foldingなので、
`ａ`と`Ａ`・`ß`と`SS`も一致する。**ノート内検索（Ctrl+F）の「ASCIIの英字だけ大小無視」とは意味が違う。**
`^` と `$` は行ごとに一致し（`(?m)` 相当を常に付けている）、`.` は改行に一致しない。
利用者が打つ `\n` はパターンでは改行に一致しない（`\r` か `\R` か `\s` を使う）。

置換文字列の文法はVim寄りで、ICUの `$1` 形式ではない。

| 書き方 | 意味 |
| --- | --- |
| `&` / `\0` | 一致した全体 |
| `\1`〜`\9` | 群1〜9（参加しなかった群は空）。10個目以降の群は参照できない |
| `\r` / `\n` | 改行（段落区切り） |
| `\\` / `\&` / `\/` | `\` / `&` / `/` そのもの |
| `$` | 普通の文字（ICUの群参照にはならない） |

これ以外の `\x` と末尾の単独の `\` は「置換文字列の書き方が違います」で断り、本文は変えない。
一致が多すぎる・時間がかかりすぎる・置き換えた本文が大きすぎるときも、理由の1行を出して本文は変えない。
パターンの書き方が違うときは、理由の1行の末尾に「位置 N」（1起算）が付く。
**理由の1行が出ているあいだは、EnterもCtrl+Enterも「1 件」「すべて」も本文を変えない**
（打ち直して件数が出てから当てる）。**下見と違う本文（別のノートへ切り替えた・本文が変わった）にも当たらない**
（どちらも「本文か入力が変わったので、この置換は当てられません。もう一度入力してください。」の1行）。
`Enter`（1 件）が探し始めるのは**いまの選択の開始以降**の最初の一致で、
ノート内検索の `/` が選択の**次**から探すのとは 1 文字ぶん違う（同じ一致をもう一度置き換えられる）。
**ゼロ幅の一致（`x*` など）を空文字列で置き換える「1 件」は本文も選択も変わらない。**
特別扱いはしない（Vimの `:s/x*//` も同じ）ので、そのときは「すべて」を使う。
置換の直後はフォーカスが欄にあるので **Ctrl+Zは欄の取り消し**になる。本文を戻すにはEscで本文へ戻ってからCtrl+Z。
パターンと置換文字列は保存せず、起動のたびに空から始まる。Ctrl+Hは割り当てない。

### Ex の `:%s`

| コマンド | 動作 |
| --- | --- |
| `:%s/パターン/置換/g` | 欄を開かず、全部の一致を1回で置き換える |
| `:%s/パターン/置換/` | 欄を開かず、**各論理行の最初の一致だけ**を置き換える（Vimと同じ） |

区切りは `/` だけで、パターンと置換文字列の中の `\/` は区切りにならない。旗は `g` だけ。
区切りが足りない・パターンが空・知らない旗は、未知のコマンドと同じ1行で断り、入力は消えない。
1件以上置き換えたら他のExと同じく黙って閉じ、**0件ならExを閉じず「対象名 / 0 件」を出す**。
**`:s`（`%` なし・行の範囲）は意図して未対応**で、未知のコマンドと同じ1行になる。

## 原文の行番号（`:set`）

| コマンド・操作 | 動作 |
| --- | --- |
| `:set number` / `:set nu` | 編集中の本文の左に、md原文の論理行番号を出す |
| `:set nonumber` / `:set nonu` | 出さない |
| `:set number!` / `:set nu!` / `:set invnumber` / `:set invnu` | いまと逆にする |
| Ctrl+Pの一覧の「行番号の表示を切り替える」 | 同じ切替。`:set`自体は語を要るのでこの一覧には出ない |

語は空白で切った1語の完全一致で、未知の語・語なし・余計な語は未知のコマンドと同じ1行で断り、入力は消えない。
番号は**編集モードで文書があるときだけ**出る。閲覧（RTF）では表示行が原文の行に対応しないので出さない。無題の編集中は出る。
折り返しの継続行には番号を重ねず、空行と末尾の空行にも番号が付く。**本文には書き込まない**ので、保存・Undo・選択に混ざらない。
切り替えても本文・Undo・選択はそのままで、本文の矩形が動いたときは最初に見えていた論理行が戻る。
値は `data/settings.json`（版 2）に残り、次の起動でも同じ。**先に書いてから採用する**ので、表示と保存が食い違わない。

`data/`に書けないときは値を変えず理由を出す（**失敗の理由は箱ではなく欄の中の 1 行**・ADR 0031 の補正 D1）。設定ファイルが壊れていれば既定（非表示）で起動し、
理由を1回だけ出して、そのセッションは設定を変えず**上書きもしない**（人が直すか消すまで）。

## テーマ（設定画面と `:set theme=`）

| コマンド・操作 | 動作 |
| --- | --- |
| 頭の歯車（閉じるアイコンの左隣） | 設定画面を開く |
| Ctrl+P の一覧の「設定」 | 同じ面を開く |
| 設定画面の ← → | 同じグループの候補へ移る |
| 設定画面の ↑ ↓ | 通常幅は同じ列の前後グループへ、1列の狭幅は前後の候補へ移る。見出しは飛ばし、端で止まる |
| 設定画面の Tab | 次の候補へ移る。最後の行番号から最初のテーマへ戻る |
| 設定画面の Enter・Space・項目のクリック | テーマは候補一覧を開く。言語は採用、行番号は真偽を反転する。面は開いたまま |
| 設定画面の Esc・右上の× | 閉じて元の区画へフォーカスを返す |
| テーマ候補の検索欄 | 名前の部分一致。ASCII英字の大小を無視する。空欄で128候補を表示 |
| テーマ候補の ↑ ↓ / PgUp PgDn | 候補カーソルを1件 / 1ページ移動 |
| テーマ候補の Enter・候補クリック | 設定を書けた場合だけ採用。候補一覧は開いたまま |
| テーマ候補の Esc・戻る / 右上の× | 設定に戻る / 設定を閉じて元の区画へ戻る |
| `:set theme=<ID>`（例: `dracula` / `nord` / `system`） | 同じcatalogから欄を開かず直接採用。`light` / `dark`も保持 |
| `:set language=ja` / `:set language=en` / `:set language=zh-Hans` | 表示言語を変える。欄を開かず直接当てる（ADR 0032 の決定 7） |

設定画面は中央の独立した面にタイトル・×・輪郭を持ち、背後を暗くして操作を遮る（ADR0046）。
テーマは現在値と「テーマを選ぶ…」の入口を表示する。候補面はNeNeNibの125種類、Folioのlight/dark、systemを名前と色見本で示す（ADR0049）。
言語は3候補、行番号は1つのチェック操作で、キーボードの注目と採用済みの値を別に示す。
小さい窓では内容をスクロールして選択へ到達でき、タイトル・閉じる入口・案内・版番号は固定表示する。
CMakeから導出した製品版は読み取り専用であり、選択肢ではない（FR-014・ADR0045）。

設定画面でも Ctrl+S（保存）・Ctrl+N（新規）・Ctrl+P（一覧）と表のアクセラレータが届く。一般設定では文字は打てない（IMEも出ない）。テーマ候補面は検索欄へ入力でき、IME変換中は候補を採用しない。
既定は「OS に従う」で、そのあいだは OS のライト／ダークの切替へその場で追従する。
切り替えても**本文・Undo の段数・未保存の印・モード・スクロール位置**は失われない。
設定を読めないセッション（壊れた `settings.json` など）では、開いた瞬間から理由の 1 行が出て、採用は断る（上書きもしない）。

## 履歴（`:history` / `:hist`・パレット・「操作」）

| コマンド・操作 | 動作 |
| --- | --- |
| `:history` / `:hist` | 現在のノートの履歴の一覧を開く（ADR 0038 の決定 11） |
| 「操作」→「履歴から戻す」・Ctrl+P の一覧の「履歴から戻す」 | 同じ面を開く |
| 履歴の面の ↑ ↓・ホイール | 版を移る（巡回しない。端では止まる） |
| 履歴の面の Enter・行のクリック | その版の本文を**編集中の本文**へ流し込み、面を閉じて本文へフォーカスを移す |
| 履歴の面の Esc | 閉じて元の区画へフォーカスを返す |

行は「版番号  最初の行」で、**1 が最新**（`data/.history/<カテゴリ>/<ノート>/1.md`〜`5.md`）。最初の行は本文の最初の空でない論理行で、
時刻は出さない（ファイルにも無い・決定 16）。読めない版は「版番号  （読めません）」の行として出し、Enter は欄の 1 行で断る。
履歴が 1 本も無い・無題・ノートを選んでいないときは面を開かず、理由を 1 行で出す。

戻すのは**未保存の編集**で、md も履歴も書かない（決定 1）。閲覧中なら編集モードへ入ってから本文を丸ごと置き換える。
置き換えは Undo 1 単位なので **Ctrl+Z 1 回で戻す前の本文**へ戻る。確認の箱は出さない。カーソルは先頭・スクロールは 0。
保存すると、そのとき md にある本文（戻す前に保存されていた本文）が `1.md` に積まれる（ADR 0012 の決定 2 のまま）。

履歴の面でも Ctrl+S（保存）・Ctrl+N（新規）・Ctrl+P（一覧）と表のアクセラレータが届く。文字は打てない。
保存が済むと一覧は古くなるので面は閉じる。別のノートへ移る・別の面を開くときも面を閉じ、持っていた版は捨てる。

## カテゴリの作成（`:newcategory` / `:newcat`・パレット・右クリック）

| コマンド・操作 | 動作 |
| --- | --- |
| `:newcategory 名前` / `:newcat 名前` | 面を開かず、その名前のカテゴリを末尾に作る（ADR 0039 の決定 10・補正 2） |
| `:newcategory` / `:newcat`（名前なし） | 名前入力面（題「新しいカテゴリ」）を開く |
| Ctrl+P の一覧の「新しいカテゴリ」 | 同じ名前入力面を開く |
| ドロワーの「カテゴリ」見出しの＋ | 同じ名前入力面を開く。押して外で離した場合は取り消す |
| 名前入力面の Enter | 作る。使えない名前・同じ名前・フォルダを作れないときは面の中の 1 行で断り、面は残る |
| 名前入力面の Esc | 何も作らずに閉じる |

作れたら入力面を閉じ、新しいカテゴリ行へカーソルを置いて見える位置へ寄せ、フォーカスを索引へ返す。
開いている文書・本文・モード・選択は変えず、保存も走らせない（編集中でも本文・Undo・未保存の印が残る）。
`data/` が無ければ `data/` から作る。フォルダは作れたが `categories.json` を書けなかったときは、作った行を残したまま失敗の箱で 1 回知らせる。
Ex の名前が使えない・同じ名前・絞り込み中は、入力面の結果行で知らせる。
カテゴリ行やドロワーの空きの右クリックからも「新しいカテゴリ」を開ける（FR-038）。

## カテゴリ名の変更（`:renamecategory` / `:rencat`）

| コマンド・操作 | 動作 |
| --- | --- |
| `:renamecategory 名前` / `:rencat 名前` | カーソルのカテゴリ、無ければ現在文書のカテゴリを改名（ADR 0041） |
| `:renamecategory` / `:rencat`（名前なし） | 元カテゴリ名を全選択した名前入力面を開く |
| カテゴリ行の右クリック→「カテゴリ名を変更…」 | その行を対象に同じ名前入力面を開く。選択文書は変えない |
| 通常の名前入力面の Enter / Esc | 変更する／変更せず閉じる |
| 保留面の Enter / Esc | 同じ変更を再試行する／保留を取り消さず閉じる |

先行する名前変更が保留なら、その実kindの復旧面を先に開く。この間、今回頼んだ操作はまだ始めない。
固定された旧名→新名は読取専用で、Home／End、選択とコピーで全文を読める。
