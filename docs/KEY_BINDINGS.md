# キーバインドとコマンド

2026-09-13現在の操作表。`?`・コマンド・パレットはIssue #37 / Draft PR #44の追加で、配布版へはまだ反映していない。

## ヘルプを開く

INDEXにフォーカスがあるときの `?` と、コマンド入力の `:help` は同じヘルプを開く。
Ctrl+Pでも同じ一覧を開ける。一覧には実装済みのコマンドと、区画ごとのキーバインドを表示する。
本文や入力欄の `?` は文字として入力される。INDEXの文字キーはIMEを英数入力にして使う。

## INDEX（左の索引）

| キー | 動作 |
| --- | --- |
| `?` | ヘルプとコマンド一覧 |
| `:` | コマンド入力 |
| `Ctrl+P` | コマンド一覧 |
| `Ctrl+S` | 開いている本文を保存。編集モードは保つ |
| `j` / `k` | 次／前のノート、または折り畳んだ・空のカテゴリへ |
| `g` `g` / `G` | 最初／最後の行へ |
| `h` / `l` | カテゴリを折り畳む／展開する。カテゴリ行からの `l` は中のノートへ |
| `Enter` | ノートから本文へ。カテゴリ行では移動しない |
| `↑` / `↓` / `PgUp` / `PgDn` | 索引をスクロール。`j` / `k`のカーソル移動とは別 |
| `Esc` | 何もしない。アプリは閉じない |

別のノートを選ぶときは、編集中の本文を保存してから切り替える。保存できなければ切り替えない。

## 本文（右のペイン）

| キー | 動作 |
| --- | --- |
| `Ctrl+P` | コマンド一覧。開くだけでは保存せず、本文を保つ |
| `Ctrl+S` | 本文を保存。編集モードは保つ |
| `Esc` | INDEXへ戻る。編集中なら保存し、編集モードは保つ。保存失敗なら本文に留まる |

## コマンド一覧・コマンド入力

| キー | 動作 |
| --- | --- |
| 文字入力 | 一覧では名前・別名で絞り込む。コマンド入力では命令を書く |
| `↑` / `↓` | 一覧の候補を選ぶ |
| `Enter` | 選んだ操作、または入力した命令を実行 |
| `Esc` | 入力面を閉じ、開く前の区画へ戻る。保存しない |
| `Ctrl+P` | 同じコマンド一覧へ切り替える |

IME変換中のEnterは変換確定に使い、操作実行に使わない。本文内の `:` と `?` は命令にならない。

## 保存と終了

| コマンド | 動作 |
| --- | --- |
| `:w` / `:write` | 現在の本文を保存。モードを保つ |
| `:q` / `:quit` | 保存済みなら終了。未保存の変更があれば拒否 |
| `:wq` / `:x` | 保存できた場合だけ終了 |
| `:q!` | 現在の未保存変更を破棄して終了。保存済みの内容や履歴を巻き戻す操作ではない |
| `:help` | コマンドとキーバインドの説明 |

右上の×と `Alt+F4` は保存して終了する。保存に失敗したらアプリと本文を残す。

行番号の `:set number`、`/`検索、正規表現置換は今後の追加項目。実装時にこの表と画面内の説明を更新する。
