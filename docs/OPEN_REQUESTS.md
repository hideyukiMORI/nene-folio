# 外のプログラムからノートを開く・ノートを書く

LLMのエージェントやスクリプトなど、NeNe Folioの外のプログラムのための決まりです。
次の版に含まれる機能（#1069・#1070・#1071）です。公開済みの1.5.0には含まれません。

できることは2つです。

- **開いて見せる**: 指定のノートを開いて、指定の箇所を選ぶ。リンクか、依頼のファイルで頼みます。
- **ファイルを書く**: `data/<カテゴリ>/<ノート>.md`を、ふつうのファイルとして書く。NeNe Folioが気づいて読み直します。

NeNe Folioの側に、ノートを作る・書く・消すための口はありません。開いたかどうかを返す仕組みもありません（画面で分かります）。
通信のポートも開けません。やりとりは、起動の引数と、dataフォルダの中のファイルだけです。

以下の`data/`は、ノートの保存先のフォルダそのものです。場所は、設定の「ノートの保存先…」の「現在の保存先」で確かめられます。
ZIP版の既定は、実行ファイルの隣の`data/`です。WSLからは`/mnt/c/…`の形で同じフォルダに届きます。

## どちらで開くか

| 道 | 向いている場面 |
| --- | --- |
| 依頼のファイル | Windowsの実行ファイルを起動できない書き手（WSLの中のエージェントなど）。NeNe Folioが動いていても、いなくてもよい |
| リンクを引数にして起動 | Windowsの側で動くプログラム。NeNe Folioが動いていなければ起動する |

リンクをクリックして開くための登録（`nenefolio://`をWindowsに関連づける）は、まだありません。Store版で予定しています。ZIP版は登録しません。

## 依頼のファイルで開く

`data/.requests/`に、名前が`open-`で始まり`.json`で終わるファイルを置きます。`.requests`フォルダが無ければ作ります。

```json
{"version":1,"action":"open","category":"仕事","note":"議事録","lines":"3-8","text":"決定事項"}
```

| 欄 | 必須 | 値 |
| --- | --- | --- |
| `version` | 必須 | 数の`1` |
| `action` | 必須 | 文字列の`"open"` |
| `category` | 必須 | カテゴリの名前（dataの下のフォルダの名前） |
| `note` | 必須 | ノートの名前。`.md`は付けても付けなくてもよい |
| `lines` | 任意 | 文字列。`"12"`か`"3-8"`（1から数える。始まりは終わり以下） |
| `text` | 任意 | 探す文。1024バイトまで |

- ファイルはUTF-8で、全体で64KiBまで。JSONのオブジェクト1つだけを書きます。
- 値はJSONの文字列そのままです。リンクのような`%`の符号化はしません。
- 値に、制御文字と改行は置けません（JSONの`\n`や`\u0000`で書いても同じです）。
- 知らない欄があっても、読み飛ばします。知っている欄を2回書くと、正しくないものとして扱います。
- カテゴリとノートの名前は、ASCIIの英字だけ大小を問わずに探します。

### 置いた後に起きること

- NeNe Folioが動いていれば、0.3秒ほどで気づきます。動いていなければ、次に起動したときに見ます（そのときも、更新から5分より古いものは開かずに消します）。
- ノートが閲覧表示で開き、箇所が選ばれ、窓が前面へ出ます（Windowsの決まりで、タスクバーが光るだけのこともあります）。
- 処理したファイルは、NeNe Folioが消します。置く側が消す必要はありません。
- 複数あるときは、更新の古い順に1つずつ開きます。
- 設定などの面やダイアログが開いている・文字の変換の途中・ドラッグの途中は、ファイルを残したまま待ち、終わってから開きます。
- 利用者が本文を編集していて、保存していない変更があるときは、**すぐには開きません。利用者に、どうするかを聞く面が出ます**（次の版から）。
  - 選べるのは3つです: 「保存して開く」／「別の名前で残して開く」（編集中の本文を`1_元の名前`という新しいノートとして保存し、元のノートのファイルは変えません）／「開かない」。
  - 「開かない」を選ぶと、その依頼は取り消されます（依頼のファイルは、読んだ時点で消えています）。要るなら、もう一度置いてください。
  - 面が出ているあいだに置いた依頼は、利用者が答えた後に、**いちばん新しい1つだけ**が扱われます。続けていくつも置いても、古いものは開かれません。
  - 利用者が席を外していると、答えるまで開きません。依頼を置いた側は、開いたかどうかを知る方法がありません。
  - 保存していない変更が無ければ、聞かずに開きます。無題の下書きがあれば、名前の入力が出ます。

### 開かずに消されるファイル

次のものは、何も知らせずに消されます。

- JSONとして正しくない、オブジェクトでない、必須の欄が無い、`version`が`1`でない、`action`が`"open"`でない。
- 名前の規則に合わないカテゴリやノートの名前（`..`、区切りの文字など）。
- 64KiBを超える。
- **更新の日時が5分より古い。** 日時は、ファイルの更新の日時と、NeNe Folioの動いているPCの時計で比べます。
- UTF-8でない。Windows PowerShell 5の`>`や`Out-File`の既定はUTF-16なので、消されます。

一覧に無いカテゴリやノートを指した依頼は、消されたうえで、NeNe Folioの画面に1行「リンクのカテゴリが見つかりません。」などが出ます。

`open-*.json`に当たらない名前のファイルと、フォルダには触りません。

### 確実な書き方

**別の名前で書き終えてから、すぐ`open-*.json`へ名前を変えます。** 書いている途中の形を読まれません。

- 途中の名前は、`open-*.json`に当たらないものにします（例: `.tmp-1234`）。
- 同じフォルダの中で名前を変えます。
- 5分の規則は更新の日時で見るので、書いてすぐ名前を変えます。古い日時のまま写したファイル（`cp -p`など）は消されます。
- 名前は、ほかの依頼と重ならないものにします（時刻や連番）。

保存先の場所は例です。自分の「現在の保存先」に読み替えてください。

bash（WSLなど）:

```bash
requests="/mnt/c/Users/<あなた>/NeNeFolio/data/.requests"
mkdir -p "$requests"
name="$(date +%s%N)"
printf '%s' '{"version":1,"action":"open","category":"仕事","note":"議事録","lines":"3-8"}' \
  > "$requests/.tmp-$name"
mv "$requests/.tmp-$name" "$requests/open-$name.json"
```

PowerShell 7:

```powershell
$requests = "$env:USERPROFILE\NeNeFolio\data\.requests"
New-Item -ItemType Directory -Force $requests | Out-Null
$name = [DateTime]::UtcNow.Ticks
$json = '{"version":1,"action":"open","category":"仕事","note":"議事録","text":"決定事項"}'
[IO.File]::WriteAllText("$requests\.tmp-$name", $json)
Rename-Item "$requests\.tmp-$name" "open-$name.json"
```

`[IO.File]::WriteAllText`は、PowerShellの版によらずUTF-8（署名なし）で書きます。

## リンクを引数にして開く

```text
NeNeFolio.exe "nenefolio://open?category=仕事&note=議事録&lines=3-8&text=決定事項"
```

- 同じdataで動いている窓があれば、そこへ渡して、この起動は終わります。無ければ起動してから開きます。
- `category`と`note`は必須、`lines`と`text`は任意です。意味は依頼のファイルと同じです。
- 値は、UTF-8を`%`で符号化します（上の例は読みやすさのためにそのまま書いています。空白や`&`、`#`、`%`を含む値は必ず符号化します）。`+`は空白になりません。
- キーは小文字です。同じキーを2回書くと、正しくないものとして扱います。知らないキーは読み飛ばします。
- リンク全体で2048バイトまで。
- 面が開いている・ほかの操作の途中は、開かずに、画面に1行で知らせます。もう一度渡してください。
- 形が正しくないリンクも、画面に1行で知らせます。

## 箇所の選ばれ方

閲覧表示で、段落を単位に選びます。

1. `text`があれば、`lines`のあたり（前後5行）で探します。
2. 無ければ、ノート全体で探します。
3. それも無ければ、`lines`の段落を選びます。
4. `lines`も当たらなければ、ノートを開くだけです。

`text`は原文（Markdown）の中の文字の並びとして探します。指定と違う所を選んだときは、画面の1行でそう知らせます。
`lines`だけなら、その行の段落を選びます。行の番号は原文の行で、1から数えます。

## ノートのファイルを外から書く

`data/<カテゴリ>/<ノート>.md`は、ふつうのテキストのファイルです。外のプログラムが作っても、書き換えても、消してもかまいません。

- UTF-8で書きます。1つのノートは16MiBまでです。
- 新しいカテゴリは、`data/`の下にフォルダを作ります。名前が`.`で始まるフォルダは、カテゴリになりません。
- 外で足した・消したノートやカテゴリは、NeNe Folioが動いていれば0.3秒ほどで一覧に出ます（ほかのアプリから戻ったときにも確かめます）。
- 開いているノートを外で書き換えると、閲覧表示なら読み直して、読んでいた位置を保ちます。
- **利用者が編集している最中のノートを外で書き換えた場合**: 編集中の本文はそのままで、画面に1行で知らせます。その後の保存は、外で変わったファイルを上書きせずに止まります。利用者は「名前を付けて保存」か「編集を破棄して読み直す」を選びます。外の版が黙って消えることも、利用者の編集が黙って消えることもありません。
- `index.json`（ノートの順と星）、`categories.json`、`settings.json`、`.history/`、`.rename.json`、`.nenefolio.lock`は、NeNe Folioのものです。書き換えないでください。順や星を付けたいときも、`.md`だけを置けば、一覧の末尾に出ます。
- 書いた直後に開いて見せたいときは、`.md`を書き終えてから、依頼のファイルを置きます。

## 気をつけること

- 依頼のファイルを置けるプログラムは、NeNe Folioの窓を前面へ出し、開いているノートを切り替えられます。利用者が頼んだときにだけ置いてください。
- できるのは、一覧にあるノートを開くことと、箇所を選ぶことだけです。依頼やリンクで、ファイルが作られたり、書き換わったり、消えたりすることはありません（処理した依頼のファイルそのものは消えます）。
- 結果は返りません。開けなかった理由は、利用者の画面の1行にだけ出ます。
