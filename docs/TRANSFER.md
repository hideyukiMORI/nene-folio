# Markdownの取り込みと書き出し

1.1.0に含まれる機能（#494）。0.3.0 betaと先に申請した1.0.0 Store候補には含まれません。

## 外部のMarkdownを取り込む

1. 取り込み先のカテゴリを右クリックし、「このカテゴリへMarkdownを取り込む…」を選びます。
2. Windowsのファイル選択で、UTF-8の`.md`を選びます。複数のファイルを同時に選べます。
3. 追加した数、同名でスキップした数、未処理の数が表示されます。

元ファイルを残したまま、選んだカテゴリへ追加します。同名のノートは上書きしません。
ファイル名からノート名を付けるため、名前を変えて取り込みたい場合は元ファイルのコピーに別名を付けてください。
検索で一覧を絞り込んでいる間は、検索を解除してから取り込みます。

ファイルを読めない、不正なUTF-8を含む、ノートを保存できないなどの問題があれば、その位置で停止します。
すでに追加したノートは残ります。原因を直して同じファイルを選び直すと、追加済みの同名ノートはスキップします。
取り込み中も、開いているノートの編集内容・選択・Undo・未保存の印は保ちます。

## ノートを書き出す

「操作」メニューまたはCtrl+Pの操作一覧から選びます。カテゴリのZIPは、そのカテゴリの右クリックからも選べます。

| 操作 | 書き出す内容 |
| --- | --- |
| このノートを書き出す… | 1枚のMarkdown原文。編集中なら未保存の内容を含む。無題のノートも可能 |
| 保存済みカテゴリをZIPに書き出す… | 対象カテゴリに保存してあるノート |
| 保存済み全ノートをZIPに書き出す… | すべてのカテゴリに保存してあるノート |

書き出し先に同名のファイルがある場合は上書きせず、別の名前を選ぶよう知らせます。
書き出しても元ノートの保存・名前変更・選択変更は行いません。未保存の印も消えません。
「別名で保存…」は新しいノートを作って開く操作なので、書き出しとは異なります。

ZIPは`カテゴリ名/ノート名.md`の構成で、検索による表示の絞り込みには依存しません。
空カテゴリは含みません。対象ノートが0枚の場合は空のZIPを作ります。
**ZIPには未保存の編集内容、カテゴリの色や順序、設定、履歴を含みません。** 完全なバックアップや復元用の形式ではありません。
1枚でも読めないノートがあれば、不完全なZIPを出力せず理由を知らせます。

## 範囲と制限

- 取り込みはUTF-8 Markdownだけです。ZIPの取り込みには対応していません。
- 1枚の本文は通常のノートと同じ16 MiBまでで、埋め込みNULを含む本文は拒否します。
- UTF-8の先頭署名（BOM）は通常のノートと同じ規則で読み飛ばし、通常はBOMなしで書き出します。本文と改行を保持しますが、元ファイルのバイト列を丸ごと複製する形式ではありません。
- ZIPは無圧縮で、65,534ファイル・完成サイズ128 MiBまでです。処理中は同期して読み書きするため、大量のノートでは待ち時間とメモリ使用量が増えます。
- ファイル選択の取消では何も追加・出力しません。公開前に書き込みが失敗した場合、途中の出力を完成ファイルとして残しません。

契約と実装境界は[ADR0082](adr/0082-markdown-transfer.md)、確認範囲は[品質記録](quality/2026-11-01-markdown-transfer.md)を参照してください。
