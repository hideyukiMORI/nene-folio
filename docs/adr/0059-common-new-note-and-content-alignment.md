# ADR 0059 — 新規ノートを共通ヘッダーへ集約し、本文操作列を36pxの基準へ揃える

- 状態: 受理（2026-10-18、hideの推奨案への反映指示に基づき実装前に判断を固定）
- 日付: 2026-10-18
- Issue: [#344](https://github.com/hideyukiMORI/nene-folio/issues/344)
- 規則: FR-029/034/039、ARC-001/004/011、C-002/008/012/017/018、QLT-008/012/013
- 関連: ADR0017/0026/0033/0047/0048/0051/0056

## 文脈

新規ノートはドロワー先頭と本文操作列に重複している。パンくず・通常本文はペイン左から36 logical px、
操作列は8で、125%表示では操作列が35物理px左へ張り出す。hideがヘッダー移設と整列について相談を依頼した。
情報設計・視覚デザイン・Windows操作の3つの専門家ペルソナによる独立レビューは、ヘッダー左への集約と
本文操作列の整列を支持した。実在専門家への取材ではない。320 logical pxの一覧窓では文字付き新規は収まらず、
アイコン化と一段下への移動で意見が分かれた。hideの反映指示を受け、位置を保つ前者を採用する。

## 決定

1. 新規ノートの常設入口を共通ヘッダー左へ一つに集約する。ドロワーの40px新規帯と本文操作列の新規を撤去する。
   右側の表示3択・設定・閉じるとヘッダー高44は維持する。左12、ボタン高32、紙と追加記号の24px図形を使う。
   新規の幅は現言語の文字実測と図形・余白から決め、右側の表示群まで24 logical px以上の空白を残せない場合は幅32の図形だけへ縮める。
   320幅でも同じ左位置を保ち、表示群の左端72との間に28pxの移動領域を残す。ブランドと「表示」の補助文字は余白がある場合だけ描く。
2. 図形は既存icon_paintの24 viewBoxの面のパスに加え、紙と追加記号を組み合わせてカテゴリ追加の単独＋と区別する。
   通常はthemeのdialog_control/dialog_border/category_text、押下時はselectedの対、高コントラストの縁はcategory_text。
   新規の描画・mouseの押下/解放・capture取消・hit test・tooltip・focus印・UIA Boundsは同じ矩形を使う。
   狭幅でも標準tooltipに3言語の「新しいノート」とCtrl+Nを示す。別のtooltip実装や依存を追加しない。
3. 新規のUIA親を共通ヘッダーへ移し、Name/Button/Invokeは維持する。旧本文側要素を削除し、TabとUIA列挙は新規→表示群→設定→閉じる。
   F6のヘッダー入口は新規、索引入口は検索欄とする。既存のmodal/IME/本文投入/終了中の抑止を使う。
   純粋なfocus移動は既存契約のまま。検索欄へのfocusは#342/ADR0024の名前付きEDIT保存・UNTITLED質問なしを適用する。
   新規実行は既存NEW→new_note_atの一経路へ渡す。
4. 本文操作列は保存・操作・ヘルプ・収まる場合のノート内検索を持ち、各ボタン外形の始点を固定36 logical pxへ揃える。
   パンくず・通常本文と共通の基準とし、ボタン文字の内側8pxは残す。行番号の桁が増えても上部の基準は動かさない。
   先頭の新規撤去で空く幅を使うため、最小幅でも保存・操作・ヘルプを保てる。
5. カテゴリ右クリックの「このカテゴリに新しいノート」、Ctrl+N、Ex、操作メニュー、パレットは維持する。
   作成先・無題の離脱確認・保存/取消・成功後だけ一覧から両方へ広げる契約はADR0050/0051のまま。
   新規ボタンを押して外へ離すかcaptureを失った場合は作成しない。

本ADRはADR0051の常設入口・40px帯・固定ボタン種別、ADR0047/0048の共通ヘッダー構成と狭幅移動領域、
ADR0056の新規要素の親を補正する。その他の作成・保存・表示切替・provider寿命の契約は維持する。

## 検証と限界

完成候補のDebug/tidyと文言unit、隔離した所有fixtureのWin32で3表示・3言語・通常/最小幅・120/144/168 DPIの
矩形/画像、押下/解放/取消、drag領域、tooltip、F6/TabとUIA Name/親/Bounds/Invokeを対象確認する。
無題の取消で本文/Undo/表示/窓幅が変わらないことを確かめる。既存の保存・本文RTF・検索性能の試験は再実行しない。
対象結果を最終headへ再利用し、必須CI後に統合する。schema・依存・ゲート変更なし。Waivers: none。

## 2026-10-18 の補正（#348）

[ADR0060](0060-ui-part-styles-and-state-rule.md)で決定1の新規の高さ32を28へ、ブランドとの間24を16へ補正する。
決定4の本文操作列は1つのA群（1px区切り）とし、狭幅では「このノート内を検索」→「保存」の順に絵だけへ縮めて消さない。
左端36の基準、新規の位置、押して外へ離すかcaptureを失えば作成しない契約は維持する。閲覧/編集の札は位置を変えずS選択群へ揃える。
