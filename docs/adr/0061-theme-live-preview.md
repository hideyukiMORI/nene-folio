# ADR 0061 — テーマ候補を即時にプレビューし、明示的な確定だけ保存する

- 状態: 受理
- 日付: 2026-10-24
- Issue: #366
- 規則: ARC-001/004/008/011、C-005/012、QLT-008/009/012/013
- 補正: ADR0031/0049の表示と確定の同時性、ADR0060のテーマ候補操作。保存の原子性とADR0057のOS外観優先を維持する。

## 根拠

hideは候補へカーソルを移した時点で、実際の画面全体の配色を一時的に確認できることを求めた。
採用印と候補枠だけでは結果が分からない。既存のpalette/RTF採用と再着色を使ってプレビューする。

## 決定

1. 保存済みのテーマは既存`folio_settings`だけが所有する。applicationが持つ表示choiceは一時的な候補を含み、
   `folio_state_theme_choice`は保存済み値を返す。取消のための設定コピーや開始時のスナップショットは作らない。
2. `folio_state_preview_theme`は設定やファイルを書かず、既存snapshotからpaletteを解決する。
   配色が変わるときだけRTFを準備し、成功時にpalette/RTF/表示choiceを一緒に採用する。失敗時は全て保持する。
   OS外観更新も同じ非永続palette採用を使う。HC中も表示choiceは更新し、解除後にその候補を解決する。
3. 候補の矢印・ページ移動・wheel・実際のpointer移動・UIA Focus/Selectは同じプレビューへ合流する。
   スクロールによる一時的な添字変更や、動いていないpointerの合成MOVEでは候補を戻さない。
   検索変更は先頭候補をプレビューし、0件なら保存済み配色へ戻す。IME変換中は既存候補を保つ。
4. Enter/クリック/UIA Invokeだけが既存`folio_state_set_theme`へ渡して保存する。
   保存失敗なら採用印と保存値を保ち、候補のプレビューと失敗理由を残す。成功後も一覧は開いたまま。
   同じ保存値の確定は書かずに表示をその値へ戻す。Ctrl+Sは本文だけを保存し、テーマを確定しない。
5. Esc/戻るは設定へ1段、×は設定全体を閉じ、その前に直近の保存済みテーマへ戻す。
   他の面や文書操作へ移る場合も復元を先に行う。RTF準備失敗またはnative再着色pendingが残れば面を閉じず、
   既存の面内通知を残して再試行可能にする。同じpaletteでもpendingなら再着色を再試行する。
   通常終了では未確定テーマを書かず、終了取消では面と候補を維持する。
6. 全体の色反映は既存`recolor_window`/`recolor_pane`だけを使う。dirty・Undo・選択・表示論理行とnative EDIT focusを保つ。
   設定以外のファイルをプレビューで書かない。開く際の検索初期化は候補通知より先に済ませ、別候補の一瞬の表示を防ぐ。

## 確認

applicationのpreview/確定/取消/書込失敗/確保失敗、HC中の移動と解除を対象unitで確認する。
native fixtureで入力経路・全体色・保存値・本文状態の保持・切替時間を確認する。
最終PR headの必須CIで正典`eng/check.ps1`を要求する。schema・依存・ゲート変更なし。Waivers: none。

## 採らない案

- 候補移動のたびに設定を保存する: 取消に再書込が必要となり、試す操作が永続化される。
- 開始時のRTF/設定をコピーして戻す: 本文保存やOS外観更新後に古い状態へ戻る別の所有者ができる。
- 一覧だけ独自の色描画を使う: 本文・ドロワーと異なる反映経路になり、実際の結果を確認できない。
