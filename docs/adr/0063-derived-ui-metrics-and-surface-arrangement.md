# ADR 0063 — 固定UIの計測を所有者に保持し、面の確定後に一度だけ配置する

- 状態: 受理（#373の実装前判断）
- 日付: 2026-10-25
- Issue: [#373](https://github.com/hideyukiMORI/nene-folio/issues/373)
- 規則: ARC-001/004/005/007/011/012、C-008/012/016/017、QLT-008/012/013
- 関連: ADR0060/0062。GDIによる実測と描画、文字の保持、固定理由高、UIAの意味を維持する。

## 根拠

hideは#368統合後の実機試用でも、設定・モーダルの表示が毎回重いと報告した。
main60a564aの外部fixtureで、日本語・行番号ON・monalisa、3カテゴリ/6合成ノート/合計347bytesのDebug条件を測った。
設定openの8回中央値は21.05ms、close16.35ms。openの直接dispatch約4.05msに対し、その後のpaint/UIA処理が約16.95msだった。
設定openで配置が3回、固定操作ラベル幅の計測が60回。native名前面は66件の理由を毎回測り、当該計測は約19.19msだった。
独立した統計値の和を総時間とはしない。専用非入力desktopのCPU/message/paint測定であり、実display呈示の保証ではない。
証跡は `D:/NeNeFolio/agents/gui-responsiveness-20261025/performance/` に置く。

NeNeNib main605f21f9の `Direct2DRenderer::status_text_layout` は、文字・書式・領域の同一性で配置を再利用し、色だけでは作り直さない。
この入力と派生計測を分ける考えを採り、Folioの描画backendを変更する根拠にはしない。

## 決定

1. 固定操作ラベルの幅は `folio_window` が所有する派生計測として保持し、描画・hit・tooltip・UIAが同じ値を読む。
   正典の `measure_utf8` とGDI/font-link/字間規則で求める。対象ID、言語、font/DPI/字間が同じ間は再計測しない。
   font再生成ではHFONTの値が再利用されても必ず失効させる。言語/DPI/字体が変われば新しい入力で準備し、失敗した値を成功cacheとして固定しない。
   文書名・本文・動的結果を固定文言のcacheへ混ぜず、必要のない全ui_text表の一括計測も行わない。
2. 面のmode・初期選択・初期入力を確定してから、既存の配置経路を一度だけ呼ぶ。
   programmaticな入力初期化で同じ面の途中状態を配置しない。利用者のEN_CHANGE、IME、検索/置換語の所有、テーマのpreview開始順を変えない。
   検索・置換帯で実本文の矩形が変わる場合は、既存の行位置保持と本文配置を行う。
3. 寸法・位置・表示可否が変わらない背景の子窓へ、同じMoveWindow/ShowWindowと全体再描画を繰り返さない。
   実Win32の矩形または明示した入力から判断し、別の配置正本を作らない。暗幕/面/操作可否など変化した領域は正しく更新する。
   通常resize/DPI/言語/font、検索・置換帯のgeometry、本文切替、行番号の追従を省略しない。
4. native名前面の固定理由の最大高は、主窓が所有する専用の計測資源に保持し、dialogを閉じても再利用する。
   keyは幅・DPI・言語・実際に要求した字体の特性とし、HFONTだけを永続keyにしない。font変更時は明示失効する。
   既存のDrawTextW/変換/全理由の列挙で同じ最大高を作り、現在種別の案内など追加入力は別途同じ計測で上限へ含める。
   面のHWND・入力値・結果・選択は再利用せず、各同期呼出しが所有する。固定理由高の省略・切捨て・推定値への置換は行わない。
5. UIAの公開・通知・選択・focus・閉鎖後の参照失効を保つ。応答改善のために通知や検査を無効化しない。
   計装・時計・性能用の入口は製品へ足さず、外部fixtureで調べる。保存schema・実行時依存・ゲート閾値/除外は不変。

## 検証

同一条件/同一計測境界で開閉を比較する。固定文字幅の呼出回数、重複配置、初回/反復、native初回paintを分ける。
言語/DPI/font失効、最小窓と通常窓、Help到達、検索/置換帯の本文位置、テーマpreview/取消、描画/hit/UIAの矩形一致を直接境界として確認する。
native理由高は既存全理由計測との一致と、開閉後の再利用・幅/字体/言語変更・資源失敗を確認する。
実displayへの反映は可能な実visible条件で別に観測し、隔離fixtureの数値と混同しない。
最終PR headの必須CIで `eng/check.ps1` を通す。成功済み不変入力は再利用する。Waivers: none。
