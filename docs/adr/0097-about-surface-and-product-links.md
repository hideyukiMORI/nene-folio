# ADR 0097 — アプリの情報は設定の副面で示し、公式リンクは閉じた表から既存ポートへ渡す

- 状態: 受理（production変更前。hideの最終的な見た目の受理は実画面の確認後）
- 日付: 2026-11-16
- Issue: #838
- 関連: ADR0031/0032/0045/0049/0056/0058/0064/0079、ロードマップ「Aboutと次版へ持ち越すもの」
- 規則: ARC-001/002/003/004/008/010/011/012、C-002/005/010/011/012/017/018、CNF-002/009/010/011、FR-014、QLT-008/009/010/012/013、GIT-001〜004

## 境界

「このアプリについて」は、製品名・版・一行の説明・ライセンス・同梱書体の出典・第三者通知ファイルの案内・公式リンクを示す読み取り中心の面である。
自動更新、更新確認、通信、ライセンス全文の表示、利用状況の収集は行わない。保存する設定・台帳・schema・製品の版は変えない。
版上げ・配布・Store操作、VERSIONINFO、THIRD_PARTY_NOTICES.txtの内容は範囲外。
画面仕様の原本は D:/NeNeFolio/design/about-20261116/handoff.md（`/design:design-handoff` の型で作成）。

## 入口と面

入口は設定の最後の行「このアプリについて…」の一つだけとする。保存先の行と同じ入口ボタンで、クリック・Enter/Space・UIAのInvokeが同じ処理へ入る。
主画面の常設ボタン、新しいキー、Exの別名、コマンドパレットの項目は増やさない。到達経路を一つに保ち、設定の中の版表示と同じ場所から辿れるためである。

面は閉じた `command_surface_mode` に `COMMAND_SURFACE_ABOUT` を足し、テーマ副面と同じ設定フレーム・暗幕・×・「‹ 設定」を共有する。
EDITを持たず、レイヤー自身がfocusと鍵を受ける（設定と同じ）。戻る/Escは設定へ戻ってAboutの行を選び、×は面全体を閉じる。
開いた直後のfocusは「‹ 設定」に置く。開いた直後のEnterが外部ブラウザーを起動しないためである。
focusの順はリンク4つ→戻るで、Tab/Shift+Tabと矢印で循環する。面を開閉しても本文・Undo/Redo・未保存印・検索/絞り込み条件は変わらない。

## 表示する内容

製品名は既存の `UI_TEXT_APP_LOGO`、版は既存の `UI_TEXT_SETTINGS_VERSION` と `product_version_text()` を使い、第二の製品名・版入力を作らない（FR-014 / ADR0045）。
設定フッターの版の1行は残す。説明・ライセンス・同梱書体・通知ファイルの案内・リンクの補足は `ui_text` の新しいIDへ三言語で置く。
固有名（MIT License、HideyukiMORI、Noto Sans JP / SC、SIL Open Font License 1.1、THIRD_PARTY_NOTICES.txt、fonts）は訳さない。
著作権表示は LICENSE と同じ「© 2026 HideyukiMORI」。配布形式（ZIP / MSIX）で文言を変えず、ファイルの絶対pathを組み立てない。

色・書体・寸法の新しい定数は足さない。本文は `current_text`、版と補足は `dialog_secondary`、リンクは中立のコマンド部品とし、
色や下線ではなく形でボタンであることを示す（高コントラストでも意味が残る）。内容幅が狭いときはリンクを2列2行にし、
内容が高さを超えるときは設定と同じ画素スクロールで、focusした部品を見える位置へ出す。演出（ADR0096）の対象にしない。

## 公式リンク

coreに閉じた `enum product_link`（REPOSITORY / RELEASES / STORE / ISSUES）と、その絶対https URLを返す唯一の表を置く。
applicationの `folio_state_open_product_link` が、既存の `web_uri_create` で検証した値を既存の `web_link` ポートへ一度だけ渡す（ADR0079）。
UIは意図を渡すだけで、ShellExecuteや別の検証を持たない（ARC-002 / ARC-008 / ARC-011）。
ノート内リンクの「閲覧中で文書があるときだけ」という条件は、本文の表示状態に結び付いた別の意味なので変えない。製品リンクは文書やモードに依存しない。
結果は既存の `folio_state_outcome` で返し、失敗は面内の通知行に1行で示す。成功しても面は閉じない。
UIAではリンクのNameをラベル、HelpTextを開く先のURLにし、押す前に行き先を読めるようにする。

## 採らなかった案

- 主画面ヘッダーへの常設ボタン、専用キー: 使用頻度の低い情報のために常設の操作を増やさない。
- ライセンス全文・第三者通知の全文表示: 同梱ファイルが正本で、アプリ内に第二の写しを持たない（ARC-001）。
- URL文字列を本文に並べてクリック可能にする: 当たり判定が小さく、高コントラストで区別が色頼みになる。
- 更新確認: 通信と時刻が要り、配布経路（Store / GitHub）ごとに意味が違う。Storeの更新機構と重複する。
- 最初のfocusを先頭のリンクに置く: Enterの打ち過ぎで外部アプリが開く。

## 検証

製品リンク表の網羅とURI検証、applicationの成功/拒否/ポート失敗/確保失敗、設定行と面の鍵・クリック・UIA・戻る・×、
三言語×明/暗/高コントラスト×最小と広い窓の実画面採取、既存の設定試験の更新。最終headの必須CIを完了条件とする。
読み上げの実聴取、物理IME、全OS/DPI、Store署名版での起動は確認外として品質記録へ残す。
