# ADR 0104: 状態遷移図はフローチャートの模型へ読み、既存の配置と描画を使う

Status: accepted / 2026-11-17 / Issue #872

## 背景

閲覧表示のMermaidはフローチャートとシーケンス図だけで（[ADR0089](0089-native-lazy-mermaid.md)）、状態遷移図（`stateDiagram` / `stateDiagram-v2`）は「未対応の種類」の案内だった。
状態遷移図は、状態（箱）と遷移（矢印）、開始・終了の印、複合状態（入れ子の枠）からなり、フローチャートの模型（ノード・辺・サブグラフ）でそのまま表せる。

## 決定

- coreの新しい`mermaid_state`が、状態遷移図を種類`DIAGRAM_FLOWCHART`の`diagram_model`へ読む。配置（`diagram_flow_layout`）・描画・上限・遅延描画・通知・書出しでの原文の保持は既存のまま。
  模型の種類も配置も描画も足さない（ARC-001）。向きの読み取りは`mermaid_flow_direction`の一か所をフローチャートと共有する。
- 文は行ごとに読む（`DIAGRAM_SEQUENCE`の文の読み方。フローチャートの読み方は`{`を括弧として数えるので、複合状態の`{`と合わない）。
- 対応する構文と模型:
  - `A --> B`・`A --> B : ラベル`: 実線・閉じた矢印の辺。状態は角丸の箱（`DIAGRAM_ROUNDED`）、既定の表示は状態のid。
  - `[*]`: 遷移の元では開始（`DIAGRAM_CIRCLE`）、先では終了（`DIAGRAM_DOUBLE_CIRCLE`）。どちらも空のラベル。複合状態ごとに別の開始・終了。
  - `state "表示名" as A`・`A : 説明`: 表示の文字を置き換える（名前と説明の2段表示はしない）。
  - `state A { ... }`（`state "表示名" as A { ... }`も）: サブグラフ。`state A <<choice>>`: ひし形。`direction`: 図全体と複合状態の向き。
  - 既定の向きは上から下（Mermaidと同じ）。
- 未対応（図全体を未対応の案内にし、部分的な図を作らない）: `note`、並行領域`--`、`<<fork>>` / `<<join>>`、`classDef` / `class` / `:::` / `style`、
  複合状態そのものへの遷移（先に遷移で現れた状態を後から複合状態にする場合も）。図全体と異なる`direction`の複合状態は、フローチャートのサブグラフと同じく配置で未対応になる。

## 却下した案

- 状態遷移図の専用の模型・配置: 同じ箱と矢印の配置を2つ持つことになる。
- 開始・終了を小さな塗りの点にする: 新しい形と寸法の規則が要る。最初は既存の円・二重円で表し、見た目の調整は別にする。

## 検証

模型（状態・遷移・ラベル・開始と終了・複合状態とその開始と終了・choice・direction）と、未対応・不正の入力を単体で、
既存の描画の試験（`diagram_render_tests`）に状態遷移図を加え、解析・配置・描画の3段階と明暗の画像を確かめる。Waivers none。
