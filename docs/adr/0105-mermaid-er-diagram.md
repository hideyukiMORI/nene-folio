# ADR 0105: ER図はフローチャートの模型へ読み、多重度は線のラベルの文字で示す

Status: accepted / 2026-11-17 / Issue #882

## 背景

閲覧表示のMermaidはフローチャート・シーケンス図・状態遷移図（[ADR0104](0104-mermaid-state-diagram.md)）を図にし、ER図（`erDiagram`）は「未対応の種類」の案内だった。
ER図は、実体（箱）と関係（線）、両端の多重度、実体の属性からなる。多重度の記号（鳥の足）と属性の表を除けば、フローチャートの模型（ノード・辺）でそのまま表せる。

## 決定

- coreの新しい`mermaid_er`が、ER図を種類`DIAGRAM_FLOWCHART`の`diagram_model`へ読む。配置・描画・上限・遅延描画・通知・書出しでの原文の保持は既存のまま（ARC-001）。
  文は状態遷移図と同じく行ごとに読み、向きは`mermaid_flow_direction`を共有する。既定の向きは上から下。
- 対応する構文と模型:
  - 実体: 四角（`DIAGRAM_RECTANGLE`）。名前は`-`を含んでよい（`LINE-ITEM`）。名前だけの行でも実体になる。
  - 関係`A <左><線><右> B : ラベル`: 左は`|o` `||` `}o` `}|`、右は`o|` `||` `o{` `|{`。線は`--`（識別、実線）か`..`（非識別、破線）。矢印なし。
    ラベルは引用符を外す。線のラベルの2行目に多重度を`1 : 0..*`の形（左の実体の側 : 右の実体の側）で足す。ラベルが空なら多重度だけ。
  - 属性の段`A { ... }`: 各行の`型 名前 [PK, FK, UK]`を実体の名前の下に1行ずつ足す。`"説明"`は省く。同じ実体の段が複数あれば足していく。
  - `direction`。
- 未対応（図全体を未対応の案内にし、部分的な図を作らない）: 引用符の実体名、別名`A["表示名"]`、`style` / `classDef` / `class` / `click`、`accTitle` / `accDescr`。
  多重度の別名（`one or more`等）と、上の8つ以外の記号は不正として案内する。

## 補足（#888）

属性を持つ実体は形`DIAGRAM_ENTITY`にする。名前は実体のid、表示の文字（label）は属性だけを持ち、模型の形は変えない。
配置がidと属性の2つの文字の寸法から箱を決め、四角・中央の名前・区切りの線・左揃えの属性を描画要素として出す（描画は四角を描くだけ）。
属性の無い実体と空の段は従来の四角のまま。型・名前・キーの列を揃えた表にはしていない。

## 補足（#898）

多重度は線の端の記号で描く（最初の決定の「線のラベルの2行目の文字」を置き換える）。#890（ADR0107）で、線の端の印を矢印の種類として足し、同じ辺の印を横に並べる仕組みができたため。
矢印の種類に、ちょうど1（縦棒2本）・0か1（丸と縦棒）・1以上（縦棒と鳥の足）・0以上（丸と鳥の足）を足す。描画はadapters/win32の矢印の一か所で、矢印より大きく（1.6倍）描く。丸は図の地の色で塗る。
関係のラベルは語だけ。語が無ければラベルを出さない。

## 却下した案

- 多重度を線の端の記号（鳥の足・輪・縦棒）で描く: 新しい矢印の種類と、端の向きに合わせた描画が要る。最初は文字で示し、見た目の調整は別にする。
- 属性を型・名前・キーの列の表にする: 実体の形と、表の行の寸法を配置へ渡す仕組みが要る。最初は名前の下の行で示す。
- ER図の専用の模型・配置: 同じ箱と線の配置を2つ持つことになる。

## 検証

模型（実体・関係・多重度の文字・線の種類・矢印なし・属性・段の追加・向き）と、未対応・不正・上限の入力を単体で、
既存の描画の試験（`diagram_render_tests`）にER図を加え、解析・配置・描画の3段階と明暗の画像を確かめる。Waivers none。
