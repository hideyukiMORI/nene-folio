# ADR 0110: 「ノートを探す」の名前/本文は←→とAlt+←→で切り替え、Enterは読む・Ctrl+Enterは直す

Status: accepted / 2026-11-18 / Issue #940（#928の一部）

## 背景

hideの実機確認（#928）の要望: 左右キーで名前と本文を切り替えたい（画面にもキーを示す）、「一致箇所を開く」をCtrl+Enterなどで。
入力欄の中の←→は文字のカーソル移動で、そのまま切替に使うと衝突する。Enterはすでに「開く」で、本文検索では編集表示で開いていた。
案を並べたページ（D:/NeNeFolio/design/928-finder-choices/、https://claude.ai/artifact/CUTvRvcn4i6k956YX1uFRp ）を見て、hideが「全部おすすめで」と決めた（2026-11-18）。

## 決定

1. 名前/本文の切替（案D）: 入力欄が空のとき、←は名前、→は本文を選ぶ。入力欄に文字があるときの素の←→は文字のカーソル移動のまま。
   Alt+←／Alt+→は、検索の面のどこにフォーカスがあっても（入力欄・候補・原文・ボタン）、文字の有無に関係なく切り替える。
   切り替えてもフォーカスと検索語は動かさない。ただし、新しい側で見えなくなる・使えなくなる所（原文欄・候補・開くボタン）にフォーカスがあったときは入力欄へ戻す。同じ側をもう一度選んでも検索をやり直さない。
   Alt+←→のキーは既定の処理へも渡す（飲み込むと、Altを離したときに窓のメニューが始まるおそれがある）。経路は既存の`discovery_choose_mode`（`discovery_switch_mode`がフォーカスを戻す）。
   二択の表示にキーを添える（「名前 Alt+←」「本文 Alt+→」）。二択へTabで入ってからの←→・Enter/Spaceは従来どおり。
2. 開く操作を2つに分ける（案B）。
   - Enter／「開く Enter」: 名前検索は従来どおり、いまの表示モードのまま開く。本文検索（「一致行を開く Enter」）は閲覧表示で開き、検索語の最初の一致を表示の中で選んで見える位置へ寄せる。
   - Ctrl+Enter／「編集で開く Ctrl+Enter」: 編集表示で開く。本文検索では従来のEnterと同じ経路（保存済み原文が検索時と同じなら最初の一致を選択。ADR0095）。名前検索では編集表示で開くだけ。保護されたノートは閲覧のまま開く。
   - ボタンは2つ並べる（左が「編集で開く」、右が既定の「開く」）。Tabの順は 原文を見る → 編集で開く → 開く → 閉じる。「開く」にフォーカスがあるときのCtrl+Enterも編集で開く。
   - 下の3つのボタンは、面が狭くて収まらないときは同じ比で縮める（重ねない）。
3. 閲覧表示で一致へ寄せる方法: 閲覧は描画した文字を表示しているので、保存済み原文の位置は使えない。ノート内検索（`/`）の仕組みで、表示の先頭から最初の一致を探して選ぶ。
   このとき検索語はノート内検索の語にもなり、向きは前方に揃え、開いた後に n / N で次の一致へ進める。記法の中だけに一致する語（表示に出ない文字）は見つからず、ノートの先頭のまま開く。
4. Ctrl+Enterで届く文字（0x0A）は1行の入力欄へ入れない（鍵で処理済み）。
5. 日本語入力の変換中は、←→・Alt+←→・Enter・Ctrl+Enterを変換へ渡す（従来の`command_composing`）。

## 影響

- ADR0095「本文検索のEnterは編集表示で開く」は、Ctrl+Enterと「編集で開く」へ移る。Enterは閲覧で開く。
- 本文検索のEnterは、編集中だった表示を閲覧へ切り替える（名前付きのノートは検索を開いた時点で保存済み。無題は既存の保存確認を通る）。
- 本文検索のEnterは、ノート内検索の語を検索語で置き換える（以前の語は残らない）。
- 入力欄の右の二択が広くなり（1つ72→104）、入力欄がそのぶん狭くなる。下の「原文を見る／結果を見る」は144→120。

## 却下した案

- いつも素の←→で切り替える: 入力した語の途中を直せなくなる。
- カーソルが端にあるときだけ切り替える: 端にいると気づかずに切り替わる（選択のページの案C）。
- Enterの意味を変えず、Ctrl+Enterを同じ「開く」にする: 「見に行く」と「直しに行く」を分けられない（案C）。
- 閲覧で開くときに原文の位置から表示の位置を計算する: 描画と原文の対応表が要る。ノート内検索で足りる。

## 検証

native試験（`discovery_native`・`body_discovery_native`と96 DPIの変種）: 空の入力欄の←→、文字があるときの→はカーソル移動、Alt+←→、変換中は切り替えない、
Ctrl+Enterと「編集で開く」で編集表示、本文検索のEnterで閲覧表示と表示の中の最初の一致の選択・ノート内検索の語、本文検索のCtrl+Enterで原文の一致の選択。
既存の本文検索の試験のうち「開く＝編集表示」を前提にしていた11か所は「編集で開く」へ替えた。
