# ADR 0111: ノートのカテゴリ移動は、移動先を選ぶ面を開き、既存の移動へ合流する

Status: accepted / 2026-11-18 / Issue #941

## 背景

ノートを別のカテゴリへ移す方法は、一覧でのドラッグだけだった（FR-009 / ADR0008）。カテゴリが画面の外にあると運びにくく、キーボードでは移せない。
hideの依頼（2026-11-18）: 「一覧のメモ名上で右クリックで、カテゴリ移動も」。移動先の選び方は、案を並べたページ（D:/NeNeFolio/design/928-finder-choices/ の6番）でhideが案Aを選んだ（「6も推しで」）:
「カテゴリを移動…」で移動先を選ぶ面を開き、文字で絞り込み、↑↓とEnterで決める。

## 決定

1. コマンド`FOLIO_COMMAND_MOVE_NOTE`「カテゴリを移動…」を足す。ノート行の右クリックメニュー（「名前を変更…」の次）とコマンドパレットに出る。Exの名前と直接のキーは付けない。
   - 右クリックからは、その行のノートが対象。ノートを開かずに移す（ドラッグと同じ。開いている文書・編集中の本文・Undoは変えない）。
   - パレットからは、開いている名前付きのノートが対象。無題・未選択は既存の理由（名前が要る／選択なし）で断る。
2. 移動先を選ぶ面（`COMMAND_SURFACE_MOVE`）は、テーマの選択と同じ枠を使う（検索の入力欄と、絞り込んだ行の一覧）。枠・行の高さ・スクロール・入力欄の位置は共有し（`choice_surface`）、
   行の中身・決定・閉じ方だけが違う。テーマの選択と違い、設定の副面ではないので「‹ 設定」は無く、Escと×は面を閉じる。
   - 行は全カテゴリを一覧の順に並べ、入力欄の文字を名前に含むものへ絞る（ASCIIの大小は無視。規則は`ascii_fold_contains`の1つで、テーマの選択と共有）。
   - そのノートがいまあるカテゴリも出すが、「（いまのカテゴリ）」と印を付け、選んでも何もしない。開いた直後と絞り込みの後は、選べる最初の行にいる。
   - ↑↓・PageUp/PageDown・ホイールで行を移し、Enterか行のクリックで決める。日本語入力の変換中は決めない。
3. 決定は application の`folio_state_move_note_to_category(from, 移動先)`の1つ。移動先の末尾の位置は状態が数え、既存の`folio_state_move_note`へ渡す（新しい移動の経路は作らない・ARC-001）。
   - 規則と失敗はドラッグと同じ: 一覧を絞り込み中は断る、お気に入り優先の表示で移動元か移動先に星があるときは断る、移動先に同じ名前があれば断る。
   - 断られた理由は面の下の1行に出し、面は開いたまま（別の移動先を選べる）。成功したら面を閉じ、一覧と本文の見出しを描き直す。

## 影響

- ノート行のメニューは3項目から4項目になる。
- お気に入り優先の表示で星のあるカテゴリへは、ドラッグと同じく移せない（手動順へ切り替えると移せる）。右クリックの移動でこの制約を緩めるかは決めていない。
- 絞り込みの比べ方の関数をcoreの`ascii_fold`へ移した（テーマの選択の振る舞いは同じ）。

## 却下した案

- メニューの中にカテゴリ名を並べる（案B）: カテゴリが多いとメニューが長くなり、多いとき用にもう1つの面が要る。
- 副メニュー（案C）: いまのメニューに副メニューの仕組みが無い。
- 面を新しい種類として枠から作る: 入力欄と一覧の配置・スクロール・読み上げの経路が2つになる。
- 移動先の位置をUIが数える: 状態の一覧と同期する前の数を使うおそれがある。

## 検証

application の単体（同じカテゴリ・無いカテゴリ・末尾への移動）、`ascii_fold_contains`の単体、
native試験`move_category_native`（行のメニュー → 面が開く、行の名前といまのカテゴリの印、Escで何も移さない、Enterで最初の選べる行へ移る、開いている文書が変わらない、絞り込み、いまのカテゴリは選べない、絞り込んでEnterで戻す）。
