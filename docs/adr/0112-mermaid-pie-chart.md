# ADR 0112: 円グラフは扇を節点として持ち、角度は整数で渡し、色はアクセント色の濃淡にする

Status: accepted / 2026-11-18 / Issue #955

## 背景

閲覧表示のMermaidはフローチャート・シーケンス図・状態遷移図・ER図・クラス図を図にし、円グラフ（`pie`）は「未対応の種類」の案内だった。
円グラフは箱と線ではないので、これまでの図のようにフローチャートの模型へ読み替えられない。扇という新しい形と、扇の色が要る。
色の決め方は、実際のLight / Darkの色で3案の見本を並べ（D:/NeNeFolio/design/928-finder-choices/ の7番）、hideが案A（テーマのアクセント色の濃淡）を選んだ（2026-11-18「円グラフはAで。」）。

## 決定

- 図の種類に`DIAGRAM_PIE`を足す。coreの`mermaid_pie`が読み、`diagram_pie_layout`が配置する。振り分けは従来の`mermaid_diagram_create`の一か所（最初の語の表）。
- 模型: 扇1つが節点1つ。idは名前、labelは凡例の1行、新しい欄`share`が扇の角度（1/100度）。角度の合計は必ず36000で、丸めの残りは最後の扇が受ける。
- 構文: `pie`、同じ行の`showData`と`title 題`、行としての`title 題`・`showData`、扇の行`"名前" : 数`。
  数は正の10進（整数部は9桁まで、小数は千分の一まで数え、それより下の桁は数えない）。`%%`のコメントは従来どおり読み飛ばす。
- 凡例の行は「名前 40%」、`showData`があれば「名前 [書かれた数] 40%」。割合は整数へ四捨五入する（Mermaidと同じ）。
- 配置: 題（あれば上に中央）、円（直径200）、その右に凡例（色の見本と1行）。扇は上から時計回りに、書いた順。扇の上には文字を置かない。
- 形: 場面の部品に扇`DIAGRAM_SECTOR`を足す。円の外接の四角と、開始角・角度（1/100度、上から時計回り）を持つ。
  coreは三角関数を使わない（coreが使えるCの関数は許可の一覧だけ）。角度から輪郭を作るのはadapters/win32の描画（GDIの`Pie`）で、そこでだけ`sin`/`cos`を使う。
  角度が小さすぎて2本の半径の区別が付かない扇は描かない（GDIは同じ半径を渡すと円全体を描くため）。その扇も凡例には出る。
- 色（案A）: 扇の塗りはアクセント色を地の色へ向けて段階的に薄めた（暗いテーマでは沈めた）色。段は5つ（アクセント色の16分の16・12・9・6・4）で、6つ目からは繰り返す。
  部品に段`shade`を足し、混ぜるのはcoreの`diagram_palette_shade`の一か所。テーマの色の表は増やさない。扇の輪郭は地の色で、隣の扇と離して見せる。凡例の見本は同じ段の色。

## 未対応（図全体を案内にし、部分的な図を作らない）

`accTitle` / `accDescr`、`%%{init}%%`（色や配置の指定）、扇が64を超える図。
不正として扱うもの: 扇が無い、名前が空、数が無い・0・負・数でない、題が2つ。

## 影響

- 節点の値`diagram_node`に`share`、部品`diagram_primitive`に`shade`が増えた。他の図では0のまま。
- 扇が6つ以上あると、同じ段の色が繰り返される。隣り合う扇は必ず違う段になる（5つ目の次は1つ目の濃さ）が、離れた扇は同じ色になるので、凡例の順で読む。
- 高コントラストの配色では、アクセント色と地の色の濃淡がそのまま使われる（専用の配色は足していない）。

## 却下した案

- コードの色分けの色を使う（案B）: 暗いコードの地に合わせた色で、明るい地では淡い。
- 線だけにする（案C）: 凡例との対応が順番だけになる。
- 扇の上に名前や割合を置く: 細い扇で重なり、引き出し線の配置が要る。
- coreで三角関数を使う: 許可の一覧（ARC-003の検査）を広げることになる。角度を整数で渡せば要らない。
- フローチャートの模型へ読み替える: 箱と線の配置は円グラフに使えない。

## 検証

単体: 模型（題・扇の数・角度と合計・凡例の行・`showData`・1つだけの扇）、配置（題・扇・凡例の部品の数と順、扇が時計回りに続くこと、段の繰り返し、凡例が場面の中にあること）、
濃淡（最初の段はアクセント色そのもの、段ごとに地の色へ近づく、最後の段より先は最後の段）、不正と未対応の入力16通り。
描画: 既存の`diagram_render_tests`に円グラフを加え、解析・配置・描画の3段階と明暗の画像を確かめる。Waivers none。
