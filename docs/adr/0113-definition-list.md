# ADR 0113: 定義リストは用語をリンクの色、説明を左罫線だけの1セルの行で描く

Status: accepted / 2026-11-18 / Issue #971

## 背景

ROADMAPの候補「定義リスト」。見せ方は、実際のLight / Darkの色の見本を3案並べ（D:/NeNeFolio/design/928-finder-choices/ の8番）、
hideが案C（用語をアクセント色、説明の左に細い線。太字を使わない）を選んだ（2026-11-18「C,b, a で」の1つ目）。

RichEditは段落の罫線（`\brdrl`）を描かない（ADR0005。引用が字下げと薄い色だけなのはこのため）。
今回あらためて非表示のRichEditで確かめ、段落の罫線は描かれず、表のセルの罫線は辺ごとに描かれることを見た（D:/NeNeFolio/agents/971-definition-list/）。

## 決定

- 書き方: 用語の行の直後の行が`: 説明`（コロンの後に空白かタブ）。`: `の行を続ければ説明が増える。説明の後の行は、空行までその説明の続き。次の用語は空行の後。
- 用語になれるのは、字下げの無い1行だけの普通の段落（見出し・リスト・引用・タスク・2行以上の段落は用語にならない）。
  用語が無い`: `の行、字下げ4桁以上の`: `の行、`:`の後に空白が無い行、用語との間に空行がある行は、従来どおりの文。
- 説明を終わらせるもの: 空行、見出し、区切り線、囲みコード、リスト。説明の直後の`---`は見出し（setext）ではなく区切り線。
- 表示:
  - 用語は1行の段落で、文字はリンクの色（色表の4）。太字にしない。
  - 説明は1セルの表の行。左の罫線だけをリンクの色（幅15）で引き、残り3辺は地の色（幅1）で引く。
    罫線を指定しない辺にはRichEditが灰色の線を描くので、消すには地の色で引く必要がある（実画面で確かめた）。
  - セルの幅は、既存の表と同じく閲覧欄の幅へ合わせる（`note_pane_table_layout`。辺ごとの罫線はそのまま保たれる）。
- 色表: RTFの色表の末尾に地の色（`theme_palette.pane`）を足して11色にした（`\cf11`）。
  閲覧・編集・空の文書の頭を同じに保つため（既存の決まり）、`markdown_rtf_plain` / `markdown_rtf_empty`も`markdown_rtf_create`と同じく`theme_palette`を受け取る形に変えた。
  コードブロックの「コピー」の札は今も色を足さない（ADR0098）。
- 判定と描画は`markdown_blocks`の一か所。開いている段落が定義リストの何であるか（用語・説明・どちらでもない）を閉じた`enum markdown_definition_part`で持つ。

## 影響

- 以前との違い: 1行の段落の直後に`: `で始まる行を書いていたノートは、その行が同じ段落の続きではなく説明として出る。
- 説明1つが表の行1つになる。定義の多いノートでは、表の行の配置（幅合わせ）の回数がその分増える。
- 説明の中では行内の書式（強調・コード・リンク・脚注の参照）が使える。リスト・コードブロック・引用は入れられない（それらは説明を終わらせる）。
- 説明の中の文字の選択やキャレットの動きは、表のセルの中と同じになる。

## 却下した案

- 段落の左罫線（`\brdrl`）: RichEditが描かない。
- 行頭に縦線の文字を置く: 折り返した2行目以降に線が続かない。
- 欄の上に重ねて線を描く: スクロールや再配置のたびに位置を求め直す仕組みが要り、表の行より作る量と壊れ方が大きい。
- 残り3辺の罫線を指定しない: 灰色の枠が出る（実画面で確認）。
- 色表を変えずに既存の色で3辺を引く: 地の色と同じ色が色表に無い。
- 用語と説明の間の空行、複数の用語が1つの説明を共有する書き方: 用語の判定が段落をまたぎ、普通の文との区別が弱くなる。必要になったら別に検討する。

## 検証

単体: 用語と説明のRTF、複数の説明、続きの行、行内の書式、空行での終わりと次の用語、見出し・区切り線・囲みコード・リストでの終わり、
説明にならない9通り（用語が無い、2行の段落、空白の無いコロン、深い字下げ、間の空行、見出し・リスト・引用・タスクの直後）、色表の11色（通常と高コントラスト）。
native（`definition_list_native`）: Light・Dark・高コントラストの実画面で、用語と説明の順、コロンが出ないこと、続きの行、説明にならない行、説明が1セルの行であることを確かめ、画面を保存する。
Waivers none。
