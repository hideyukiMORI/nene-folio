# ADR 0122: 左の欄の上の部分を、検索の枠1つと重ねて効く絞り込みの札に作り直す（段に分ける）

Status: accepted（1段目と、2段目のうち見出しの数・お気に入りの札・開く札・解除・タグごとの札・「+N」・「すべて含む／いずれか」を実装。新しいノートの印・検索の範囲は未実装） / 2026-11-23 / Issue #1199（hideの判断: 2026-11-23「デザイン、今の案でいい」「並べるかな」「うん、それがいいかもね。」「左の欄の上の部分は、26で２行。よい。たりる。」）

## 背景

左の欄の上の部分（検索・すべて／お気に入り・タグで絞り込み・カテゴリの見出し）を、デザインとして詰める（#1199）。
14の配色の実物の絵を、ビジュアルの設計者とデスクトップGUIの操作の設計者の2つの席に見せて、いまの形を前提にせずに案を出してもらった。2人がそろって挙げた弱い所:

- 同じ形の箱が積まれていて、作る・探す・切り替える・絞るの違いが形に出ていない。
- いちばん目立つのが「すべて」の塗りで、強い色が「何も絞っていない」ことに使われている。
- 絞り込みが2つの別々の形（2択と釦）に分かれている。
- 畳む印（右の−）が、足す＋と対に見える。字の左端が2pxずれている（カテゴリ名は42、ノートの題は40）。

hideは、押して見比べる模式図（原本 D:/NeNeFolio/design/sidebar-header/index.html）から「詰めた案」を選び、実物の寸法で描いた絵（原本 D:/NeNeFolio/design/sidebar-header/real.html）を見て、残りを決めた。
絵は125%の拡大の画面の寸法で描いたので、絵の上の値は、ここでは96 DPIの論理pxへ直して書く（÷1.25）。

## 決定

### 目指す形（hideが決めたこと）

1. 枠を持つのは検索の欄だけ。その右に「新しいノート」の印を置く（名前とCtrl+Nは、マウスを載せたときの説明とメニューで伝える）。
2. 絞り込みは、重ねて効く同じ形の札（☆ お気に入り、# タグ ▾）。点いた札は、字の色・太さ・塗った星で示し、強い色の塗りは使わない（最初の絵にあった✓は置かない。hide 2026-11-23「他のは✓まーく使ってた？タグとか。必要？」。タグの札に✓が無く、そろわないため）。
3. タグが複数のときは、タグごとに札を並べ、×で1つずつ外す。札の高さは21（絵の上の26）。2行を超えた分は「+N」の札にまとめる。
4. タグが2つ以上のときだけ「すべて含む／いずれか」を出し、「× 解除」と同じ1行に置く。絞り込みが効いていないときは、その行を出さない。
5. 高コントラストでは、点いた札を2pxの枠と太字で示す。
6. 検索の既定は全体。絞り込み中に検索しているあいだだけ「探す範囲 すべてのノート／絞り込みの中」を出す。
7. カテゴリの行の畳む印は、行の左の▾／▸にする。右の列は星だけに使う。

### 段の分け方

2段目で2択とタグの釦は札に置き換わるので、1段目では、2段目の後も残る所だけを直す。段ごとに、実窓の試験・変異・独立レビュー・必須CIを通す。

### 1段目で決めること

1. **畳む印の形**: `ICON_PAINT_FOLD_COLLAPSE`（開いている）は下向きの三角、`ICON_PAINT_FOLD_EXPAND`（畳んでいる）は右向きの三角。同じ三角を90°回した形で、24のviewBoxの中心のまわりに置く。「−」「＋」の板はやめる（ADR0033の決定3の、この2つの形を置き換える）。「新しいカテゴリ」の＋（`ICON_PAINT_ADD`）は変えない。
2. **畳む印の場所**: 箱は16の正方形で、カテゴリ行の左の余白（字下げ16）に置き、番号の左端で終わる（x = 0〜16。三角の見える幅は8）。行の縦の中央。色は`header_text`のまま（ADR0033の決定6の、折畳の箱 `[幅−16−24, 幅−16]` を置き換える）。
3. **右の列**: カテゴリ行の右の列には何も描かない。カーソルの角のxは、ノートの行と同じ 幅−52〜幅−46 のまま（ADR0015の決定7。式は変えない）。星の中心（幅−28）も変えない。
4. **ノートの題の左端**: 40から42へ（カテゴリの字下げ16＋番号から名前まで26）。カテゴリ名の左端と同じ式（別々に丸めた2つの和）で決めるので、どのDPIでも1pxもずれない。題の右端（幅−58）は変えない（ADR0091の決定1の、題の範囲の左端だけを改める）。
5. **カテゴリ名の右端**: 幅−32から、ノートの題と同じ幅−58へ。右の列が空いても、カーソルの角（幅−52〜幅−46）は残るので、長い名前が角の下へ入らないようにする（前は、長い名前の行にカーソルがあると、字の上に角が載った）。
6. **畳む・開くの操作は変えない**: カテゴリ行のどこを押しても畳む・開く（印だけの当たりは作らない）。キーボード・読み上げ（Expand/Collapse）も同じ。

### 2段目で決めること（決まった順に足す）

1. **見出しの行の数**（#1215）: 見出しの「カテゴリ」の右の数は、ノートの総数（絞り込み中は「該当 / 全体」）で、カテゴリの数ではない。模式図と絵は「カテゴリ 17」と見出しのすぐ隣に描いたが、隣に置くとカテゴリの数に読める。4つの案を、どれが席の案かを伏せて、ビジュアルの設計者とデスクトップGUIの操作の設計者の2つの席に見せた。ビジュアルの設計者は下の形を推し、GUIの操作の設計者は別の案（該当の数を解除の行に出す）を推したうえで、下の形も「それでよい。見過ごせない欠点は無い」と答えた。hideの指示（「専門家ペルソナに聞いてそれでいいならそれで。」）のとおり、下の形に決めた。
   - 数は「＋」の左（8空ける）に右寄せで、その左（6空ける）に単位を置く: ふだんは「ノート 17」、絞り込み中は「ノート 2 / 17」（英語 Notes、中国語 笔记。単位の文言は`UI_TEXT_STATUS_NOTE_UNIT`）。準備中の「準備中」は変えない。
   - 数は、細い等幅（Consolas 11。前のまま）。単位は、言語ごとのUIの書体の細字11。等幅の書体には仮名・漢字が無く、1つの書体で描くと、単位だけがOSの選ぶ代わりの書体になる（独立レビューが見つけた）ので、2つに分けて描く。見出しと同じ太字・字間にはしない。
   - 数に使える幅は、見出しの字の右（8空ける）から「＋」の左（8空ける）まで（下限は前と同じ64）。単位＋間＋数がその幅に入らないときは、単位を描かず、数だけ（前の形）を描く。
   - カテゴリの数は、見出しにマウスを載せたときの説明に出す（「カテゴリ 5 ・ ノート 17」。hide: 説明に出すだけで足りる）。読み上げでも、数は見出しと別の要素にする。この2つは、絞り込みの札で読み上げの木を作り直す変更に入れる（**未実装**）。

2. **札の並べ方**（#1220。中核の`chip_flow_arrange`。まだ左の欄からは呼んでいない）: 0番の札（お気に入り）、タグの札、「開く札」の順に、左から詰めて並べる。札の間と行の間を空け、入らなければ次の行の左端へ送る。使ってよい行の数（2）に入らないときは、後ろのタグの札から畳んで「+N」の札に置き換え、「+N」と「開く札」まで入る所で止める。0番の札と「開く札」は、行の数を超えても必ず置く。行より広い札は、行の幅に切る（描く側が省略する）。字の幅はWin32の側で測り、幅の配列で渡す。描画・当たり判定・読み上げは、この1つの結果を使う。

3. **解除の意図と、タグの条件の改訂の番号**（#1236。application。まだ左の欄からは呼んでいない）: 札の「× 解除」は、application の1つの意図`folio_state_clear_conditions`で行う。タグの条件を空にして「すべて含む」へ戻し、表示の範囲を「すべて」へ戻す。検索語は残す（タグの面の「すべての条件を解除」は検索語も消すので、別の意図）。タグの条件を外せなかったときは、範囲も変えずに、その結果を返す（UIで2つの意図を続けて呼ぶと、1つ目が失敗したときの半端な状態をUIが扱うことになる）。タグごとの札は、何番目の札がどのタグかを、`folio_state_tag_filter_revision`（タグの条件を持ち替える・捨てるたびに進む。非同期の失敗で application が自分で外したときも進む）で確かめる。見出しの列（#975）と同じ「種類1つ＋番号＋改訂」の方式。

4. **見出しの行の説明と、読み上げの数の要素**（#1238）: 見出しの行（「カテゴリ」の字の左端から、数の右端まで）に、説明（tooltip）「カテゴリ {k} ・ ノート {n}」を出す。同じ文を名前に持つ読み上げの要素（UIA の Text、`ACCESSIBLE_INDEX_COUNT`。フォーカスは取らない）を、左の欄の、タグの釦と「＋」の間に置く。数は application から取り、絞り込み中も全体の数。説明の文は、左の欄のほかの説明と同じ道（配置し直すときに写し直す）で新しくなる。別の写し直しは足さない（ノートを増やす実窓の試験で、足さなくても新しい数になることを確かめた）。

5. **札の行と「× 解除」**（#1242。左上の見た目が変わる最初の段）: 「すべて／お気に入り」の2択と「タグで絞り込み…」の釦を、検索の欄の下の1行の札に置き換える。
   - **札**: 高さ21、左右の余白7、札の間と行の間5、中の絵12（字との間4）。検索の欄の帯（36）の下に2空けて置き、行の下に4空ける。枠は1pxの`border`。様式は部品の描き方の「F」（ADR0060 の 2026-11-23 の補正）。
   - **お気に入りの札**: 「☆ お気に入り」。押すと表示の範囲が「お気に入り」になり、もう一度押すと「すべて」へ戻る（既存のコマンド「お気に入りだけの表示を切り替える」と同じ1本の道）。点いた札は、塗った星・太字・字の色（`current_text`）の枠で示し、塗らない（✓は置かない。決定2）。高コントラストでは枠が2px。押している間だけ、ほかの部品と同じ塗り。
   - **開く札**: 「# タグ ▾」（▾は絵）。押すとタグの面が開く（前の釦と同じ）。タグの条件があるときは「# タグ {n}」になって点く。読み上げの名前は前と同じ文（「タグ 2 個 · すべて含む」など）。前の字「タグで絞り込み…」は、お気に入りが点くと既定の幅（240）の1行に入らず2行目へ落ちたので、短くした。
   - **並べ方**: 中核の`chip_flow_arrange`（決定2）に、0番＝お気に入りの札、開く札＝タグの札で渡す。行に入らない幅では2行になる。
   - **「× 解除」**: お気に入りかタグの条件が効いているあいだだけ（`folio_state_conditions_active`）、札の行の下の右端に、高さ18の行で出す。枠は持たない（字だけ。押下・hover・focus は札と同じ道）。押すと`folio_state_clear_conditions`（決定3）。行の下に2空ける。
   - **固定の帯の高さ**: 36（検索）＋札の行（2＋札の行の高さ＋4）＋解除の行（あるときだけ 18＋2）＋36（カテゴリの段）。前は136の固定、いまは条件なし・1行で99、条件ありで119。描画・当たり・読み上げの矩形・木の上端・スクロールの上限は、同じ1つの配置（`drawer_filter_band`）を使う。読み上げの配置の覚えの鍵に、帯の高さを足した。帯の高さが変わったら、左の欄が描いた後に主窓へ知らせ（`folio_message_drawer_band`）、主窓が説明の矩形を写し直し、消えた解除に残った focus をお気に入りの札へ移す。
   - **読み上げの木**: 左の欄の下に、群「絞り込み」（Group。子は、お気に入りの札＝Button＋Toggle、開く札＝Button＋Invoke）、解除（Button＋Invoke。条件が効いているときだけ）、数（Text）、新しいカテゴリ、木。前の「表示範囲」の群（Selection と2つの RadioButton）は無くした。
   - **Tabの順**: 検索 → 札の行（1回だけ止まり、お気に入りの札に入る。中は左右の矢印で動き、Enter／Spaceで確定）→ 解除（あるときだけ）→ 新しいカテゴリ → 木。開く札は、前はTabで止まったが、いまは札の行の中で矢印で移る。木が空のときの focus の移し先は、お気に入りの札。
   - **説明（tooltip）**: お気に入りの札は「お気に入り」、開く札は「タグで絞り込み」、解除は「絞り込みを解除」。

6. **タグごとの札と「+N」**（#1247）: タグの条件のタグ1つごとに、札を、お気に入りの札と開く札の間に、条件の順で並べる。
   - **タグの札**: 「# 名前」と、右に×の絵（札の中の絵と同じ12。`ICON_PAINT_CLOSE`）。いつも点いた見た目（太字・字の色の枠。条件として効いているので）。札のどこを押しても、そのタグが条件から外れる（×だけの当たりは作らない。高さ21の札の中の×は小さすぎる。hideの判断）。幅の上限は132で、長い名前は … で切る（席の仮決め）。上限は、行の幅から「+N」と開く札と間2つを引いた残りまで、さらに狭める（下限48）。狭めないと、長い名前の札が「+N」・開く札と同じ行に入らず、2行に収めるために全部のタグが畳まれる（実物の絵で見つけた）。名前の全体は、説明（tooltip）と読み上げの名前「タグ {名前} を外す」で伝える。
   - **外す道**: タグの面がタグを外すときと同じ1本（`note_tags_with` で1つ減らした集まりを作り、`folio_state_set_tag_filter` へ、いまの「すべて含む／いずれか」のまま渡す）。application に新しい意図は足さない。
   - **「+N」**: 2行に入らないときは、`chip_flow_arrange`（決定2）が後ろのタグから畳み、畳んだ数を「+N」の札（点いた見た目）で、開く札の手前に置く。押すとタグの面が開く（開く札と同じコマンド）。説明（tooltip）と読み上げの説明に、畳んだタグの名前を条件の順に並べる。読み上げの名前は「ほか {n} 個のタグ」。「+N」の幅は、並べる前に、いちばん広い数（条件のタグの数）で測る。
   - **開く札**: タグの条件があっても「# タグ ▾」のまま、点かない（#1242 の「# タグ {n}」はやめる。数と中身は、札そのものが示す）。読み上げの名前は前と同じ（「タグ 2 個 · すべて含む」など）。絵の「＋ タグ ▾」には替えない（「新しいカテゴリ」の＋と紛れる。席の仮決め）。
   - **読み上げの木**: 群「絞り込み」の子は、お気に入りの札、タグの札（Button＋Invoke。種類は1つ `ACCESSIBLE_FILTER_TAG` で、番号と、タグの条件の改訂の番号 `folio_state_tag_filter_revision` で1つを指す。見出しの列 #975 と同じ方式）、「+N」（Button＋Invoke。畳んだ分があるときだけ）、開く札。条件が変わると、前の改訂の札は答えなくなり、host が群の子の変化を知らせる（条件の改訂・置かれた数・「+N」の有無を1つの値で見張る）。畳まれた番号の札は無い。
   - **キーボード**: Tabは札の行に1回だけ止まる（お気に入りの札）。行の中は左右（上下）の矢印で、お気に入り → タグの札 → 「+N」 → 開く札 の順に動き、端で折り返す。Enter／Spaceで確定。タグの札を外した後の focus は、同じ場所に来た次の札、無ければ最後の札、タグの札が無くなればお気に入りの札。
   - **続けて押したとき**: タグの札を外すと、隣の札（最後の1つなら開く札）が同じ場所へ来る。「× 解除」と同じ守りで、押した点では、ポインタが動くまで次の押下を受けない（ダブルクリックで2つ外れない・タグの面が開かない）。ポインタが1画素でも動けば守りは外れ、同じ点へ戻って押せる（「× 解除」の守りも同じ扱いにそろえた）。Spaceで札を押している間に、ポインタが別の札へ focus を移したら、キーの押下は取り消す（離したときに別のタグを外さない）。押してから離すまでに条件が変わっていたら（改訂が違えば）、何も外さない。
   - **固定の帯の高さ**: 決定5の式のまま（札の行が2行になると、札の高さ21＋行の間5だけ高くなる）。

7. **「すべて含む／いずれか」**（#1249）: タグの条件が2つ以上のときだけ、札の行の下の行（「× 解除」と同じ行）の左に、2択を出す。
   - **見た目**: 枠を持たない札（F 様式の`grouped`）が2つ。字は「すべて含む」「いずれか」（英語 All / Any、中国語 全部 / 任一。行に入る短い字）。選んでいる方は、字の色（`current_text`）・太字・下辺の2pxの線。塗らない。幅は、どちらも太字で測る（選び替えても動かない）。左右の余白2、2択の間と解除との間は8。高さは解除の行と同じ18。
   - **切り替える道**: タグの面の切り替えと同じ`folio_state_set_tag_filter`（タグはそのまま、形だけ替える）。選んでいる方を選んでも何もしない（改訂も進めない）。
   - **読み上げ**: 左の欄の子として、群「絞り込み」の後ろ・解除の手前に、群「タグの条件」（Group＋Selection）と、2つの RadioButton（SelectionItem）。名前と説明（tooltip）は、タグの面と同じ「すべて含む」「いずれか含む」。
   - **キーボード**: Tabは、札の行の次に、2択に1回だけ止まる（選んでいる方に入る）。左右の矢印は focus だけを動かし、Enter／Spaceで確定（主窓の表示の2択・3択と同じ決まり。ADR0060 の決定5）。次のTabで解除へ。
   - **狭い幅**: 2択と解除が1行に入らないときは、解除を次の行へ送る（帯が、解除の行1つぶん高くなる）。
   - **消えるとき**: タグが1つ以下になったら2択は無くなり、focus が残っていたら、お気に入りの札へ移す。「× 解除」の後は、形は「すべて含む」へ戻る（決定3）。

## 分かっていて残すこと

- 点いた札の幅は、太字で字の幅が変わる言語では、点いていないときより広い（英語。日本語と中国語は全角の字で、幅が変わらない）。押すと、右の札が右へ動く。
- 札の配置は、使うたびに字の幅を測って作り直す（覚えない）。タグが多いと、描くたびに測る回数が増える（上限は32個）。重さが見えたら、条件の改訂と幅を鍵に覚える。
- お気に入りの札と開く札だけで2行を使う狭い幅では、タグの札は全部「+N」に畳まれる。お気に入り・「+N」・開く札が1行に1つずつしか入らない幅では3行になる（`chip_flow_arrange` は、この3つを必ず置く）。左の欄の最小の幅（200）では、3つの言語とも2行に入る。
- タグの札を外した点では、ポインタが動くまで次の押下を受けない。同じ場所に来た次の札を、ポインタを動かさずに続けて外すことはできない（少し動かせば外せる）。ダブルクリックで2つ外れる方を防いだ。逆がよければ、hideの判断で変える。
- 「+N」の幅は、条件のタグの総数の桁で取る。畳んだ数の桁が少ないときは、字を札の中央に描く。
- 検索の欄の中の「Ctrl+Shift+F」は、1段目では残す。2段目で欄が狭くなると、いまの決まり（案内と並べて入るときだけ出す）で出なくなる幅が増えるので、そのときに扱いを決める。

## 検証

- 実窓の試験（`favorites_ui_native`の`fold_mark_pixels`・`note_title_edge`）: 開いたカテゴリ行の左の余白に横長の印があり、右の列（幅−40〜幅）は地の色だけ。畳むと同じ場所の印が縦長になり、開くと元に戻る。ノートの行は、x 41より左に何も描かず、41〜48に題の字がある。
- 絵（診断用の`--favorites-visual`）で、三角の向きと、題とカテゴリ名の左端がそろうことを席が見た。
