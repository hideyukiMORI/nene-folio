# ADR 0123: ノートの上部を、山形の釦で細い1行に畳む

Status: accepted / 2026-11-25 / Issue #1264（hideの判断: 2026-11-24「ノートの上部の情報やインターフェースを表示、非表示をトグルできるアイコンボタンとか欲しい」「イ細い１行だけ残す、山形」。席の仮決め＝設定に覚える・キーは空いているものから・メニューとコマンドに足す、に「それでよい」）

## 背景

ノートの上部（頭の帯＝パンくずと閲覧／編集、操作の帯＝保存・このノート内を検索・操作▾、タグの行＝荷札）は、いつも出ていて、合わせて 108（44＋36＋28）の高さを使う。本文を広く使いたいときに畳めない。

hideは、押して試せる模式図（原本 D:/NeNeFolio/temp/20261124/note-top-options.html）から、畳む範囲は「イ＝細い1行だけ残す（題・保存していない印・戻す釦）」、釦の印は「山形」を選んだ。

## 決定

1. **畳むと、上部は細い1行（高さ 28）になる。** 残るのは、ノートの題（言葉の書体。入らない分は … で切る）、変更ありの間だけその直後の未保存の印、右端の山形の釦。パンくずの番号とカテゴリ名・閲覧／編集・操作の帯・タグの行は、描かない・押せない・Tab で止まらない・読み上げの木に出さない。本文・ミニマップ・見出しの欄・検索／置換の帯は、その分（80）だけ上へ詰まる。
2. **釦は、頭の帯の右端の山形のアイコン釦**（`ACCESSIBLE_NOTE_HEADER`。部品の高さの正方形）。開いているときは上向き（押すと畳む。名前「ノートの上部を隠す」）、畳んでいるときは下向き（押すと戻す。名前「ノートの上部を表示」）。名前は、最大化／元に戻す、と同じく「押すと起きること」。山形は、操作▾の山形（`ICON_PAINT_MENU`）と同じ太さで、箱の上下の中央に置いた新しい絵（`ICON_PAINT_CHEVRON_UP`・`ICON_PAINT_CHEVRON_DOWN`）。
3. **閲覧／編集の2択は、釦の分（28＋間 8）だけ左へ寄る。** ADR 0060 の補正の決定15「閲覧／編集の右端は、× の当たりの右端と同じ縦線」は、山形の釦の右端が持つ。
4. **状態は設定に覚える**（`data/settings.json` の版 8 の `note_header`。既定は true＝表示。アプリ全体で 1 つ。ノートごとではない）。版 1〜7 は読めて true。書くのはいつも版 8 で、**版 8 を旧アプリ（1.5.0 まで）は読めない**（これまでの版上げと同じ）。書けなかったときは、状態を変えず、ミニマップの切り替えと同じ道で知らせる。
5. **入口は 3 つ**: 山形の釦／キー `Ctrl+Shift+H`／操作▾のメニューとコマンドパレットの「ノートの上部の表示を切り替える」。メニューの置き場は、表示を切り替える仲間（ミニマップ・見出しの欄）と同じ操作▾にした（表示▾は、配置 3 つの選択の群で、作りがそれに固定されている）。**畳んでいるあいだは操作▾が無いので、メニューからは戻せない**（釦・キー・パレットで戻す）。
6. **畳んでいるあいだのキー**: 保存（Ctrl+S）・閲覧／編集の切り替え（Ctrl+E）・このノート内を検索（Ctrl+F）は、釦が見えなくても、これまでどおり効く。検索／置換の帯は、細い1行のすぐ下に出る。`Ctrl+M`（操作▾）は、ADR 0081 の決定 2 のとおり、操作の釦が見えないので何もしない。F6 の「ノートの道具」の区画の入口は、山形の釦になる。Tab の順は、閲覧／編集 → 山形の釦 → 保存 → …（見えない部品は飛ぶ）。
7. **切り替えたとき**: 開いている面（検索／置換の帯を含む）は閉じる。隠れた部品に focus があったら、山形の釦へ移す。本文は、いま見えている行を保って配置し直す（見出しの欄の開閉と同じ `rearrange_keeping_line`）。
8. **ノートが開いていないときは、畳んでいる扱いにしない。** 上部そのものを描かないので、空の案内の場所は、設定の値で動かさない。一覧だけの表示では、右ペインが無いので何も起きない。
9. **寸法の決まりとの関係**: ADR 0060 の決定 2・7 の「ヘッダー 44・本文操作帯 36 は維持する」は、開いているときの値として、そのまま。畳んだ 28 は、部品の高さ（28）と同じ既存の値で、新しいトークンは足していない。
10. **設定の面には、行を足していない。** 釦が画面にいつも出ていて、状態もそこで見えるため。

## 採らなかった案

- 畳む範囲を「釦の行とタグだけ」（ア）・「タグだけ」（ウ）: hideが模式図でイを選んだ。
- 釦の印を「上の帯」「目」: 同じく、hideが山形を選んだ。目の印は「表示の切り替え」一般に見え、何が消えるかが伝わりにくい。
- 状態を窓の位置のファイルやセッションだけに持つ（見出しの欄の開閉と同じ扱い）: 「次に開いたときも同じ」（Issue の意図する結果）に合わない。
- 畳んだ行に、パンくずの番号とカテゴリ名も残す: 「細い1行だけ」に対して色面が強く、畳んだ感じが出ない。カテゴリは、左の欄の選ばれた行で分かる。

## 残していること

- 畳んでいるあいだの Ctrl+S・Ctrl+E・Ctrl+F、検索／置換の帯の場所は、自動の試験に無い（絵と手で確かめる）。
- 畳んでいるあいだは、閲覧か編集かが画面の釦では分からない（本文の見た目と、下の帯で分かる）。
- 最小の窓・3 言語・高コントラスト・96／144／192 DPI の絵は、撮っていない。
