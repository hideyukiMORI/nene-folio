## 実装の要点

- 層と依存は [PROJECT_LAYOUT](../PROJECT_LAYOUT.md) のとおり。core は `windows.h` / `stdio.h` を含まず、外部シンボルは
  `eng/symbol-allowlist.json` の libc の一部だけ。`eng/symbols.py` はアーカイブ内と宣言済み依存で解決してから照合する
- 型は不完全型、結果は閉じた `enum`（`x.h` に `struct x;` と関数、`x_outcome.h` に `enum x_outcome`。CNF-002 が 1 ファイル 1 型定義を数える）。
  実装ファイルの外部関数は `x_` 接頭辞
- ポートは関数ポインタの束で、文脈は `struct persistence_adapter;` / `struct appearance_adapter;` の不完全型（`void *` 無し）。
  テストは `tests/unit/state_tests.c` で同名の struct を定義して偽物を作る。ポートの adapter は state より長く生かす
- 台帳は版 1・**キー順固定**: `categories.json` は `version` → `categories[{name, color, expanded}]`、`index.json` は `version` → `notes[]`。
  順序が違えば MALFORMED で起動を止める（既定値に落とさない）。書き戻しは一時ファイル＋`MoveFileExW`
- md → RTF は `src/core/markdown_rtf.c`。見出し・強調・インラインコード・コードブロック・箇条書き・番号付き・リンク・引用。
  `_` は語の中では強調にしない。`\` で打ち消せるのは ASCII の記号だけ。色は `rtf_palette`（色表 1〜6）
- 見た目の値: ドロワーの頭 44px・カテゴリ行 34px（上に 6px）・ノート行 30px（字下げ 40）・番号は Consolas・
  右ペインの頭 44px・本文 Yu Gothic UI 11pt・見出し 22pt。色の正本は `src/core/rtf_palette.c` と `src/ui/win32/folio_palette.c` の 2 つだけ
- テーマは `appearance_adapter` が `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\AppsUseLightTheme` を起動時に読む
- 分岐 90% は `eng/coverage.py` の測定ビルド（ASan 付き）で測る。中核の確保だけを `-Dmalloc=folio_probe_malloc` でテストへ向け、
  `tests/unit/allocation_tests.c` が全確保を 1 回ずつ失敗させる。90% に届かないときはまずここにシナリオを足す（閾値は触らない）
- Debug 構成の全 target を ASan / UBSan / nullability で計装する。CRT は常に `/MT`。既定リンクは kernel32 だけで、OS ライブラリは
  `nenefolio_system_link` でだけ足す（許可表は `eng/architecture.json`）

## 規則・保留

- Waivers: none。ゲートの閾値・除外・重大度は弱めていない。広げた許可は `platformLibraries.adapters_win32` の advapi32（ADR 0005）だけ
- 警告集合に足した名指しの `-Wno-nullability-extension` は CNF-005 の対象外の「規則の選択」（ADR 0004）
- `symbols.py` は依存モジュールの定義を名前で解決するため、ヘッダに無い外部関数の呼び出しは検出しない（C-008 のレビュー事項）
- 色の直書きが 2 つのパレット以外に無いことは字句検査していない。紛れ込んだら事故駆動で CNF に足す
- RichEdit の限界（段落罫線・行内の地）でデザインから外した 2 点は ADR 0005 に記録
