## 実装の要点（本日足したもの。前日分は [2026-09-09](2026-09-09.md)）

- **編集と保存**: `folio_state` が `pane_mode` と「読んだ本文」（`note_text`）を持ち、RichEdit が編集中の本文を持つ。保存の意図は
  `folio_state_store_note`（Ctrl+S・EDIT のまま）と `folio_state_end_edit`（「閲覧」札・別ノートの選択・`WM_CLOSE`・VIEW へ）の 2 本で、
  UTF-16 を受けて core の `utf8_text` → `note_text_from_editor`（元の改行の形に畳む）→ `note_text_equals`（同じなら書かない）→ `write_note`。
  Escape は編集中は何もしない。破棄は無い。ドロワーは選択前に主窓へ `folio_message_edit_flush` を同期で送る
- **並び替えと移動**: `drawer_layout_drop(layout, source_row, y)` が `drop_target`（種類・**移動先の**カテゴリ・移動後の番号・挿入線の y）を返す。
  カテゴリ行は塊の中点、ノート行はポインタのある塊（境界は間の中ほど）のノート行の中点で数え、折り畳み／ノート 0 本なら末尾。
  台帳は `*_ledger_moved` / `note_ledger_inserted` / `removed` で作り直し、書けたときだけ差し替える。`folio_state_move_note(state, note_ref, note_ref)` 1 本で、
  同じカテゴリなら並び替え、違えば (a) 同名検査 → (b) 台帳 2 つ → (c) `move_note`（rename）→ (d) 索引と選択の付け替え → (e) 移動先 → 移動元の `write_note_ledger`。
  (e) の失敗は `LEDGER_STALE`（次回の起動で揃う）
- **UI のドラッグ**: `WM_LBUTTONDOWN` で行を覚えて `SetCapture`、`SM_CYDRAG` を超えたらドラッグ、`WM_MOUSEMOVE` ごとに配置を作って drop を引き、
  `WM_LBUTTONUP` で意図かクリック（クリックの確定は離したとき）。`WM_CAPTURECHANGED` で取り消し。並び替え後は親に `InvalidateRect` だけ頼み、
  `folio_message_selection_changed` は送らない（RichEdit を流し直すと編集中の本文が消える）
- **失敗の 1 行**は `src/ui/win32/failure_box.c` の 1 か所から出す。文言は `folio_state_failure_line`
- **色**は引き続き `src/core/rtf_palette.c` と `src/ui/win32/folio_palette.c` の 2 つだけ（`editor_text` を追加）。挿入線は行のカテゴリ色
- `index.json` は並び替えか移動をするまで作られない（起動時に書かない・ADR 0004 / 0007）
