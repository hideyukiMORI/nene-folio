## 実装の要点（本日足したもの。前日分は [2026-09-10](2026-09-10.md)）

- **スクロール**（ADR 0009）: `drawer_metrics` に `viewport_height` / `bottom_padding`。`drawer_layout_scroll_limit` / `scroll` / `overflow_above` / `overflow_below` /
  `reveal`。`row.top`・`hit` / `drop` の y・`line_y` は表示座標。`hit` は帯（`top_padding` より上）を当てない。`folio_state` の `scroll` は要求量、意図は有効量から数え直す。
  UI はホイール = 3 行 / 刻み、↑↓ = 1 行、PgUp/PgDn = 1 画面 − 1 行。DIB セクションに帯の下でクリップして描き、フェード 24px を画素ごとに混ぜる
- **色**（ADR 0010）: `category_ledger_recolored` → `folio_state_recolor_category`（同じ色は書かない）→ `drawer_window` の `WM_RBUTTONUP` → `ChooseColorW`
  （`CC_RGBINIT | CC_FULLOPEN`・カスタム色は白 16 個・実行中だけ）。`toggled` と `recolored` の複製は 1 つの静的関数
- **枠なし窓**（ADR 0011 / 0014）: `window_procedure` の先出しの switch で `WM_NCCALCSIZE`（TRUE / FALSE とも 0・最大化中は作業領域）・`WM_GETMINMAXINFO`
  （560×360）・**`WM_NCACTIVATE` → TRUE・`WM_NCPAINT` → 0**。`WM_SIZE` で `InvalidateRect`。パンくずは `breadcrumb_room` で札 → 番号 → ノート名 → カテゴリ名
- **履歴**（ADR 0012）: `persistence_port.archive_note`。`store_edited` は「同じなら何もしない → archive → rtf → write → 差し替え」。archive の失敗は
  `HISTORY_FAILED`（文言「履歴を書けなかったので保存していません。編集中の本文は残っています。」）。adapters は `1.md.tmp` を先に書き切ってから
  `5.md` 削除 → `4→5 … 1→2`（`MOVEFILE_REPLACE_EXISTING`）→ `tmp → 1.md`。`.` 始まりのディレクトリは走査しない。移動時に履歴は追随しない
- **区画と鍵**（ADR 0013）: `folio_step`・`folio_state_select_adjacent` / `set_category_expanded` / `reveal_selection` / `selection`。主窓の `switch_note` 1 か所
  （保存 → 選択 → 同じモードで開く → 描き直し）。ドロワーは `folio_message_select_note`（`WM_APP + 1`）を送るだけ（`edit_flush` / `selection_changed` は削除）。
  主窓の `WM_CHAR` で `j` / `k` / `g g` / `G` / `h` / `l` / Ctrl+S、`WM_KEYDOWN` の Enter。RichEdit の `EN_MSGFILTER` で `Esc`。`note_pane_edit` はフォーカスを動かさない。
