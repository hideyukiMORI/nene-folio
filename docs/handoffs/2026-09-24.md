  **机上で決められない所見は受理の前に probe へ戻す**（今回の S6 / S8）。
- **草案の段階で検査器（`eng/conformance.py`）を実際に走らせる。** 今回も S1 / S2 / D11 は CNF-002 と CNF-009 の当たりだった。
- **Issue ごとに新しい agent を立てる。**
- **姉妹の PR は片方を merge したら、もう片方は衝突が無くても sync の push が要る**（保護規則が最新の base での check を求める）。
- **`gh pr edit` は `edited` で先行の run を cancel する。** 本文を直すなら push の前に済ませる。
- **使用制限で agent が止まっても、作業木の未コミットの編集から再開できる。**
- それ以外（未定義の規則 ID と CNF-006・`ready_for_review` で CI が起動しないこと・PR 本文の GIT-004 の字面）は
  1 つ前の再開点のままでよい。
