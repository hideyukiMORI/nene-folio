   `post.ps1` の「フォーカスが非表示なら主窓へ投げ直す」規則は欠陥を隠すので、フォーカスの検証には `-Raw` の写しを使う。
2. 件名と PR の題は 100 文字以内（CI は枝の各コミットの件名も検査する）。
3. `merge-pr.ps1` は本文の欄が行頭に来ること・`Closes #N` を要求する。
4. **CMake の POST_BUILD の複写は古いファイルを消さない。** 資産を差し替える・減らす変更のあとは、
   実機をビルドし直す前に出力ディレクトリの複写先（`build/fonts` 等）を手で消す。
