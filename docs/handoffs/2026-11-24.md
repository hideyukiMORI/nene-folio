## 積んだ枝を、下から main へ入れる手順（今日やって分かったこと）

下の段を squash で入れた後、上の枝へ main を取り込むと、広く衝突の印が出る。**印を機械的に消さない。**

1. 下の段の枝の先頭（履歴がつながっている）を、上の枝へ取り込む。
2. `git diff origin/main <下の段の枝の先頭>` が空であることを確かめる。
3. `git merge -s ours origin/main`（中身を変えずに main とつなぐ）。`-X ours` は使わない（衝突しない塊として、同じ関数が二重に入った）。
4. 取り込む前後で `git diff` が空であること・整形の検査・構築・関係する試験を確かめてから push する。
