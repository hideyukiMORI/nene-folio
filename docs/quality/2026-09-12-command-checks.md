# #37 実機確認の手順と結果

対象: `out/worktrees/37-commands/build/NeNeFolio.exe` と、その隣の `data/command-test/` の架空ノート2本だけ。`out/hide/` と実際のmdを検証に使わない。

以下の表は確認手順。実施した範囲は末尾の結果に分けて記録する。実行時のexeのSHA-256、DPI、ウィンドウ寸法、各結果を記録する。

2026-09-13 13:44 JSTの再試行も、JavaScriptセッションのリセットと再初期化の前後とも
`native pipe unavailable / os error 2` で失敗した。接続の復旧はhideへ依頼中。

| 確認 | 手順と期待 |
| --- | --- |
| 未選択 | 起動後にINDEXで `:w`。理由が入力面に出て窓が残る。EscでINDEXへ戻る |
| 共通の入口 | INDEXで `:`、本文でCtrl+P。Ctrl+P候補の保存と `:w`、Ctrl+Sが同じ本文を保存する |
| 入力だけの保護 | 架空ノートを編集してCtrl+P→Esc。mdと履歴は増減せず、本文・モード・Undo・キャレットが維持される |
| 未保存の終了拒否 | 編集後、パレットの「終了」を実行。本文を失わず理由を入力面に表示。INDEXの空白部分をクリックして `:q` でも同じ結果。ノート行の選択や本文のEscは既存の保存を伴うため、この拒否試験では使わない |
| 保存 | `:w`後も編集モード。戻り先は開く前の区画。同一本文の再保存ではmdと履歴を更新しない |
| Undoと比較 | 保存後に本文のUndoで以前の文字へ戻す。`:q`は保存済み本文との差を検出して拒否する |
| 保存して終了 | `:wq`、`:x`、×、Alt+F4でそれぞれ保存後に終了。保存または履歴に失敗した場合は本文と窓が残る |
| 明示的な破棄 | 保存済みmdのhashを記録後、架空の文字を追記して `:q!`。ディスクと履歴が変わらず終了する |
| 未知コマンド | `:unknown`、`:w extra`。入力を消さず理由を表示。空のEx入力は取消 |
| Help・再呼出 | `:help`は検索可能な同じパレット。ExからCtrl+Pへ切替。繰返しCtrl+Pで面が増えない |
| INDEXの? | `?`と`:help`で同じコマンド・キーバインドが表示される。EscはINDEXへ戻り、md・履歴を変更しない。本文・入力欄の`?`は文字として残る |
| ヘルプの寸法 | 最小窓と120/144 DPIで、5候補、説明7行、拒否文言の領域が重ならず下端まで読める。説明文のクリックで操作を実行しない |
| マウスとフォーカス | 候補行クリック、入力面外の本文/INDEXクリック、続くCtrl+P。表示中の行がクリックを受け、入力へ戻れる |
| 重なりと再描画 | パレット表示中に本文と索引をスクロール/再描画。パレットと入力文字が裏側に消えない |
| 入力面のIME | 日本語の変換確定に使うEnterで命令を実行しない。変換中のEscでは入力面を閉じず、上下キーはIMEへ渡す。変換中のCtrl+Pで入力が消えたり一覧へ切り替わったりしない。変換確定・取消後にはEnter/Esc/Ctrl+Pが通常どおり使える |
| 本文のIME | 未確定の日本語を入力し、Esc・Ctrl+P・Ctrl+Sを個別に確認する。変換取消で本文を保存したりINDEXへ移ったりしないこと、一覧の開閉で未確定本文を失わないこと、保存される本文の範囲を記録する。IME/TSFの処理で親へ届くキーが変わり得るため、IME名と設定も記録する |
| 寸法 | 最小560×360（96 DPI相当）と120/144 DPI以上で、×・札・パンくず・入力・候補・拒否文言が収まる |

現在の自動テストが示すのはcore/applicationの動作とゲートの成功範囲。GUIの結果をそれらから推定して合格にしない。
