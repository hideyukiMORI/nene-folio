# 日本語GUI入口の実機確認（#49 / ADR0018）

対象: `out/worktrees/49-gui-entry/build/NeNeFolio.exe`。同じ場所のdataは#45で使った架空データのコピー。
自動検査と実機を区別する（QLT-013）。15:45 JSTのComputer Useはnative pipe unavailable / os error 2で、以下は未確認。
実行exeのSHA-256・DPI・窓寸法・IME名と結果は確認時にPRへ記録する。

計算上の確認: 最小560×360の配置式を96〜384 DPIの整数289通り、説明の開閉2通りで評価した。
展開中に候補0行になる端数問題を、説明下の余白を8pxにして解消。578条件で閉じた時5行以上、開いた時1行以上を確認した。
実フォント・Windowsの描画・クリックを試した結果ではない。

| 手順 | 期待する結果 |
| --- | --- |
