# Powerline風パンくずの実機確認の手順と結果

Issue #45 / ADR 0017。対象は `out/worktrees/45-powerline/build/NeNeFolio.exe` と架空の検証データ。
Computer Use接続はnative pipe unavailable / os error 2。以下の表は確認項目で、hideによる手動確認の結果を末尾に記録する。

| 条件 | 確認すること |
| --- | --- |
| 未選択 | パンくずは空で、札・×と背景が正しく描画される |
| 通常幅・dark/light | 番号→カテゴリ→ノートが矢印でつながり、本文地へ続く |
| 長い名前 | まずノート名、次にカテゴリ名を省略。名前の文字が矢じりや操作札へ重ならない |
| 最小560×360 | 番号と操作札を保つ。カテゴリ幅0なら番号→ノートの2区画。右端の×が使える |
| 色変更 | 白・黒・明るい色・暗い色で番号の字が読める。台帳の色は選んだ値のまま |
| 120/144 DPI | 矢じり・文字・札が欠けず、省略順が維持される |
| リサイズ・再描画 | 旧位置のパンくずや縁が残らず、背景・本文が点滅しない |
| 入力面 | `?`・Ctrl+P・Exを重ねても裏へ消えず、Escの戻り先・本文・Undoを保つ |
| 操作 | パンくずで窓を掴める。閲覧・編集・×の当たり判定と動作は従来どおり |

実行した場合はexeのSHA-256、DPI、窓寸法、各条件の結果を追記する。Chromeの画面案を実機合格に読み替えない。

番号4として「長い名前のノートを開き、窓の横幅を縮める。上の文字が右側のボタンに重ならず、
ノート名から先に省略されるか」を案内し、hideから「オッケー」と報告された。
