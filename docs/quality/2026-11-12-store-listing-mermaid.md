# Store掲載文でMermaidの図を2番目の柱にする（#803）

## 根拠

hideが2026-11-12の対話で「mdツールとしてアピールしているが、マーメイド図もアピールポイントとして押し出したほうがいいかも」と述べ、
提案に対して「進めて」と依頼した（[Issue #803](https://github.com/hideyukiMORI/nene-folio/issues/803)）。
公開中の原稿（[#787の記録](2026-11-07-store-listing-current.md)）でのMermaidの扱いは次のとおりだった。

| 欄 | 訂正前 | 訂正後 |
| --- | --- | --- |
| 短い説明 | 「画像と図」。Mermaidの語なし | Mermaidと、フローチャート・シーケンス図を明記 |
| 製品の機能 | 8項目。画像と同じ2番目の項目の後半 | 9項目。Mermaidを2番目、画像を3番目に分ける |
| 説明 | 「画像と図を添える」の2文目 | 冒頭の段落に1文、独立した節を2番目に置く。画像は次の節 |
| 説明の末尾 | 一部の記法に対応 | 加えて、クラス図・ガントチャートなど他の種類は非対応と明記 |
| 検索キーワード | 原稿の正本に無い | `keywords`を追加。7語のまま2語を入れ替える案 |

主役はMarkdownノートのまま保つ。冒頭の1行目と「書いて、読み返す」の節は変えていない。

## 掲載する内容と照合先

Mermaidの節は[Markdownの対応範囲](../MARKDOWN.md)の「Mermaidの図」と[ADR0089](../adr/0089-native-lazy-mermaid.md)に合わせた。

| 掲載文の主張 | 照合先の記述 |
| --- | --- |
| `mermaid`と指定したコードブロックを閲覧時に図として表示 | 小文字の`mermaid`を指定したコードブロックを閲覧時に表示 |
| 分岐・戻りのある流れ、サブグラフ | 辺の連鎖、戻り辺・自己辺、入れ子のサブグラフ |
| 参加者どうしのやり取り、注釈、繰り返しや条件分岐の枠 | メッセージ、`Note`、`loop` / `alt` / `opt`等の枠 |
| 現在のテーマの配色に合わせる | 配色は現在のテーマ |
| 本文を先に表示してから図を仕上げる | 本文を先に表示し、画面の近くにある図から進める |
| スクリプトを実行せず、外部へ通信しない | JavaScript・callbackを実行せず、図から外部の画像やURLを取得しない |
| ノートに原文が残る | 編集・保存・書き出しにMermaidの原文を保つ |

`docs/MARKDOWN.md`、`docs/TRANSFER.md`、`src/core/ui_text.c`は公開tag `v1.3.2`から変わっていない。
Mermaid.jsと同じ見た目になること、全ての記法や図の種類への対応、表示の速さは掲載文に書いていない。
