# 2026-11-19 ガントの`inclusiveEndDates`と、#1030の独立レビュー（#1032 / ADR0115）

## 何をしたか

- `inclusiveEndDates`を読む。書くと、日付で書いた作業の終わりがその日を含む（終わりを1日後ろへ）。図のどこに書いても全体に効く。期間（`Nd`）と`until`の終わりは変わらない。
- #1030（`weekday`・`weekend`）と合わせて、読み取りだけの独立レビューを受けた。

次の版で、1.5.0の候補には入らない。

## 独立レビュー

レビュー席はMermaidの文法（gantt.jison）の全文と、ganttDb.js・ganttRenderer.jsの該当部分を取得して照らした。
#1030の品質記録に「設計席の記憶による」と書いた点は、原文で確かめられた: `weekday`の既定は日曜。`weekend friday`は金・土で、既定は土・日。文法は大文字小文字を区別しない。

| 指摘 | 対応 |
| --- | --- |
| 欠陥（#1030）: 名前が`weekday`・`weekend`で始まる作業の行（例: `Weekend deploy :2026-11-07, 2d`）を、指示語の誤りとして不正にしていた。Mermaidの字句は`weekday 曜日`と`weekend friday｜saturday`だけを指示語にし、ほかは作業の行として読む | 後ろがその形でなければ作業の行へ回すようにした。`:`の無い形は、作業の行として従来どおり不正になる |
| 欠陥（#1032）: `inclusiveEndDates`の後ろの文字を黙って捨てていた（部分的な図になる） | 後ろに文字があれば未対応にした。Mermaidはそれを別の作業として読む |
| ADRに、`weekday`が自動で選ばれた週の目盛りにも効くことが無い（Mermaidは`tickInterval`が週のときだけ） | 「Mermaidとの違い」に足した |
| 小: 古い注釈（「週は月曜から」、指示語の一覧） | 直した |
| 小: ADRで、足した指示語の説明が「未対応」の節の下にあった | 「後から足した指示語」の節にまとめた |
| 小（#992から。レビュー席の記憶で、原文では未確認）: 2週以上の`tickInterval`は、d3では暦の週の通し番号にそろうので、図の最初の目盛りから数えるこのアプリと1週ずれることがある | 直さず、「Mermaidとの違い」に未確認と明記して足した |
| 小: 試験の置き場所（`gantt_until`の中） | 新しい試験は`gantt_week_words`に分けた。先に入れたものは動かしていない |
| 試験の不足 | 足した。内容は下の一覧 |

足した試験:
- `weekday`・`weekend`で始まる作業の行。
- 同じ指示語を2回書くと、後のものが効く。
- 水曜の目盛り（図の始まりから6日先）と、図の始まりと同じ曜日の目盛り。
- `inclusiveEndDates`と週末の除外で、金曜に終わる作業の終わりが動かず、次の作業が除外日の土曜から始まる。
- 同じ図の`until`が、`inclusiveEndDates`で変わらない。
- `inclusiveEndDates`の後ろに文字がある行（未対応）。
- `weekday monday tuesday`（不正）。

レビュー席は、試験の期待値を手で数え直した。週末の2つの試験は、Mermaidの`fixTaskDates`をたどって確かめた。
直した後の単体の試験は1回目で通った。
