# 2026-11-19 閲覧の段落と原文の行の対応表（#1008 / ADR0116）

## 何をしたか

ADR0106が次の段階とした閲覧の右クリックの「ここを編集」「Markdownとしてコピー」の土台。coreの描画が、ブロックごとの原文の範囲と、閲覧欄に残す段落の記号の数を記録する。
画面には何も出ない（第2・第3段階は予定）。1.5.0の候補には入らず、通常exeへも反映しない（hideの実機確認の対象を変えないため）。

| 段階 | 結果 |
| --- | --- |
| 計画 | 読み取り専用の計画席が、4つの方式（描画と同じ一巡の表、段落の書式に番号、近い見出し、coreで文字位置を数える）を比べ、表を推した。計画はD:/NeNeFolio/agents/source-map-20261119/plan-20261119.md |
