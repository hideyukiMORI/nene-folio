| リストの項目の次の行が`#`だけ（字下げなし） | 項目の段落の続き | リストを閉じて、外の空の見出し |
| `#`の次の行が`===`や`---` | 「#」という見出し（下線の書き方） | 空の見出しと、段落「===」または罫線 |
| `#`の次の行が表の区切りの行 | 1列の表（頭の行が「#」） | 空の見出しと、段落 |
| 表の本体の次の行が`#`だけ | 表の行 | 表を閉じて、空の見出し |
| `#`の次の行がリンクの定義 | 定義にならず、本文に出る | 定義として読まれ、本文から消える |

試験で固定したのは、上の3つ（引用・リスト・`===`）。表とリンクの定義の場合は、試験に入れていない。

レビューが挙げた、前からある弱点（この差分の欠陥ではない。`# `＝空白つきの空の見出しで、前から同じ）:
- ノートの最後が空の見出しだと、目次（アウトライン）に出ない見込み（途中の空の見出しは1行として出る）。コードと文書からの読みで、実画面では確かめていない。
- 途中の空の見出しは、目次で文字の無い行になる（押せるし、キーでも選べる）。読み上げでは名前の無い項目になる。
