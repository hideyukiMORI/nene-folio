# 隣り合うコードブロックの間の隙間の品質記録 — 2026-11-23

Issue #1205。hideが候補（main `f7d673f`）で見つけた: 囲いのコードのすぐ後ろ（空行を挟んで）に字下げのコードを書くと、2つが1つの箱につながって見える。

## 原因

コードの面は、コードの行の背景色が、段落の前後の余白（最後の行の`\sa120`、最初の行の`\sb120`）まで塗られることで箱に見えている。間に何も表示しないまま次のコードブロックが始まると、2つの余白が同じ色でつながる。

**囲いのコードが2つ続く場合も、直す前はつながっていた**（Issueでは未確認としていた。直す前の候補の構築を別のdataで起動して撮った絵で確かめた）。

## 何を変えたか

- コードブロックのすぐ後ろ（間に何も書かれていない）で次のコードブロックが始まるとき、次のブロックの最初の段落の前に、地の色の細い行（6pt）を1つ書く（`src/core/markdown_blocks.c`の`open_code`・`part_code`・`close_code`）。
- 「すぐ後ろ」は、出力の長さで見分ける: 前のコードブロックを閉じたときの長さと、次を開くときの長さが同じなら、間に何も書かれていない。空行・リンクの定義・脚注の定義は何も書かないので隣り合う。リストの印の行・段落・表・区切り線・図が入れば、隣り合わない。
- 何も表示しない空の囲い（言語名もコードの行も無い）は、行を書かず、前のコードブロックを「最後のブロック」のまま残す。空の囲いを挟んだ2つのブロックの間の行は1つ。
- Mermaidの図は面の色を持たないので、前後に行を置かない。
- 原文の対応表（「ここを編集」「Markdownとしてコピー」）: 細い行は、次のブロックの最初の記録（見出しの行、見出しの行が無ければ最初のコードの行）に数える。表の前の詰め物と同じ扱い。閉じの囲いと、見出しの行の無い囲いの開きは、段落を持たないまま。
- 閲覧表示の文字に、ブロックの間の空行が1つ増える（範囲を選んだコピーに入る）。原文・編集表示・コードのコピーの中身・コピーの通し番号は変わらない。
