# NeNe Folio 0.2.0 — ベータ版

Windows x64向けの、インストール不要なMarkdownノートです。
v0.1.0以降の画面・操作・アクセシビリティ・応答性の改善をまとめました。
配布物は[v0.2.0 Release](https://github.com/hideyukiMORI/nene-folio/releases/tag/v0.2.0)のAssetsから取得できます。

## 主な変更

- 設定を独立した画面へ集約。125種の追加テーマを検索でき、候補の配色を保存前にプレビューできます（#286、#294、#364、#366）。
- 一覧・両方・ノートの3表示と、Ctrl+Shift+1 / 2 / 3による切替を追加。一覧から戻すと窓幅も復元します（#290、#292）。
- カテゴリ追加と新規ノートの入口、本文操作帯、保存状態の表示を整理。メニュー・ヘルプ・名前入力などの外形と操作を揃えました（#288、#302、#344、#348、#349、#350、#351、#379、#381）。
- 本文をCtrl+ホイール、Ctrl++ / Ctrl+-で50～300%に拡大・縮小できます。Ctrl+0で100%に戻ります。閲覧と編集で倍率を保ち、行番号も追随します。倍率は起動中だけの表示状態です（#383）。
- ノート内検索欄を本文上部へ移動。全ノート検索へ移る際は、名前付きの編集中ノートを先に保存します。無題の編集中ノートは検索対象に含めません（#306、#342）。
- 全ノート検索の初回準備を一件ずつ進め、その間も入力・描画を処理します。準備中表示の後に、最新の検索語の結果をまとめて表示します（#369）。
- 未保存の無題ノートから離れるときに「保存しない」を選べます。取消では本文とUndoを保持します（#298）。
- 基本画面と補助画面のUI Automation公開、Windowsの高コントラスト配色への追随を追加しました（#319、#320、#321）。

## 修正と応答性

- 編集時の行間・行番号のずれ、検索欄の文字欠けを修正しました（#340）。
- 空状態で描画が繰り返される不具合を修正し、本文が無効な状態でもテーマ背景を保ちます（#356、#377）。
- 文字の計測結果と候補の対応を再利用し、可視行だけを描画。連続入力中や補助画面を開いた際の応答を改善しました（#368、#373、#375）。
- 全ノート検索の本文探索と部分一致の比較を改善しました（#328、#331）。
- Windows終了へ同意する前に編集中の本文を保存し、読み込み未完了の本文を編集・保存へ渡さないようにしました（#309、#310）。
- メモリ確保サイズの加算・乗算前にオーバーフローを検査します（#311）。

## ダウンロードと起動

Assetsの`NeNeFolio-0.2.0-win-x64.zip`と`SHA256SUMS`をダウンロードしてください。
ZIP全体を新しい書き込み可能なローカルNTFSフォルダへ展開し、`NeNeFolio.exe`を起動します。
`fonts/`はexeの隣に置いたままにしてください。インストールやネットワーク接続は不要です。
Windows 10 version 2004以降のx64向け、署名なしのportableパッケージです。

初回は`data/`なしで起動できます。カテゴリを追加してノートを作成すると、exeの隣へ保存されます。
ノート・カテゴリ順・設定・保存履歴は`data/`にあります。

## v0.1.0からの更新

1. アプリを終了し、現在の`data/`フォルダをバックアップします。
2. 新しいZIPを別のフォルダへ全体ごと展開します。
3. 古い`data/`を新しいexeの隣へコピーして起動します。

稼働中のアプリやデータへ上書きしないでください。
未完了の`data/.rename.json`がある場合は古いexeへ戻さないでください。

## 既知の制約と確認範囲

- 大量ノートの初回検索では、全本文の準備に時間がかかります。一件のファイルI/O・UTF-8検証と最後の一致計算は同期処理のままで、待ち時間の上限は保証しません。入力が続くと準備完了が遅れます。
- 合成10,000ノート×10KiBの計測では、初回入力処理は約0.47msでした。一方、確認用messageと描画要求を加えた条件では準備・描画完了まで約140秒かかっています。全件読込の高速化や全環境の応答保証を意味しません。条件・比較方法は[初回検索の品質記録](../quality/2026-10-25-first-search-responsiveness.md)を参照してください。
- 対象単体・native試験と必須CIの結果を根拠にしています。専用desktopでの合成入力・PrintWindowによる描画確認は、物理IMEの候補操作、人による読み上げの聴取、DWMによる実画面呈示の確認とは区別しています。これらは今回の公開時点で未確認です。
- 署名、インストーラ、自動更新はありません。β版として不具合報告を受け付けます。
