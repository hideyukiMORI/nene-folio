# NeNe Folio 0.2.0 — ベータ候補

v0.1.0以降に加わった操作・表示・アクセシビリティ対応をまとめたWindows x64向けportable版です。
この文書は配布準備用です。公開状況は[Releases](https://github.com/hideyukiMORI/nene-folio/releases)で確認してください。

## 主な変更

- 設定を中央の独立した画面へ集約し、検索できる125種の追加テーマを用意しました（#286、#294）。
- カテゴリ追加の固定ボタンと、新しいノートの作成先を選ぶ操作を追加しました（#288、#302）。
- 一覧・両方・ノートの3表示と直接ショートカットを追加しました。一覧表示から戻すと窓幅も復元します（#290、#292）。
- 未保存の無題ノートを離れるとき、保存しないで進む選択ができます（#298）。
- ノート内検索欄を本文上部へ移しました（#306）。
- 基本画面と補助画面のUI Automation公開、OSの高コントラスト配色への追随を追加しました（#319、#320、#321）。
- 全ノート検索の本文宛先探索と部分一致の比較を改善しました（#328、#331）。

## 修正

- 編集時の過大な行間と行番号のずれ、全ノート検索欄の文字欠けを修正し、新規ノートボタンの配色を整えました（#340）。
- 全ノート検索へ移ると名前付きの編集本文を先に保存します。無題では保存先を尋ねず、検索対象外のまま進めます（#342）。

- Windows終了へ同意する前に、編集中の本文の保存を完了します（#309）。
- 読み込みが完了していない本文を編集・保存へ渡さないようにしました（#310）。
- メモリ確保サイズの加算・乗算前にオーバーフローを検査します（#311）。

## 起動と更新

ZIPを新しい書き込み可能なローカルNTFSフォルダへ全体ごと展開し、`NeNeFolio.exe`を起動します。
`fonts/`はexeの隣に置いたままにしてください。インストールやネットワーク接続は不要です。
Windows 10 version 2004以降のx64に対応する、署名なしのportableパッケージです。

更新時はアプリを閉じ、現在の`data/`をバックアップしてから、新しい展開先へコピーします。
稼働中のアプリやデータへ上書きしないでください。ノート・カテゴリ順・設定・保存履歴は`data/`にあります。
今回の変更で新しい保存schemaを追加していません。未完了の`data/.rename.json`がある場合は古いexeへ戻さないでください。

## 確認範囲と残る項目

対象試験と最終headの必須CIに加え、Releaseの配布物・dataなし起動・設定の版表示を確認します。
最初の候補は[#338の品質記録](../quality/2026-10-18-beta-candidate.md)、実機フィードバック後の更新は
[#342の品質記録](../quality/2026-10-18-filter-focus-save.md)を参照してください。

現在のRelease測定では、合成10,000ノート×10KiBの初回検索は中央値719ms、不一致の後続検索は52msでした。
全件一致は212msで大半が一覧描画です。大量の一致行があると描画・スクロールに待ち時間が残ります。
条件・p95/最大・限界は[検索応答の品質記録](../quality/2026-10-18-release-response.md)に記載しています。
この値はWindows 11・120 DPIの専用desktopでGDI描画が終わるまでの観測で、全環境の応答保証ではありません。

物理的な日本語IME候補操作と人による読み上げの聴取は、自動試験の合格とは別の確認項目です。
公開前の実機確認手順も品質記録にまとめます。
