# NeNe Folio 0.3.0 — ベータ版

2026-10-27。Windows x64向けの、インストール不要なMarkdownノートです。
v0.2.0から、本文スクロールの修正、Markdownの表示調整と基本構文の追加をまとめました。
[v0.3.0 ReleaseとAssets](https://github.com/hideyukiMORI/nene-folio/releases/tag/v0.3.0)を配布先とします。
公開・ダウンロード検証の確定状態は[今回の品質記録](../quality/2026-10-27-beta-release.md)を参照してください。

## 主な変更

- 閲覧モードでホイールが効かない問題を修正しました。本文をクリックした後も動かなかった条件を含みます。
  バーの外観は隠したままnativeのスクロールと行番号の追随を保ちます（#392）。
- 本文・引用・リストの行間と段落余白を詰めました。h4〜h6は本文と同じ11pt・通常の太さで、見出し色と余白で区別します。
  コードブロックは空行もつながる背景面と余白を持ちます（#394）。
- 表と列の左/中央/右寄せ、表内の行内装飾を追加しました。幅や倍率に合わせてnativeのセルを折り返し、表内・表直後の検索と選択を扱います（#396）。
- 入れ子リスト、引用内のリスト、チェックリスト、取り消し線、`----`などの水平区切り、setext見出し、
  行末2空白またはbackslashによる明示改行を追加しました。番号付きリストは先頭番号から連番で表示します（#396）。
- tilde fenceと長いfence、同じ個数の複数backtickで囲むcode spanを扱います。閉じていない装飾記号は文字として残します（#396）。

記法と範囲は[Markdownの書き方](../MARKDOWN.md)にまとめています。
保存するMarkdown原文、保存schema、設定形式、実行時依存はv0.2.0から変更していません。
表示用の表構造やチェックの印を、保存ファイルへ書き足すことはありません。

## ダウンロードと起動

Assetsの`NeNeFolio-0.3.0-win-x64.zip`と`SHA256SUMS`を取得してください。
ZIP全体を新しい書き込み可能なローカルNTFSフォルダへ展開し、中の`NeNeFolio.exe`を起動します。
`fonts/`はexeの隣に置いたままにしてください。Windows 10 version 2004以降のx64向けです。
署名なしのportableパッケージで、インストールやネットワーク接続は不要です。

初回は`data/`なしで起動できます。Categories（カテゴリ）見出しの`+`からカテゴリを作り、New noteからノートを作成します。
ノート・カテゴリ順・設定・保存履歴はexe隣の`data/`に保存します。保存先を変更する設定はまだありません。

## 旧ベータからの更新

1. 旧版で編集中の本文を保存してアプリを終了し、現在の`data/`フォルダ全体をバックアップします。
2. 新しいZIPを旧版とは別のフォルダへ、全体ごと展開します。
3. 旧版の`data/`を新しいexeの隣へコピーして、新しいexeを起動します。ノートと設定を確認するまで旧フォルダとバックアップを残してください。

稼働中のアプリやデータへ上書きしないでください。
未完了の`data/.rename.json`がある場合は、その処理を完了するまで古いexeへ戻さないでください。
今回の更新でノートを別の保存先へ自動移動することはありません。

## 既知の制約

- 完全なCommonMark/GFM互換ではありません。list内にquoteを置き、その後に同じ親listの継続本文へ戻る組合せでは、引用前の字下げや親listへの復帰を保証しません。
- native表は63列までです。63列を超える表は、先頭列だけに切らず、表全体を原文の行境界とともに文字として表示します。
- リンクは色と下線による表示です。クリックして外部ページを開く機能はありません。チェックの印も閲覧用で、クリックでは切り替わりません。
- HTML描画、画像埋込み、数式、脚注、wiki記法等は対応していません。記法の詳細は[対応範囲](../MARKDOWN.md)を参照してください。
- ノート本文は16 MiBまでで、NULを含む本文は受け付けません。大量ノートの初回検索では準備に時間がかかり、一件分のI/Oと最後の一致計算は同期処理です。
- 署名、インストーラ、自動更新は提供しません。物理IME、実readerの聴取、全OS/テーマ組合せを一括して受理したものではありません。

問題を報告する際は[Issues](https://github.com/hideyukiMORI/nene-folio/issues)へWindowsの版、再現手順、期待した動作を記載してください。
私的なノート本文は含めないでください。
