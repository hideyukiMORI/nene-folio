# NeNe Folio 1.1.0 — ベータ版

2026-11-01。Windows 10 version 2004以降のx64向けです。
0.3.0からの機能追加と、hideが実機で受理した表示・応答速度の改善をまとめています。
[GitHub Release](https://github.com/hideyukiMORI/nene-folio/releases/tag/v1.1.0)のAssetsにZIPとSHA256SUMSを用意します。
Store向けは別のMSIX提出候補です。候補の生成は、提出・認定合格・Store公開を意味しません。
公開と配布検証の確定記録は[品質記録](../quality/2026-11-01-release-1.1.0.md)から参照できます。

## 主な変更

- 本文右側に簡易ミニマップを追加しました。見出し・リスト・表・水平線・コードブロックの概形と現在範囲を示し、クリック・ドラッグ・ホイールで移動できます。設定またはCtrl+Shift+Mで切り替えます。狭い表示では自動で隠れます。
- UTF-8のMarkdownを複数取り込めます。現在のノートをMarkdownへ、保存済みカテゴリや全ノートをZIPへ書き出せます。既存の同名ノートや出力は上書きしません。ZIPはノート本文だけで、設定・順序・履歴を含むバックアップ形式ではありません。
- Ctrl+Eで閲覧／編集を切り替え、Ctrl+Mで操作メニューを開けます。閲覧へ戻る前に保存します。ヘルプのキー一覧を用途別に整理し、操作対象のポインタとボタンの反応も揃えました。
- 設定でノートの保存先を選べます。変更は次回起動から有効になり、ノートは自動移動しません。一覧と本文の境界もドラッグやキーで調整できます。
- 閲覧中のHTTP/HTTPSリンクをクリックまたはCtrl+Enterで開けます。文字選択のドラッグや編集中には開きません。
- Markdownの改行、引用・リストの組合せ、表の列配置を改善しました。山括弧付きURI/email、数値と基本6種の文字参照を表示し、水平線の上下に余白を設けました。
- ノート切替・検索準備・Markdown変換の重複処理を減らし、ミニマップが表示されるまでの待ち時間を短縮しました。大きな文書や表では本文の読み込みに時間がかかる場合があります。

詳細は[Markdownの対応範囲](../MARKDOWN.md)、[取り込み・書き出し](../TRANSFER.md)、[キー操作](../KEY_BINDINGS.md)を参照してください。

## ZIPの起動と更新

初めて使う場合は`NeNeFolio-1.1.0-win-x64.zip`全体を、書き込み可能なローカルNTFSの新しいフォルダへ展開し、`NeNeFolio.exe`を起動します。
`fonts/`などの同梱物を残してください。署名なしのportable版です。
初回は`data/`なしで起動でき、カテゴリとノートを作ると保存先に書き込みます。

1. 旧版で本文を保存してアプリを終了します。現在のノート保存先全体を、隠しファイルや`.history/`を含めてバックアップします。
2. exe隣に`nenefolio-startup.json`があれば、それもバックアップします。新版のZIPを旧版と別のフォルダへ展開します。
3. 既定の保存先なら、旧版の`data/`を新しいexeの隣へコピーします。保存先を変更している場合は、`nenefolio-startup.json`を新しいexeの隣へコピーすると同じ保存先を使えます。
4. 新版を起動し、保存先・ノート・設定を確認します。確認が済むまで旧フォルダとバックアップを残してください。

稼働中のexeやノートへ上書きしないでください。保存先の設定変更だけではノートは移りません。
ノートのMarkdown形式は維持します。設定は版5となり、旧版1〜4を読み込めます。
旧exeは新しい設定を読めない場合があるため、ダウングレード時はバックアップを使ってください。
未完了の`.rename.json`がある場合は、その処理が完了するまで旧exeへ戻さないでください。

## 制限

- 完全なCommonMark/GFM互換ではありません。HTML描画、画像埋込み、Mermaid、コードの構文色分けは未対応です。
- native表は63列までです。超過した表は全体を原文として表示します。チェックリストの印はクリックで切り替えられません。
- 本文は16 MiBまでで、NULを含む本文を受け付けません。ミニマップは最大256行を抽出する概形です。
- ZIP版は自動更新・署名付きインストーラを提供しません。Store版の配信状況とは別に扱います。

問題は[Issues](https://github.com/hideyukiMORI/nene-folio/issues)へ、Windowsの版と再現手順を添えて報告してください。私的なノート本文は含めないでください。
