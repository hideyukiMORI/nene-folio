# NeNe Folio 1.2.0 — Microsoft Store更新候補

2026-11-03。Windows 10 version 2004以降のx64向けです。
1.1.0以降にhideが実機で受理した改善を、Store向けの1.2.0（Windows版1.2.0.0）へまとめます。
MSIX生成とStoreの提出・認定・公開は別段階です。現時点の確定状態は
[品質記録](../quality/2026-11-03-store-release-1.2.0.md)の完了原本を参照してください。
GitHubの既存1.1.0 Betaはこの作業では更新しません。

## 主な変更

- Markdown内のPNG/JPEG画像を表示します。ローカルパスとHTTPS URLに対応し、本文を先に表示してから画像を読み込みます。画像の縦横比を保ち、本文幅や表セル幅へ収めます。
- 画像を含むノートのホイール移動とミニマップを改善し、読み込み完了後に残っていた通知を解消しました。
- コードブロックの言語指定に応じて基本的な構文色分けを行い、左上に指定した言語名を表示します。未知の名前や大小文字は入力どおりに残し、言語未指定ではラベルを表示しません。
- 常設ステータスバーに保存ファイルの更新日時・作成日時とヘルプ/コマンドのキー案内を表示します。未保存ノートや取得できない日時も区別します。
- アンバー色の新しいアプリアイコンへ更新します。角外の透過を持つ同じSVGから、Windowsの各表示サイズに必要なICOとStore用画像を生成しています。

ノートのMarkdown形式、保存schema、Store identityは1.1.0から変更しません。
詳しい範囲は[Markdown仕様](../MARKDOWN.md)、[取り込み・書き出し](../TRANSFER.md)、
[キー操作](../KEY_BINDINGS.md)を参照してください。

## Storeでの更新

公開後はMicrosoft Storeの更新経路で配布します。更新前に編集中の本文を保存し、アプリを終了してください。
設定で選んだノート保存先全体は、履歴・設定・画像を含めてバックアップしてください。
今回の提出用MSIXは未署名で、Storeが公開時に署名する原本です。手動インストール用の配布物ではありません。
提出原本の恒久パスとSHA256、アップロード・審査の実際の状態は品質記録から参照できます。

## 制限

- 構文色分けは基本的な字句分類です。完全な構文解析や編集中のリアルタイム色分けではありません。
- 画像はPNG/JPEGに限ります。HTTPS画像は外部ホストへアクセスします。元画像の自動コピーや画像を含むZIP書き出しは行いません。
- Mermaid、HTML描画、SVG/GIF/WebP、CommonMark/GFM全構文の完全互換は未対応です。
- 全Windows shell cache・独自DPI・実screen readerの組合せを検証したものではありません。
- 既存MSIX試験のWACK総合WARNING、AppDataを任意選択した場合のノート保持、実Store署名版の導入に関する限界は
  [MSIX品質記録](../quality/2026-11-01-msix-installation.md)に残しています。

掲載用の更新説明は[日本語・英語・簡体字](1.2.0-store-notes.txt)を用意します。
