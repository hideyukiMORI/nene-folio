# NeNe Folio 1.3.0 Beta

2026-11-04。Windows 10 version 2004以降のx64向けです。
GitHubの1.1.0 Betaからは1.2.0の改善も含みます。Storeの1.2.0からはMermaidと今回の品質改善が加わります。
公開済みの配布物は[GitHub Releases](https://github.com/hideyukiMORI/nene-folio/releases)で確認できます。
配布生成・起動確認・公開とStore申請の状態は[品質記録](../quality/2026-11-04-release-1.3.0.md)を参照してください。

## 主な変更

- Mermaidのフローチャートとシーケンス図を表示します。本文を先に表示してから図を読み込み、現在のテーマと書体で描画します。編集・保存・書き出しでは図の原文を保ちます。
- 図のラベルのはみ出し・欠落・重なり、矢印や接続線、自己辺やグループの表示を改善しました。
- PNG/JPEG画像、コードの基本的な構文色分けと言語ラベル、保存ファイルの日時を示すステータスバー、新しいアプリアイコンを含みます。
- ZIP書き出しに、本文が参照するカテゴリ内の`images/`ファイルを同梱します。ほかのローカル画像は確認後にまとめられます。出力するMarkdownのコピーだけを変更し、元のノートと画像を保ちます。HTTPS参照はURLのままです。
- 括弧やbacktickを含む画像記法の扱いと、ZIP内の画像パス衝突の検出を修正しました。
- 画像キャッシュと、多数の画像名の決定・ZIPのCRC計算を改善し、対象処理の待ち時間を減らしました。

ノートの保存形式、設定schema、Store identityは変更しません。
対応構文と上限は[Markdown](../MARKDOWN.md)、[取り込み・書き出し](../TRANSFER.md)、操作は[キー一覧](../KEY_BINDINGS.md)を参照してください。

## ZIPでの更新

1. 編集中の本文を保存してアプリを終了します。
2. ノート保存先全体を、画像・隠しファイル・`.history/`を含めてバックアップします。exe横に`nenefolio-startup.json`がある場合はそれも保管します。
3. ZIPを新しい書き込み可能なローカルNTFSフォルダーへ展開します。既存の起動中exeへ上書きしません。
4. 既定の保存先ならバックアップした`data/`を新しいフォルダーへコピーします。独自の保存先なら`nenefolio-startup.json`を新しいexeの横へコピーして、同じノート保存先を指定します。
5. `NeNeFolio.exe`を起動し、設定の版が1.3.0であることを確認します。`fonts/`はexeの横に置きます。

ZIPは未署名のportable betaです。`SHA256SUMS`でダウンロードしたファイルのSHA256を照合できます。
設定で保存先を変える操作は、既存ノートを自動移動しません。

## Microsoft Store

MSIXはStore提出用の未署名原本です。手動インストール用ではありません。
生成成功とStoreの提出・認定・公開は別の段階であり、公開後はStoreの更新経路で配布します。
掲載用に[日本語・英語・簡体字の更新説明](1.3.0-store-notes.txt)を用意します。

## 制限

- Mermaidはフローチャートとシーケンス図の文書化された範囲に対応します。Mermaid.jsとの完全互換や同じ配置は保証しません。未対応構文や上限超過は案内を表示します。
- 画像はPNG/JPEGです。SVG/GIF/WebP、HTML描画、CommonMark/GFM全構文の完全互換は対象外です。HTTPS画像は外部ホストへアクセスします。
- ZIPは無圧縮・完成サイズ128MiB・65,534ファイルまでです。設定・履歴・カテゴリ順・未保存の本文を含む完全バックアップではありません。
- 大量のノートや大きな文書、極端に狭い表の表示・検索準備には待ち時間や表示上の制約が残ります。
- 過去のMSIX試験のWACK総合WARNINGとAppData保存先・Store署名版の導入に関する検証限界は[MSIX品質記録](../quality/2026-11-01-msix-installation.md)に残しています。
