# NeNe Folio 1.3.1 Beta

2026-11-05。Windows 10 version 2004以降のx64向けです。
1.3.0からの不具合修正と処理速度・検証の改善をまとめました。
配布物は[GitHub Releases](https://github.com/hideyukiMORI/nene-folio/releases)、
配布生成・起動確認・公開の状態は[品質記録](../quality/2026-11-05-release-1.3.1.md)で確認できます。

## 修正

- 保存前の表示準備がメモリ不足で失敗したとき、本文を保存していないのに保存履歴だけを進める問題を修正しました。表示準備が成功してから履歴を更新します（#617）。
- 表示設定・起動設定のキーや言語値にNUL文字が含まれる一部の不正値を、正常値として受け入れる問題を修正しました。読み取った文字列全体を検証し、不正な設定を保護する既存の動作を維持します（#628）。

## 処理と検証の改善

- 本文の文字検証、編集時の改行処理、編集可能判定、行番号のための索引作成の処理を改善しました（#616、#620、#647、#651）。
- 多数の段落を含むMarkdownの行参照、行末探索、表候補の判定、コード装飾とRTF数値出力の処理を改善しました（#624、#667、#675、#681、#683）。
- 多数の名前の重複確認と、ノート一覧のクリック位置を探す処理を改善しました（#630、#635）。
- ノート内検索のUTF-16検証を改善しました。検索の一致条件、巡回、件数の意味は変更しません（#693）。
- 取り込みの失敗後の再試行、履歴復元、置換、ノート切替、倍率・設定・テーマ操作、検索や置換下見後のUndo／Redoについて、自動回帰テストを追加・強化しました。

改善量は文書の内容・長さ・操作によって異なり、一部条件では処理時間が増える場合もあります。
全操作の高速化や一定の待ち時間を保証するものではありません。比較条件・不採用候補・残る費用は[11月5日の品質記録一覧](../reports/2026-11-05.md)に残しています。
ノートの保存形式、設定schema、Store identityは変更しません。
Mermaid・画像などの機能と既存制限は[1.3.0の変更一覧](1.3.0.md)、操作は[キー一覧](../KEY_BINDINGS.md)を参照してください。

## ZIPでの更新

1. 編集中の本文を保存してアプリを終了します。
2. ノート保存先全体を、画像・隠しファイル・`.history/`を含めてバックアップします。exe横に`nenefolio-startup.json`がある場合はそれも保管します。
3. ZIPを新しい書き込み可能なローカルNTFSフォルダーへ展開します。
4. 既定の保存先ならバックアップした`data/`を新しいフォルダーへコピーします。独自の保存先なら`nenefolio-startup.json`を新しいexeの横へコピーして、同じノート保存先を指定します。
5. `NeNeFolio.exe`を起動し、設定の版が1.3.1であることを確認します。`fonts/`はexeの横に置きます。

ZIPは未署名のportable betaです。`SHA256SUMS`でダウンロードしたファイルのSHA256を照合できます。
設定で保存先を変える操作は、既存ノートを自動移動しません。

## Microsoft Store

MSIXはStore提出用の未署名原本です。手動インストール用ではありません。
生成成功とStoreの提出・認定・公開は別の段階です。
掲載用に[日本語・英語・簡体字の更新説明](1.3.1-store-notes.txt)を用意しています。

## 残る制限

- 大きな文書や大量ノートの初回検索準備、極端に狭い表の表示には待ち時間や表示上の制約が残ります。
- 貼り付け元の書式が編集面へ混入する場合があります。職場で報告された文字ウェイト混在の原因確定と修正は保留中です（#479）。
- Mermaidは文書化されたフローチャートとシーケンス図の範囲に対応し、画像形式はPNG/JPEGです。対応構文・上限は[Markdown](../MARKDOWN.md)、ZIPの制限は[取り込み・書き出し](../TRANSFER.md)を参照してください。
- 過去のMSIX試験のWACK総合WARNING、AppData保存先・Store署名版の導入に関する検証限界は[MSIX品質記録](../quality/2026-11-01-msix-installation.md)を継続します。
