# NeNe Folio 1.3.2 Beta — 公開前候補

2026-11-06。Windows 10 version 2004以降のx64向けです。
1.3.1以降の貼り付け・編集操作の修正と、検索処理・回帰検証の改善をまとめました。
この版は公開判断用の候補です。生成・起動確認・公開状態は[品質記録](../quality/2026-11-06-release-1.3.2.md)で確認できます。
公開済み配布物は[GitHub Releases](https://github.com/hideyukiMORI/nene-folio/releases)を参照してください。

## 修正

- 編集面への貼り付けをUnicodeの平文に統一し、貼り付け元の字体・大きさ・太字・色・段落揃えが混入する問題を修正しました。Ctrl+V、Ctrl+Shift+V、Shift+Insertと通常の貼り付けで、本文とUndo／Redoを維持します（#479）。
- 編集中にCtrl+R／Ctrl+2／Ctrl+5で段落の揃えや行間だけが変わる問題を修正しました。既存の移動・編集ショートカットは維持します（#709）。
- 選択中ノートのアクセシビリティ上の選択状態が、他の操作項目の更新で未選択へ上書きされる問題を修正しました（#731）。

## 処理と検証の改善

- 絵文字などの後で通常文字列のまとめ検証へ戻り、同じUTF-16文字単位の比較で不要な大小文字変換を省くよう、ノート内検索を改善しました。一致条件・巡回・件数は変更しません（#761、#763）。
- 保存・別名保存・改名・破棄・終了・履歴復元・置換・検索・表示切替について、未保存本文、選択、Undo／Redo、保存履歴を保護する実Windows操作の回帰検証を拡充しました。
- Markdown書き出しの成功・取消と、同名ファイル拒否から別名で成功する復帰を自動検証へ追加しました（#767、#771）。
- 開発時のAddressSanitizerが一部のCRT書き込みを検出できない問題を修正し、統合ツールが確定CI失敗を不要に再送しないよう改善しました（#713、#769）。

検索の改善量は内容と操作に依存し、一部ASCII条件には費用も残ります。[検索比較](../quality/2026-11-06-search-equality.md)と[検証再開の比較](../quality/2026-11-06-search-validation-resume.md)に数値を記録しています。
ノート保存形式、設定schema、Store identityは変更しません。個別試行と検証範囲は[11月6日の日報](../reports/2026-11-06.md)を参照してください。
貼り付け元を制限した合成データでの検証を、職場の全アプリや全Windows版の確認へ広げて扱いません。

## ZIPでの更新

1. 編集中の本文を保存してアプリを終了します。
2. ノート保存先全体を、画像・隠しファイル・`.history/`を含めてバックアップします。exe横に`nenefolio-startup.json`がある場合はそれも保管します。
3. ZIPを新しい書き込み可能なローカルNTFSフォルダーへ展開します。
4. 既定の保存先ならバックアップした`data/`を新しいフォルダーへコピーします。独自の保存先なら`nenefolio-startup.json`を新しいexeの横へコピーして、同じノート保存先を指定します。
5. `NeNeFolio.exe`を起動し、設定の版が1.3.2であることを確認します。`fonts/`はexeの横に置きます。

ZIPは未署名のportable betaです。`SHA256SUMS`でダウンロードしたファイルのSHA256を照合できます。
設定で保存先を変える操作は、既存ノートを自動移動しません。

## Microsoft Store

MSIXはStore提出用の未署名原本です。手動インストール用ではありません。
生成成功とStoreの提出・認定・公開は別の段階です。
掲載用に[日本語・英語・簡体字の更新説明](1.3.2-store-notes.txt)を用意しています。

## 残る制限

- 大きな文書や大量ノートの初回検索準備、極端に狭い表の表示には待ち時間や表示上の制約が残ります。
- Mermaidは文書化されたフローチャートとシーケンス図の範囲に対応し、画像形式はPNG/JPEGです。対応構文・上限は[Markdown](../MARKDOWN.md)、ZIPの制限は[取り込み・書き出し](../TRANSFER.md)を参照してください。
- 過去のMSIX試験のWACK総合WARNING、AppData保存先・Store署名版の導入に関する検証限界は[MSIX品質記録](../quality/2026-11-01-msix-installation.md)を継続します。
