# NeNe Folio 1.4.0 Beta

2026-11-17。Windows 10 version 2004以降のx64向けです。
1.3.2以降のお気に入り・タグ・ノートを探す面・本文の右クリックメニュー・窓の位置の引き継ぎと、MarkdownとMermaidの対応範囲の拡張をまとめました。
[GitHub 1.4.0 Beta](https://github.com/hideyukiMORI/nene-folio/releases/tag/v1.4.0)を公開済みです。生成・起動確認・公開状態は[品質記録](../quality/2026-11-17-release-1.4.0.md)で確認できます。
公開済み配布物は[GitHub Releases](https://github.com/hideyukiMORI/nene-folio/releases)を参照してください。

## 新しい機能

### ノートを整理して探す

- **お気に入り**: ノートの星をクリックするか、操作メニュー・コマンドパレットから付け外しします。お気に入りは各カテゴリの先頭に並び、手動の順番は星の有無それぞれの中で保ちます。
  設定の「お気に入りを先に表示」をオフにすると手動の順番に戻ります。星は再起動・改名・カテゴリ移動の後も残り、Markdown本文・Undo・保存履歴を変えません（#813、#817）。
- **タグ**: ノートにタグを付けて絞り込めます。タグはMarkdownの先頭のfront matterに保存し、閲覧表示には出しません。複数タグのAND/ORと、星・検索との組み合わせに対応します。
  タグの全体の改名・解除は、対象を確認してから行い、途中で失敗したノートを示します（#819、#821）。
- **ノートを探す**（`Ctrl+O`）: 名前のあいまい検索と、保存済み本文の文字どおりの検索を、星・タグと組み合わせて使えます。候補ごとに最初の一致箇所と行番号を原文で確認でき、候補を移動しても編集中の本文は変わりません。
  「一致箇所を開く」で、そのノートを編集表示で開きます（#823、#825、#855）。検索面の外枠・選択の下線・検索中の帯と、動きの演出は設定で切り替えられます（#827）。
- 一覧の検索欄へ`Ctrl+Shift+F`で移動でき、欄の案内にキーを表示します（#855）。

### 本文の操作

- **本文の右クリックメニュー**: 編集表示では「元に戻す／切り取り／コピー／貼り付け／すべて選択」、閲覧表示では「コピー／すべて選択」を出します。閲覧表示のリンクの上では「リンクを開く／リンクをコピー」が加わります。
  `Shift+F10`とアプリケーションキーでも開きます（#883、#900、#908）。
- **コードブロックのコピー**: 閲覧表示のコードブロックの「コピー」で、中身をそのままクリップボードへ写します（#839）。
- **最初の行の↑、最後の行の↓**: メモ帳と同じく、最初の行で↑を押すと文書の先頭へ、最後の行で↓を押すと末尾へ移動します（#854）。

### 窓と設定

- **窓の位置と大きさの引き継ぎ**: 前回閉じたときの位置・大きさ・最大化で開きます。設定の「前回の窓の位置と大きさで開く」でオフにできます。
  記録した位置でヘッダーがどの画面にも十分に入らない場合や、大きさが使えない場合は、初期の位置と大きさで開きます（#891、#904）。
- **このアプリについて**: 設定の最後から、製品名・版・ライセンス・同梱書体と第三者の表示の場所・公式リンク4つ（GitHub、Releases、Microsoft Store、不具合の報告）を確認できます。更新の確認は行いません（#838）。

### Markdown

- 囲まないURL（`https://…`）も閲覧表示でリンクになります（#850）。表示名がURLそのもののリンクもテーマのリンク色で表示します（#852）。
- 参照形式のリンク`[表示][名前]`と画像`![代替][名前]`に対応し、定義の行は閲覧表示に出しません（#861、#863）。
- 脚注`[^名前]`に対応しました。本文の参照は上付きの番号になり、脚注は文書の最後にまとまります。空白4つの字下げで続けた行は同じ脚注に入ります（#869、#878）。

### Mermaid

- **状態遷移図**（`stateDiagram` / `stateDiagram-v2`）: 状態、遷移とラベル、開始・終了の点、`<<choice>>`、複合状態（#872、#876）。
- **ER図**（`erDiagram`）: 実体と属性、関係とラベル。多重度は線の端の記号で示します（#882、#888、#898）。
- **クラス図**（`classDiagram`）: クラスとメンバー、継承・実現・コンポジション・集約・関連・依存、関係のラベル、両端の多重度（#890、#916、#918）。

対応する構文と上限は[Markdown](../MARKDOWN.md)を参照してください。未対応の構文を含む図は、部分的な図にせず、未対応の案内を表示します。

## 修正

- 見出しの中のコード（`` `code` ``）が本文の大きさで表示される問題を修正し、見出しの大きさに合わせました（#853）。
- 日本語などCJKの入力中にも本文の書体が使われるよう修正しました（#783）。
- ノートを探す面が、表示の変わらない待機中に描き直しを繰り返す問題を修正しました（#837、#844）。
- `NeNeFolio.exe`のプロパティに著作権の表示（© 2026 HideyukiMORI）を入れました（#924）。

## 保存形式

- ノート本文（Markdown）の形式は変更しません。
- 星は各カテゴリの台帳（`index.json`）へ保存します。星や並び順を保存したカテゴリの台帳は新しい版（版2）になります。1.3.2以前の版は版2の台帳を読めないので、古い版へ戻す場合は更新前のバックアップを使ってください。
- 設定ファイルは新しい版（版7）で保存します。以前の設定は読めます。1.3.2以前の版は版7の設定を読めません。
- タグはMarkdownの先頭のfront matterに書きます。タグを付けたノートだけが変わります。
- 窓の位置は、起動設定と同じ場所の`nenefolio-window.json`に保存します。削除すると初期の位置で開きます。
- Store identityは変更しません。

## ZIPでの更新

1. 編集中の本文を保存してアプリを終了します。
2. ノート保存先全体を、画像・隠しファイル・`.history/`を含めてバックアップします。exe横に`nenefolio-startup.json`がある場合はそれも保管します。
3. ZIPを新しい書き込み可能なローカルNTFSフォルダーへ展開します。
4. 既定の保存先ならバックアップした`data/`を新しいフォルダーへコピーします。独自の保存先なら`nenefolio-startup.json`を新しいexeの横へコピーして、同じノート保存先を指定します。
5. `NeNeFolio.exe`を起動し、設定の版が1.4.0であることを確認します。`fonts/`はexeの横に置きます。

ZIPは未署名のportable betaです。`SHA256SUMS`でダウンロードしたファイルのSHA256を照合できます。
設定で保存先を変える操作は、既存ノートを自動移動しません。

## Microsoft Store

MSIXはStore提出用の未署名原本です。手動インストール用ではありません。
生成成功とStoreの提出・認定・公開は別の段階です。
掲載用に[日本語・英語・簡体字の更新説明](1.4.0-store-notes.txt)を用意しています。

## 残る制限

- 本文の右クリックメニューからの切り取り・コピー・貼り付けの実行、日本語入力中の右クリック、窓の位置は、自動の試験ではなく公開前の実機確認で確かめました。タスクバーが上・左にある配置での窓の位置は確かめていません。
- Mermaidの円グラフ・ガントなど他の図種、クラス図のジェネリクス・note・namespace、図のスタイル指定は未対応です。
- 字下げによるコードブロックと、閲覧表示でのタスクのクリック切り替えは未対応です。
- 大きな文書や大量ノートの初回検索準備、極端に狭い表の表示には待ち時間や表示上の制約が残ります。
- 過去のMSIX試験のWACK総合WARNING、AppData保存先・Store署名版の導入に関する検証限界は[MSIX品質記録](../quality/2026-11-01-msix-installation.md)を継続します。
