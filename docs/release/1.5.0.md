# NeNe Folio 1.5.0 Beta

2026-11-19。Windows 10 version 2004以降のx64向けです。
1.4.0以降の「見出し」の欄、ノートを探す面のキー操作、一覧からのカテゴリ移動と、MarkdownとMermaid（円グラフ・ガント）の対応範囲の拡張をまとめました。
生成・起動確認は[品質記録](../quality/2026-11-19-release-1.5.0.md)で確認できます。タグ・GitHub Releaseの公開・Storeへの提出は、hideの実機確認の後に行います。
公開済み配布物は[GitHub Releases](https://github.com/hideyukiMORI/nene-folio/releases)を参照してください。

## 新しい機能

### 見出しの欄

- **見出しの欄**（`Ctrl+Shift+O`、または「操作」→「見出しの欄の表示を切り替える」）: 閲覧表示の本文の横に、ノートの見出しを階層ごとに字下げして並べます。
  いま読んでいる見出しに印が付き、行をクリックするとその見出しが本文の先頭に来ます。欄の上のホイールで欄を送れます。
  本文の上の操作列からTabで欄へ入り、↑↓・PageUp/PageDown・Home/Endで選んでEnterで移ります。読み上げソフトでは、階層付きの一覧として読めます。
  欄の開閉は起動している間だけ覚えます。編集表示と、本文の幅が足りない狭い窓では出しません（#977、#980、#982、#988）。

### ノートを探す

- 入力欄にいるまま↑↓で候補を選び、PageUp/PageDownで原文を送れます。原文は折り返して表示します（#933）。
- 空の入力欄で←→、文字があってもAlt+←→で「名前」「本文」を切り替えます。Enterは閲覧表示で開いて一致を選び、Ctrl+Enterは編集表示で開きます（#940）。
- 入力欄に探し方の説明を出し、候補が200件で切れたときは件数の行を出します。演出の長さを約2倍にしました（#928）。

### 一覧

- ノート名の右クリック →「カテゴリを移動…」で、移動先のカテゴリを名前で絞り込んで選べます。ノートを開かずに移ります（#941）。

### Markdown

- **定義リスト**（用語の行の直後に`: 説明`）: 用語をアクセント色、説明の左に細い線で表示します（#971）。
- **脚注**: 脚注の番号をクリックすると脚注へ、脚注の番号をクリックすると本文へ戻ります（#945）。空行の後、空白4つの字下げで複数の段落を書けます（#963）。

### Mermaid

- **円グラフ**（`pie`）: 題・扇・凡例。色はテーマのアクセント色の濃淡です（#955）。
- **ガント**（`gantt`）: 区分ごとにアクセント色の濃淡の棒、済んだ作業は淡く、重要な作業（`crit`）は太い縁、マイルストーンはひし形で描きます。
  日付・`after`・日数／週数・`excludes weekends`・`axisFormat`・`tickInterval`に対応します。
  アプリは今日の日付を読まないので、開始日の無い最初の作業のように、Mermaidが「今日」を使う書き方は未対応の案内になります（#992）。
- **クラス図**: ジェネリクス（`~T~`）を`<T>`として表示します（#938）。

対応する構文と上限は[Markdown](../MARKDOWN.md)を参照してください。未対応の構文を含む図は、部分的な図にせず、未対応の案内を表示します。

## 修正

- 一覧だけの表示との往復で、窓の幅が1ピクセルずつ変わることがある問題を修正しました（#936）。

## 保存形式

- ノート本文（Markdown）・カテゴリの台帳（版2）・設定（版7）の形式は、1.4.0から変更しません。1.4.0へ戻しても読めます。
- 見出しの欄の開閉は保存しません。
- Store identityは変更しません。

## ZIPでの更新

1. 編集中の本文を保存してアプリを終了します。
2. ノート保存先全体を、画像・隠しファイル・`.history/`を含めてバックアップします。exe横に`nenefolio-startup.json`がある場合はそれも保管します。
3. ZIPを新しい書き込み可能なローカルNTFSフォルダーへ展開します。
4. 既定の保存先ならバックアップした`data/`を新しいフォルダーへコピーします。独自の保存先なら`nenefolio-startup.json`を新しいexeの横へコピーして、同じノート保存先を指定します。
5. `NeNeFolio.exe`を起動し、設定の版が1.5.0であることを確認します。`fonts/`はexeの横に置きます。

ZIPは未署名のportable betaです。`SHA256SUMS`でダウンロードしたファイルのSHA256を照合できます。
設定で保存先を変える操作は、既存ノートを自動移動しません。

## Microsoft Store

MSIXはStore提出用の未署名原本です。手動インストール用ではありません。
生成成功とStoreの提出・認定・公開は別の段階です。
掲載用に[日本語・英語・簡体字の更新説明](1.5.0-store-notes.txt)を用意しています。

## 残る制限

- 見出しの欄の読み上げは、読み上げソフト（ナレーター）では確かめていません（自動の試験は読み上げの値まで）。
- ガントは語の大文字小文字を区別し、週の目盛りは月曜から数えます。区分の名前が長いと、次の区分の名前と重なることがあります。時刻を含む日付、月名・曜日名の書式、`click`は未対応です。
- Mermaidの他の図種（journey等）、クラス図のnote・namespace、図のスタイル指定は未対応です。
- 字下げによるコードブロックと、閲覧表示でのタスクのクリック切り替えは未対応です。
- 大きな文書や大量ノートの初回検索準備、極端に狭い表の表示には待ち時間や表示上の制約が残ります。
