NeNe Folio — Microsoft Store package for Windows x64

Windows 10 version 2004 or later is required. Start NeNe Folio from the
Windows Start menu after installation. Keep the installed package intact.

On first launch, confirm the folder for notes. The suggested location is
Documents/NeNeFolio. Categories, Markdown notes, settings and saved history
live in the selected folder. Back up that entire folder.
The gear menu shows the current folder and lets you choose a folder for
the next launch. Changing the location does not copy or move existing notes.

Use the gear icon for theme, language, line numbers and product version.
F1 or Ctrl+P lists commands and keys. Ctrl+S saves; Alt+F4 saves and closes.
Do not use an older binary while the note folder contains unfinished
.rename.json work. Close the app before updating it.

The MIT license is in LICENSE. Third-party notices are in
THIRD_PARTY_NOTICES.txt; bundled Noto font licenses are in fonts/.

This build is an unsigned submission candidate. Package construction alone
does not certify installation, updates, removal, or Store acceptance.
Microsoft Store signs packages it publishes. Local installation testing
requires a separate, explicitly configured deployment/signing environment.
