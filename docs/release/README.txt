NeNe Folio — Windows x64

Extract the whole product folder to a writable local NTFS folder, then start
NeNeFolio.exe. Keep fonts/ beside the executable. No installation or network
connection is required. Windows 10 version 2004 or later is required.

The first launch can start with no data/ folder. Use Actions > New category,
then create a note. The app creates data/ beside the executable when writing.
All notes, category order, settings and saved history stay inside data/.
Back up this folder. To update, close the app, extract the new version to a
new folder, and copy the old data/ folder there; do not overwrite an open app.

Use the gear icon for theme, language, line numbers and product version.
F1 or Ctrl+P lists commands and keys. Ctrl+S saves; Alt+F4 saves and closes.
Do not use an older binary while data/.rename.json contains unfinished work.
