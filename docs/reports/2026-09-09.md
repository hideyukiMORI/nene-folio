## 規約が邪魔になった箇所（緩めずに通した）

10 件の衝突と通し方は [ADR 0004](../adr/0004-first-drawer-slice.md) の表が正本。要点だけ:

- `-Wpedantic` が `_Nonnull` を拒否 → 名指しの `-Wno-nullability-extension` を足して C-004 の注釈を全公開ポインタに付けた
- `symbols.py` の `nenefolio_.*` 許可と CNF-002 の `<stem>_` 接頭辞が両立しない → 許可を消し、アーカイブ内と宣言済み依存で解決してから照合する方式に直した
- ASan と Debug CRT が共存しない → CRT を常に `/MT`。ランタイムは resource dir から lld-link へ明示的に結ぶ
- CMake の既定リンクライブラリが `platformLibraries` を形骸化 → `CMAKE_C_STANDARD_LIBRARIES` を kernel32 だけに絞った（ゲートを強める変更）
- 分岐 90% と C の確保失敗の分岐 → 閾値も除外も触らず、測定ビルドでだけ `-Dmalloc=folio_probe_malloc` で確保失敗を注入して全経路を走らせた（86.29% → 95.03%）
- 2 本目で、測定ビルドの ASan がテスト補助関数の寿命の誤り（stack-buffer-underflow）を捕まえた。正典ビルドの CTest では到達しない経路だった
- 4 本目で、RichEdit が段落の罫線（`\brdrl`）と行内の地（`\highlight` が行全体の箱になる）をデザインどおりに描かない → デザインから外し ADR 0005 に記録
