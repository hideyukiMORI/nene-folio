## #37の変更

規則: ARC-001 / ARC-003 / ARC-004 / ARC-005 / ARC-007 / ARC-008 / ARC-010 / ARC-011、
C-002 / C-005 / C-011 / C-012 / C-014 / C-017、CNF-002、QLT-009 / QLT-013。契約はADR 0016。

| 主なファイル | 変更した振る舞いと理由 |
| --- | --- |
| `src/core/folio_command.{c,h}` | 単一登録表で操作ID・表示名・別名・検索・Ex解析を共有。未知入力・余計な引数を成功にしない |
| `src/application/folio_state.{c,h}` / `folio_note_change.h` / `folio_state_outcome.h` | `:q`のための読み取り専用本文比較。保存と同じUTF-16検証・改行正規化を共有し、別のdirty flagを作らない |
| `src/ui/win32/folio_window.c` / `folio_message.h` / `command_surface_mode.h` / `command_row.h` | INDEXの `:`、Ctrl+P、保存・終了・Help・×を一つのdispatcherへ。前面の子窓で入力し、開閉時に本文やUndoを流し直さない |
| `src/ui/win32/drawer_window.c` / `note_pane.c` | 入力面と重なる兄弟の描画をクリップし、後方の再描画が入力面を消さないようにする |
| `tests/unit/command_tests.c` / `state_tests.c` / `allocation_tests.c` / テスト入口 / `CMakeLists.txt` | 別名・不正入力・本文差分・正規化・状態不変・確保失敗を追加し既存ゲートへ結線 |
| `docs/adr/0016-*` / ADR索引 / GLOSSARY / todo | 共通実行・フォーカス・明示的な破棄の契約、現在のDraft状態を記録 |

初版の別名は `w/write`、`q/quit`、`wq/x`、`q!`、`help`。`:q`は未保存なら拒否、
`:wq`・×・Alt+F4は保存成功後だけ終了、`:q!`は現在の未保存本文を破棄する。Helpは同じ検索可能なパレット。
設定・number・search・replaceの未実装コマンドは登録していない。保存スキーマと実行時依存は変更していない。
