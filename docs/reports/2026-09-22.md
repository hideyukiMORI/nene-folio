## 運用の学び

- **1 つの実装 agent を複数の単位にまたいで使うと文脈が尽きる。Issue ごとに新しい agent を立てる。**
- **ADR が未定義の規則 ID を名指しすると CNF-006 で落ちる。** CNF-006 は「本文に定義があるのに強制マトリクスに行が無い」と「未定義の ID」の両方を拒むので、
  新しい ID（CNF-010 / C-018）は**それを定義する単位の同じコミットで planned として置き**、実装するコミットで active にする（ADR 0001）。
- **GitHub の `ready_for_review` で CI が起動しないことがある。** push（`synchronize`）で起動する。
  `gh pr ready --undo && gh pr ready` でも起きなければ、空でない push を足す。
- **使用制限で agent が止まっても、作業木の未コミットの編集から再開できた。** 区切りで止めるときは同じ agent へ
  「未コミットを事実の範囲でコミット → 狭い検査 → 最終 HEAD で 1 回だけゲート → push → どこまで済んだかをファイル名・関数名で報告」を送る運用のままでよい。
- 面ごとの行数を引数に取る式（#69）のように、**次の単位が使う形を先に 1 本にしておく**と、#75 の設定画面は行数を足すだけで済んだ。
