### 3段を main へ入れる手順で分かったこと（squash と積んだ枝）

- 下の段を squash で main に入れた後、上の枝へ `origin/main` を取り込むと、同じ変更が別のコミットとして見えて、17ファイルに衝突の印が出た。
- **手順**: (1) 取り込みをやめる。(2) 下の段の枝の先頭（履歴がつながっている）を、上の枝へ取り込む（衝突しない）。(3) `git diff origin/main <下の段の枝の先頭>` が空であること（main の中身が、下の段の枝と同じこと）を確かめる。(4) `git merge -s ours origin/main` で、中身を変えずに main とつなぐ。(5) 取り込む前後で `git diff` が空であることを確かめる。
- **失敗**: 1回目は (4) を `-X ours`（衝突した塊だけこちらを採る）でやって、衝突しない塊として関数が1つ二重に入った（`header_press_blocked`）。(5) の確かめで見つけて、取り込む前の内容に戻した。2回目（#1249）は `-s ours` にした。
