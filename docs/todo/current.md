## 動くもの

- 起動して、実行ファイルと同じ場所の `data/` を走査し、`categories.json` / `index.json` と照合した索引を枠なし窓の左ドロワーに描く（96 DPI・1 モニタで実機確認。`docs/quality/gate-proofs.md` 第 5 節）
- 台帳が版 1 の形でなければ、理由 1 行を出して終了コード 1（FR-015）
- カテゴリ行のクリックでアコーディオンがトグルし、`categories.json` の `expanded` を一時ファイル経由で原子的に書き戻す（FR-004 / FR-007）。書き戻せなければ表示は変えず理由 1 行
- ノート行のクリックで右ペインの RichEdit に md を表示する（FR-005 の閲覧側。見出し・強調・コード・リスト・リンク・引用のサブセット）
- 見た目はデザイン「案2 堅」。OS のアプリのモードに従ってライト／ダークが切り替わる（FR-016）
- 右ペインの頭の「編集」の札で同じ RichEdit が平文の編集になり、Ctrl+S・「閲覧」の札・別ノートへの切り替え・本文の `Esc`・窓を閉じる操作で同じ md へ原子的に書き戻す（FR-006）。本文が同じなら書かず、改行の形（LF / CRLF）は元のまま・BOM は書かない。書き戻せなければ理由 1 行を出して編集中の本文を残す（FR-015）。閲覧へ戻す操作は「閲覧」の札と、#49で追加する共通の「保存して閲覧」。窓を閉じる操作は編集モードを切り替えず、保存成功後に終了する。ノートを切り替えてもモードは保つ（ADR 0013 / ADR 0016）
- ドロワーの行をドラッグすると挿入線（掴んだ行のカテゴリ色）が出て、離すと表示順が変わり、カテゴリなら `categories.json`、
  ノートなら `data/<カテゴリ>/index.json` へ原子的に書き戻す（FR-008 / FR-009）。押して動かさずに離せば今までどおりの
  クリック。書き戻せなければ理由 1 行を出して表示は変えない
- ノートは**別のカテゴリへも移せる**（ADR 0008）。ポインタのある塊のカテゴリが移動先で、折り畳んでいれば末尾に入る。
  離すと md が移動先のディレクトリへ移り、移動先 → 移動元の順に `index.json` が書き戻る。移動先に同じ名前のノートが
  あれば移さずに理由 1 行。md を移せなければ何も変えない。md は移ったが台帳を書けなかったときは
  「次回の起動で揃います」の 1 行を出し、表示はファイルに従う（FR-008 の照合で自己修復する）
- 編集中でも並び替えと移動ができる。本文は RichEdit が持ったままで、右ペインの頭のカテゴリ名・番号・色だけが付け替わる
- 索引が窓に収まらなくなると、ポインタをドロワーに置いたホイール（1 刻み = ノート行 3 つ）と、主窓が受ける
  ↑↓（1 行）・PgUp / PgDn（1 画面 − 1 行）でスクロールする（FR-012）。**スクロールバーは出さない**。上に隠れた行が
  あれば頭の帯の直下に、下に隠れた行があれば下端に、24 px（96 DPI）のフェードが地の色へ線形に混ざる。上限は core の
  純関数で、量の所有者は application。スクロールした位置でもクリック・トグル・ドラッグの挿入線とドロップ先は正しく、
  ドラッグ中にホイールを回すと同じポインタ位置で挿入線が引き直される。編集中にドロワーをスクロールしても本文と Ctrl+S は無事
- カテゴリ行を**右クリック**すると OS の色の選択（`ChooseColorW`・全開・初期値はその行の色・カスタム色 16 枠は白）が出て、
  OK で閉じるとドロワーの番号・選択行の角の印・挿入線・右ペインの頭のパンくずがその色になり、`categories.json` の
  `color` に `#RRGGBB`（大文字）で原子的に書き戻る（FR-010）。キャンセルと同じ色は書かない。ノート行・頭の帯・
  左ボタンを押している間の右クリックは何もしない。編集中に色を変えても本文と編集モードは保たれる。
  書き戻せなければ理由 1 行を出して表示は変えない。**色の選択の窓は OS の部品なので、ダークでもライトのまま出る**（ADR 0010）
- 枠なし窓の client は**作成の瞬間から窓の矩形全体**（`WM_NCCALCSIZE` は TRUE も FALSE も自分で答え、既定処理に
  渡さない）。窓は 96 DPI で 560×360 より小さくならず、最大化するとモニタの作業領域に収まる。大きさを変えると
  ドロワーの高さ・右ペインの頭の札・パンくずが新しい大きさで描き直る。右ペインの頭が狭いときは
  **ノート名 → カテゴリ名の順に末尾が省略記号**になり、番号・「/」・札 2 つは残る（ADR 0011）
- md を書き戻す**直前**の本文が `data/.history/<カテゴリ>/<ノート>/1.md`（最新）〜`5.md`（最古）に連番で残り、
  6 つ目は捨てられる（FR-017 / ADR 0012）。本文が同じなら履歴も md も書かない。**履歴を残せなければ保存しない**
  （「履歴を書けなかったので保存していません。編集中の本文は残っています。」の 1 行を出し、md も編集中の本文もそのまま）。
  履歴はファイルのバイト列をそのまま写すので改行の形も BOM の無さも保たれ、`.` で始まるディレクトリは
  カテゴリとして走査しないので `.history` はドロワーに出ない。`data/` を丸ごと写せば履歴も一緒に移る
- フォーカスの区画は**索引（主窓）と本文（RichEdit）の 2 つ**で、押した側が取る（FR-018 / ADR 0013 / ADR 0015）。索引にあるとき
  `j` / `k` が次／前の**止まる行**（カテゴリごとに、見えるノート行があればそのノート、無ければ
  **折り畳んだ／ノート 0 本のカテゴリ行**。展開中でノートを持つカテゴリ行は飛ばす・端で止まる）、`gg` / `G` が最初／最後、
  `h` / `l` が**カーソルの行のカテゴリ**の折り畳み／展開（同じなら書かない）、`Enter` で本文へ。↑↓ / PgUp / PgDn は
  これまでどおりスクロール。**カーソルがカテゴリ行にあるあいだ、選択も右ペインも変わらず保存も走らない**。
  `h` で畳むとカーソルはそのカテゴリ行へ移り、`l` で展開すると選択中のノートがその中にあればそこへ、
  無ければ最初のノートへ移る（0 本なら行に留まる）。`Enter` はカテゴリ行では何もしない。
  **鍵で動かしたときだけ**カーソルの行が見える位置へ寄る（クリックでは寄せない）。
  本文にあるとき `Esc` は、編集中なら保存してから索引へ戻す（Ctrl+S はそのまま）。**モードはペインの状態として残り**、
  編集のままノートを切り替えると、いまのノートを保存してから次のノートが**編集モードで**開く（保存に失敗したら
  理由 1 行を出して選択は動かない）。**Escape で窓は閉じない**（Alt+F4 と閉じる操作だけ）。面は選択の行に敷き、
  **右端の角はカーソルの行**（カテゴリ行なら `+` / `−` の左）に置く。角は索引にフォーカスがあるとき塗り・本文にあるとき枠 1px
- 現在のノートの**名前を変えられる**（FR-031 / ADR 0022）。GUI の「操作」→「名前を変更」・F2・`:rename 名前` が
  同じ経路で、編集中なら先に保存してから `data/.rename.json` を版 1 で公開し、履歴 → md → `index.json` の順に
  置換なしで移して記録を消す。本文・モード・Undo と索引の位置は変わらない。同じ名前は何もせず、大小文字だけ違う
  名前・既存の名前・移動先に残った履歴・ローカル NTFS 以外・シンボリックリンク／junction は記録を公開する前に
  断る（何も変わらない）。同期フォルダのプレースホルダのような name surrogate でないタグの再解析ポイントは通す（#61）。
  途中で止まったらパンくずが「名前変更の復旧待ち」になり、保存・切替・並替・色・新規・別名保存・終了確認が
  先に同じ改名を再試行する。`:q!` でも記録は残り、次回の起動が走査より先に続きを行う
- 同じ `data/` を 2 つの NeNe Folio で開けない（`data/.nenefolio.lock`）。読み取り専用など書けない `data/` は
  閲覧のために起動し、保存・改名はそのつど理由を出して断る。復旧できない記録があるあいだは起動しない
- ドロワーの頭の「すべてのノートを検索」の欄（Ctrl+Shift+F）に打つと、**名前か本文**が一致するノートだけが
  索引に残る（FR-032 / ADR 0024）。一致を持つカテゴリは折り畳んでいても展開して並び、一致しないカテゴリは消える。
  本文は**この欄に最初に文字を入れたときに 1 回だけ**読み（起動は遅くならない）、以後は保存・新規・改名・移動で
  その写しだけを入れ替える。読めなかったノートは一致しない。ASCII の英字だけ大小を無視する部分一致。
  **絞り込んでいるあいだは並び替え（ドラッグ）とカテゴリの折畳／展開（`h` / `l`・クリック）ができない**
  （色・閲覧・編集・保存・新規・別名保存・改名は可）。開いている本文は一致しなくても閉じず、
  カーソルだけが最初に見える行へ移る。Esc と Enter は索引へ戻して絞り込みを保ち、空にすると解ける。
  語は保存しない
- 「操作」メニューとパレットの**「置換」**で下端に置換の欄が開き、パターンと置換文字列の 2 つの入力に打つたびに
  「対象名 / k 件」が出る（FR-023 / ADR 0028）。Enter と「1 件」が今の選択以降で最初の一致（無ければ先頭から巡回）を
  1 件、Ctrl+Enter と「すべて」が全部を 1 回で置き換える。**どちらも Undo 1 単位**（`EM_REPLACESEL` 1 回）で、
  全置換のあとはキャレットが先頭へ戻り、読んでいた論理行は保たれる。Tab が 2 つの欄を往復し、Esc で開く前の区画へ戻る。
  欄は開いたままなので続けて置換できる。md は書かないので保存は従来どおり Ctrl+S か編集を抜ける操作。
  エンジンは OS 同梱の ICU（`icu.dll`）で、大小無視はパターンの `(?i)`（Unicode の full case folding。
  ノート内検索の「ASCII だけ」とは意味が違う）。置換文字列は Vim 寄りの自前文法
  （`&` と `\0`・`\1`〜`\9`・`\r` / `\n`・`\\` / `\&` / `\/`）で、
  それ以外の `\x` と末尾の単独 `\` は断る。閲覧中に開くと「編集モードではありません。」の 1 行が出て本文は変わらない。
  **理由の 1 行が出ているあいだは Enter も Ctrl+Enter もボタンも本文を変えない。**
  **本文や開いているノートが変わった下見、直前の入力が失敗している欄では当たらない**
  （「本文か入力が変わったので、この置換は当てられません。もう一度入力してください。」の 1 行）。パターンは保存しない
- Ex の `:%s/パターン/置換/g` が欄を開かず全部を置き換え、`g` が無ければ**各論理行の最初の一致だけ**を置き換える
  （Vim と同じ）。区切りは `/` だけで `\/` は区切りにならない。1 件以上置き換えたら黙って閉じ、
  0 件なら Ex を閉じず「対象名 / 0 件」を出す。`:s`（`%` 無し・行の範囲）は意図して未対応で、未知のコマンドと同じ 1 行
- **Ctrl+S はどの入力面（Ex・パレット・検索欄・置換の欄・ドロワーの絞り込み欄）でも共通の保存へ渡り、
  欄は開いたまま残る**（#67 / ADR 0016 の補正 2）。語・選択・キャレット・フォーカス・入力面の種類は
  変わらず、編集中でなければ本文と同じく何もしない
- 中核の分岐 2279/2458（92.72%）。確保失敗の経路は測定ビルドの注入で全部走る

  `WM_NCPAINT` → 0）。証拠は「作成直後から差 0 px」と「非アクティブ化の直後に外周 8 px が地の色のまま」（第 5-j 節と追補）。
  **施主の実機で放置後も帯が出ないことの確認が残る**
